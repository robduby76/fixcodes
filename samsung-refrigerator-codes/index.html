Find the code on your display (or count the blinks) below.

CodeWhat it means
14EIce Maker Sensor Error
14E (or 14C) on a Samsung refrigerator is an Ice Maker Sensor Error: the main board is getting a bad reading from the temperature sensor on the ice maker in the fridge…
22EFridge Fan Error
22E or 22C on a Samsung refrigerator is a fridge fan error: the control board isn't getting feedback that the fan in the fridge section is turning.
33EIce Pipe Heater Error
33E or 33C on a Samsung refrigerator is an ice pipe heater error.

40EIce Room Fan Error
40E (or 40C) on a Samsung refrigerator is an Ice Room Fan Error: the control board isn't getting a signal back from the small fan that cools the ice maker compartment…
41Family Hub Software or Communication Error
Code 41 on a Samsung refrigerator points to the Family Hub screen, not the cooling system.
84CCompressor Lock
84C on a Samsung refrigerator means Compressor Lock: the inverter control tried to run the compressor and it didn't start turning.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
