Code: F2E1🌀 Maytag Dryer

Maytag Dryer F2E1: Keypad Error (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 4 manufacturer & service sources

⚡ Quick answer

F2E1 on a Maytag dryer is a keypad error. Maytag's technical sheet explains it as a stuck button, one the control saw held down for more than 20 seconds, or a user interface mismatch. Make sure nothing is pressing on the control panel, then reset the dryer by turning off its breaker for one minute and run a Timed Dry cycle. If the code comes back, the user interface (the keypad and display board) or its connections need service.

What the code means

Maytag's Product Help article lists F2E1 as "Keypad" and gives one owner fix: turn off the dryer's circuit breaker for one minute, turn it back on, start a Timed Dry cycle and watch the dryer for one minute to make sure the code doesn't return. Maytag's service technical sheet for its electronic dryers (W10316958 Rev B) gives the detail behind it: F2E1 is a "User Interface (UI) Problem (stuck button)," meaning a button was sensed as pressed for over 20 seconds, or the user interface doesn't match the control. That sheet says this fault code appears only in Service Diagnostic mode on those models, so on some dryers you'll only see F2E1 when a technician reads the stored codes. Maytag fault codes always pair an F number (the system) with an E number (the component), and the F2 group covers the user interface: F2E2 is listed as a keypad or control problem, and F2E3 as a user interface software error. The exact meaning can vary by model, so go by the tech sheet for your model number when a technician has it.

Likely causes

  • A button held down for more than 20 seconds, for example by something leaning on or stacked against the control panel (the stuck-button condition in Maytag's tech sheet)
  • A key on the touch panel that is physically stuck or sticky, sometimes from spills or residue on the panel
  • A temporary control glitch that Maytag's one-minute breaker reset clears
  • A loose connector between the user interface and the dryer's main control (CCU)
  • A failed user interface and housing assembly, or a user interface that doesn't match the control (Maytag's "UI mismatch")

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Look at the control panel and take away anything resting on it or pushing a button, like a laundry basket or items on a shelf. Press each button once to check none feels stuck down.
  2. Wipe the panel gently with a soft, barely damp cloth if it's sticky, and let it dry fully before using the dryer.
  3. Reset the dryer the way Maytag describes: turn off the circuit breaker for one minute, turn it back on, start a Timed Dry cycle and watch for one minute to see whether F2E1 comes back.
  4. If the code doesn't return, use the dryer normally. A single F2E1 after a button was leaned on usually doesn't mean a part has failed.
  5. If F2E1 keeps coming back or some buttons don't respond, stop resetting it. Maytag's service steps for that open up the console, so plan on a repair.

🛠 When to call a pro

  • F2E1 returns after the one-minute breaker reset. Maytag's help page says to contact Maytag or schedule service at that point.
  • Buttons don't light or beep when pressed, or the dryer won't accept selections.
  • Running Maytag's Service Diagnostic mode and Test #6 (Buttons and Indicators), which means unplugging the dryer, removing the top panel, checking that every connector on the main control and the user interface is fully seated, and checking that the user interface is properly inserted in the console.
  • Replacing the user interface and housing assembly, which is the tech sheet's fix when the connections check out. If the display stays dark, the tech sheet has the technician check the main control's supply voltages first.
  • The dryer is still under warranty. Schedule Maytag service instead of opening the console.
