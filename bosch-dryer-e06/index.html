Code: E06🌀 Bosch Dryer

Bosch Dryer E06 Error Code: Heating Circuit / Heating Element Overheating

Reviewed 2026-10-25 · Based on 3 manufacturer & service sources

⚡ Quick answer

E06 on a Bosch dryer points to a fault in the heating circuit. Bosch's US guide groups it with other electronic faults that only an authorized technician can fix, and Bosch's service error list for at least one US model (WTG865H2UC) is more specific: the main heating circuit's heating element is overheating. Clean the lint filter, check the vent or condenser for blockages, and try one full power reset (power off for at least 5 minutes). If E06 comes back, book Bosch service with your model number (E-Nr).

What the code means

Bosch's US dryer error code guide lists E06 with E08, E09, E24, E25, E28, E36 and E90 as an electronic fault/error that can only be eliminated by an authorized technician. Bosch Middle East has a dedicated E06 page that says the code occurs because of a fault with the heating circuit and should be fixed by an experienced engineer. The more specific meaning comes from Bosch's service manual error list for the WTG865H2UC dryer, as quoted by the technician reference MyPros+: E:06 = main heating circuit, heating element overheating. In plain terms, the control has seen the heater get hotter than it should, so it stops heating to protect the dryer. Because that service description comes from one model's manual, other Bosch models may use E06 slightly differently, which is why the technician should confirm it. E06 is different from E63, which Bosch's US guide describes as a heating element failure, and from E08 and E09, which the same service list ties to the temperature sensors (see our Bosch E08, E09 and E90 pages).

Likely causes

  • The main heating element overheating, which is how the Bosch WTG865H2UC service error list (via MyPros+) describes E06
  • A fault somewhere in the dryer's heating circuit, which is the wording on Bosch Middle East's E06 page
  • A fault in the dryer's electronic control, which is how Bosch's US error code table groups E06
  • A temporary electronics glitch after a power interruption, which a 5-minute power reset can sometimes clear (Bosch US guide)

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Turn the dryer off and note the exact code and your model number (E-Nr) from the rating label inside the door.
  2. Clean the lint filter, and on condenser or heat pump models clean the heat exchanger or filters as your manual describes. On a vented model, make sure the exhaust hose isn't crushed or blocked. Poor airflow makes any heater run hotter, so this is worth ruling out before a service call.
  3. Power reset: unplug the dryer or switch off its circuit breaker for at least 5 minutes, then restore power. Bosch says a power cycle can often clear error codes and reset the electronics.
  4. Run a short program with a small load. If it finishes normally, watch the next few loads.
  5. If E06 returns, stop there. The heater and its wiring sit inside the cabinet, and Bosch says this fault is for an authorized technician, so don't open the dryer or bypass any thermal protection.

🛠 When to call a pro

  • E06 comes back after cleaning and a 5-minute power reset: call Bosch Customer Support at 1-800-944-2904 (US) or book an authorized Bosch technician, and give them the E-Nr.
  • Mention that the service list for some models points E06 to the main heating circuit overheating, so the technician knows to check the heating element, its wiring and the temperature sensors before the control board.
  • The dryer smells of burning, trips the breaker or shows several electronic codes: unplug it and leave it off until it's been inspected.
