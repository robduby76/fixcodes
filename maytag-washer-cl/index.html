Code: CL🧺 Maytag Washer

Maytag Washer CL Code: Time to Run the Clean Washer Cycle

Reviewed 2026-10-24 · Based on 8 manufacturer & service sources

⚡ Quick answer

CL on a Maytag washer isn't a fault. Maytag says it's a reminder to run the Clean Washer (Clean Washer with affresh) cycle, and it shows up after 30 wash cycles. Empty the drum, add one affresh tablet or liquid chlorine bleach as your manual directs, run Clean Washer and let it finish. The code clears once that cycle is done, or on its own after three more regular cycles. Don't confuse it with LC or LoC, which is Maytag's Control Lock.

What the code means

Maytag's front-load CL article says the CL code is a reminder to run the Clean Washer cycle, that it appears after 30 cycles, and that it clears automatically once a Clean Washer cycle has been completed or after three cycles. The troubleshooting chart in Maytag's MHW5630HW owner's manual says the same thing: CL in the display, or a flashing Clean Washer LED at the end of a wash cycle on some models, means the washer has run 30 wash cycles and is reminding you to run Clean Washer with affresh. If you skip it, the reminder stops after 3 more regular cycles and comes back after another 30. The washer still works normally, so you can keep washing. CL is easy to mix up with LC or LoC: Maytag lists those as Control Lock, which disables the buttons and is turned off by holding the Control Lock button (on some models a dual-function button such as Pet Pro, Extra Rinse or Steam) for 3 seconds. If your display shows LC or LoC rather than CL, the controls are locked, not asking for a cleaning.

Likely causes

  • The washer has counted 30 wash cycles since the last Clean Washer cycle, so it's prompting you to clean it
  • A Clean Washer cycle was started but interrupted or cancelled, so it didn't count as completed
  • The display actually reads LC or LoC, which is Maytag's Control Lock, not the CL cleaning reminder

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Check the exact letters. CL is the cleaning reminder; LC or LoC means Control Lock, which you turn off by touching and holding the Control Lock button (or the button with Control Lock printed on or under it) for 3 seconds.
  2. Remove all clothes and other items from the drum. If the washer detects items during Clean Washer, it shows rL (remove load) and you have to restart the cycle.
  3. Put one affresh washer cleaner tablet directly in the empty drum or basket, not in the detergent dispenser. If your manual allows liquid chlorine bleach instead, use only the amount it gives (for example 2/3 cup in the bleach compartment on some front loaders) and never thickened, easy-pour or no-splash bleach, which Maytag says can cause excess suds.
  4. Select Clean Washer (Clean Washer with affresh) and start it. Don't add detergent, and don't open the door or lid or interrupt the cycle; Maytag's top-load cycle guide says the cycle can't be paused and runs about 60 minutes.
  5. Run hot water at the nearest sink first so the washer gets the hottest water available, which helps the tablet dissolve. If your washer has no Clean Washer cycle, Maytag says to use the cycle with the highest water level and hottest temperature.
  6. When the cycle ends, wipe out any leftover residue and leave the door or lid slightly open so the inside can dry. Maytag recommends Clean Washer every 30 washes, and monthly on front loaders, to prevent odors.
  7. If you'd rather not clean right now, you can keep washing; the reminder clears by itself after 3 more regular cycles and returns after another 30.

🛠 When to call a pro

  • CL keeps coming back immediately after a completed Clean Washer cycle.
  • The washer shows other F# E# codes along with CL; Maytag says to unplug it for 5 minutes and call for service if an F# E# code persists.
  • The control panel won't respond to any button even after holding Control Lock for 3 seconds.
  • The washer is under warranty. Call Maytag at 1-800-344-1274 or schedule service with your model number.
