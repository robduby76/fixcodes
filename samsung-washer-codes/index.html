Samsung Washer Error Codes: What Each Code Means

Every Samsung washer code explained on FixCodes, 5 in all. Together they cite 24 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
4CWater Supply / Not Filling
A 4C code on a Samsung washer means the washer has detected a water supply problem: water is not entering the washer correctly.
SCNot Draining
SC on a Samsung washer is the 5C code read on a seven-segment display: the washer can't drain water fast enough, or at all.
SudToo Many Suds
Sud on a Samsung washer means it detected too many suds.
U6Unbalanced Load
U6 on a Samsung washer is an unbalanced load error: the laundry has bunched up on one side of the drum, so the washer stopped short of a safe spin.
UrUnbalanced Load Retry
Ur on a Samsung washer means Unbalanced Load Retry: the washer sensed the load was off-balance before spinning, so it's adding water, trying to rebalance the laundry…

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
