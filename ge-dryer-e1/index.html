Code: E1🌀 GE Dryer

GE Dryer E1 (E01) Error Code: Inlet Thermistor Short or Control Memory Fault, Depending on Model (Meaning, Causes, Fixes)

Reviewed 2026-10-25 · Based on 5 manufacturer & service sources

⚡ Quick answer

E1 on a GE dryer depends on the model. On GE's 24-inch compact vented dryers (the GFD14 family), GE's technical service guide says E1 (stored as E01) is an inlet thermistor short: the temperature sensor on the heater reads out of range for five minutes, so the control can't trust the heat reading. On GE Profile DPVH880 dryers, E1 is listed instead as the interface EEPROM (the control's memory chip) not reading or writing properly. Start by turning the dryer off at the breaker for a minute, then run a short timed cycle. If E1 comes back on a compact dryer, the inlet thermistor and its wiring need a resistance check behind the rear heater panel; on a Profile dryer, a returning E1 usually points to the control board.

What the code means

GE uses E1 for different faults depending on the dryer family, so check your model number (on the label inside the door opening) first. In GE's Technical Service Guide for the 24 Inch Vented Dryer GFD14ESSNWW (publication 31-9309), the fault code table lists Inlet Thermistor Short: when the inlet thermistor readings exceed the minimum threshold (0.2 V) for 5 minutes, an inlet thermistor fault is set, and the action is to check resistance, connector and wiring and replace the thermistor if necessary. The inlet thermistor (NTC2) sits on top of the heater assembly, on the right as viewed from the back of the dryer, under the rear heater access panel. A thermistor's resistance drops as it heats up, so a shorted sensor or a pinched wire looks to the control like an impossible temperature. On that same compact control, the related codes are E02 (E2) outlet thermistor short, E03 inlet thermistor open and E04 outlet thermistor open, as listed in the code table MyPros+ compiles from GE's GFD14 service manual. On GE Profile DPVH880 dryers, the error list that MyPros+ compiles from GE's Profile DPVH880 service manual gives E1 as Interface EEPROM reading or writing improperly, and on that model the inlet thermistor short is E2 instead. Because the meanings differ so much, don't order parts until you know which family your dryer belongs to; if it's neither, look at the tech sheet behind the control panel or in the owner's packet.

Likely causes

  • Compact GFD14-type dryers: a shorted inlet thermistor (NTC2) on the heater assembly
  • Compact GFD14-type dryers: a pinched, chafed or shorted wire, or a loose connector, between the inlet thermistor and the main board
  • Compact GFD14-type dryers: a main board that misreads the thermistor circuit, if the sensor and wiring test good
  • Profile DPVH880 dryers: the user interface (control) board's memory chip failing to read or write, sometimes cleared by a power reset and otherwise fixed by replacing the board
  • Either family: a brief power disturbance or glitch that a one-minute breaker reset clears

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Find your model number on the label inside the door opening so you know which E1 meaning applies.
  2. Turn the dryer off at the circuit breaker (or unplug it) for one full minute, then restore power.
  3. Run a short timed dry cycle with a small load. If E1 doesn't return, it was likely a one-time glitch; keep an eye on it.
  4. Before any inspection, unplug the dryer (and shut off the gas on a gas model). The rear heater panel and the heater assembly carry 240 V when the dryer is plugged in.
  5. On a compact GFD14-type dryer, look at the back of the cabinet: if the power cord or rear outlet area shows damage, scorching or a crushed harness, stop and book service rather than running the dryer.
  6. Clean the lint screen and make sure the vent isn't blocked. A blocked vent doesn't cause a thermistor short, but it makes the heater run hotter and is worth ruling out while you're there.
  7. If you're comfortable with a multimeter and the dryer is unplugged, a compact dryer's inlet thermistor can be checked off its connector: GE lists about 57.3 to 63.85 kilohms at 68°F (room temperature). A reading near zero means the sensor or its wire is shorted.
  8. If E1 keeps coming back, stop using the dryer for heated cycles and schedule a repair.

🛠 When to call a pro

  • E1 returns on a compact GFD14-type dryer: GE's guide says to check resistance, connector and wiring and replace the inlet thermistor if necessary. It's under the rear heater access panel, which GE notes is held by seventeen screws.
  • The thermistor reads correctly but E1 persists: the wiring between the heater and the main board, then the main board itself, are next.
  • E1 returns on a Profile DPVH880 dryer after a power reset: the code points to the control's memory, which usually means replacing the user interface board.
  • You see scorched wiring, a melted connector, or smell burning at the back of the dryer.
  • Any time you smell gas or burning, unplug the dryer, shut off the gas, and call for service. GE Appliances Factory Service books repairs at repair.geappliances.com.
