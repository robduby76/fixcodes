Whirlpool Washer LoC (LC) Code: Control Lock Is On (How to Unlock)

Reviewed 2026-10-25 · Based on 5 manufacturer & service sources

⚡ Quick answer

LoC (or LC on some models) on a Whirlpool washer isn't a fault. Whirlpool says it means the Control Lock is turned on, so the buttons won't respond and a new cycle can't be started or changed. Press and hold the Control Lock key for 3 seconds until the display counts down 3, 2, 1 and the lock clears. On many models Control Lock shares a button with another option such as Extra Rinse, Pet Pro or Steam.

What the code means

Whirlpool's Product Help article for front load washers is titled "There is no Error - Control Lock is activated." When Control Lock is on, the control won't function, and if you press buttons the display shows LoC or LC (depending on the model) as a reminder that the lock is set. Whirlpool's front load washer error code list gives the same meaning, and its owner's manuals say plainly that Loc "is not an error code but just an indication that the control is locked." Control Lock is a child-safety and anti-bump feature: you turn it on by holding the Control Lock key for 3 seconds, and the display counts down "3," "2," "1" before showing LC or LoC. While it's on you can still touch Start to pause a running cycle or Power to turn the washer off. On top load models without a code display, a lit Control Lock light does the same job. Don't confuse LoC with CL: on some Whirlpool front loaders CL at the end of a cycle is the reminder to run the Clean Washer with affresh cycle, not a lock.

Likely causes

  • Control Lock was turned on, often by accident, by holding the lock key (or the button it shares) for 3 seconds
  • On models where Control Lock is a second function of Extra Rinse, Pet Pro, Steam or another option, a long press on that option locked the controls
  • Someone (often a child) leaned on or played with the panel, which is exactly what the lock is meant to stop
  • Less often, a stuck or damaged key on the touchpad keeps the controls from responding, so the lock can't be released

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Find the Control Lock key. It may be its own button or a second function of another key; Whirlpool names Extra Rinse, Pet Pro and Steam as examples. Look for a lock icon or the words "hold 3 sec for Control Lock" near a button.
  2. Press and hold that button itself, not the printed text below it, for 3 seconds. The display counts down 3, 2, 1, and LoC or LC clears once the lock is off.
  3. On touch panels, touch the button name rather than the indicator light, as Whirlpool's top load guide advises.
  4. If you can't find the key, check the Control Lock section of the owner's manual for your exact model; it names the button to hold.
  5. If the lock still won't release, reset the control: unplug the washer (or switch off its breaker) for 5 minutes, restore power, and try the 3-second hold again.
  6. To lock the controls again later, for example with small children around, hold the same key for 3 seconds.

🛠 When to call a pro

  • If no key responds and LoC won't clear after a 5-minute power reset, the touchpad (keypad) or user interface board may be faulty; order the part by your washer's full model number.
  • An appliance technician can confirm whether the problem is the keypad, the wiring to it, or the control board before parts are swapped. Whirlpool's service line is 1-866-698-2538.
