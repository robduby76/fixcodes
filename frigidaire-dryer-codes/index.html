Frigidaire Dryer Error Codes: What Each Code Means

Every Frigidaire dryer code explained on FixCodes, 3 in all. Together they cite 7 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
E61Heater Relay Failure
E61 on a Frigidaire electric dryer means the control board found a problem with the relay that switches the heater on and off.
E64Heater Open Circuit, Dryer Not Heating
E64 on a Frigidaire dryer means Heater Open Circuit: the control board found a break in the heating element or its wiring, so the dryer tumbles but doesn't heat.
E65High Limit Thermostat Trip Count Too High

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
