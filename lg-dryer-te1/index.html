Code: tE1🌀 LG Dryer

LG Dryer Error Code tE1: Thermistor Problem (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 5 manufacturer & service sources

⚡ Quick answer

tE1 on an LG dryer means the control detected a problem with the dryer's thermistor, the temperature sensor that tells the board how hot the air is. LG's first fix is a reset: cut power, hold START/PAUSE for 5 seconds, then power back up. If tE1 comes back, LG's service literature says the thermistor reads open, so the usual repair is the thermistor or its wiring, and occasionally the control board.

What the code means

LG's dryer error code list says a tE1 code means a problem was detected with the dryer's thermistor, and that the fix is usually a simple reset; LG's newer list groups tE1 through tE6 as thermistor errors with the same steps. The thermistor is a temperature sensor that helps the dryer hold the temperature you selected, so without a good reading the dryer can't control its heat. LG's service manuals are more specific: tE1 is displayed when the thermistor is open (no circuit), while tE2 means it is shorted, and both say the thermistor should be replaced if the code persists. In the service manual's diagnostic test, tE1 and tE2 show up during the first check step, and the related symptoms LG lists are a heater that won't turn off and a big difference between the actual and sensed temperature. On LG steam models, tE4 is a separate code for the steam generator's own thermistor, so it isn't the same repair as tE1.

Likely causes

  • A temporary control glitch that a reset clears (LG's first step for tE1)
  • An open (broken) thermistor, which LG's service manuals name as the tE1 condition
  • A loose, corroded or damaged connection or wire between the thermistor and the control board
  • A poor connection at the 6-pin connector on the controller, or a failed controller, which LG's thermistor test checks for

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Reset the dryer the way LG describes: unplug it or switch off its breaker, and while it has no power, press and hold START/PAUSE for 5 seconds. Then restore power and run another cycle.
  2. Clean the lint filter and make sure the exhaust vent isn't crushed or clogged. It doesn't fix a failed sensor, but it rules out heat problems while you watch whether tE1 returns.
  3. If tE1 comes right back, stop resetting and write down the code. LG says the dryer may need repair service at that point, and repeated resets erase the history a technician uses.
  4. If you're comfortable with appliance repair and the dryer is out of warranty, unplug it first and follow your model's service manual to reach the thermistor. LG's procedure is to measure its resistance with the harness unplugged and compare it to LG's temperature chart; for example, LG's table lists about 18.0 kilohms at 50°F, 11.7 at 70°F and 6.2 at 100°F.

🛠 When to call a pro

  • tE1 comes back after LG's reset. LG says to request repair service, and its service manuals say the thermistor should be replaced.
  • Testing the thermistor and its harness against LG's resistance table, then checking the harness-linking connector if the sensor reads in range.
  • Checking the controller's 6-pin connector and, if the circuit tests good from there, replacing the controller, which is LG's last step in its thermistor test.
  • The dryer is still under warranty. Contact LG or an LG-authorized servicer instead of opening it yourself.
  • The dryer keeps heating when it shouldn't or runs very hot. LG lists a heater that won't turn off as a thermistor symptom, so stop using it until it's checked.
