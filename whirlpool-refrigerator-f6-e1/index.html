Code: F6 E1🧊 Whirlpool Refrigerator

Whirlpool Refrigerator F6 E1 (F6E1): Display and Main Control Not Communicating (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 4 manufacturer & service sources

⚡ Quick answer

F6 E1 on a Whirlpool refrigerator means the main control board (the ACU) and the display/control panel (the HMI) have stopped talking to each other. Whirlpool's first step is a 1-minute power reset, then making sure cooling is turned back on. If the code comes back, the usual suspects are a loose or damaged harness between the two boards, then the display board, then the main control board.

What the code means

Whirlpool's own refrigerator tech sheet W11446054 lists F6E1 under "Communication System" as "Comm Failure Between ACU 1 and HMI 1." The ACU (appliance control unit) is the main control board that runs the compressor, fans and heaters; the HMI (human-machine interface) is the display and buttons you use to set temperatures. When the two lose their data link, the display can't send settings to the main board or show what it's doing. Whirlpool's consumer Product Help page for F6 E1 (bottom-freezer and French-door models) doesn't spell out the meaning; it just calls it a flashing "F" code and gives a power reset. On some older Whirlpool-built refrigerators with separate fridge and freezer displays, Sears PartsDirect lists the same kind of failure as "CF" on the freezer display.

Likely causes

  • A temporary control glitch, for example after a power blip, which a power reset clears (Whirlpool Product Help)
  • A loose, unplugged or damaged wire harness between the main control board and the display/user interface (Sears PartsDirect's procedure for the same communication failure)
  • A failed display or user interface board (Sears PartsDirect checks this after the harness)
  • A failed main control board (ACU), the last item in Sears PartsDirect's order

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Reset the power. Whirlpool says to unplug the refrigerator or switch off its breaker for 1 minute, then restore power.
  2. Check that cooling is on. After the reset, Whirlpool says to make sure the cooling function is turned on, since a fridge can come back with cooling off and won't keep food cold.
  3. Watch it for a minute. Whirlpool says to monitor the refrigerator for 1 minute to make sure the code doesn't come back.
  4. While it's being sorted out, keep the doors closed and keep an eye on temperatures with a thermometer. The fridge may not run normally if the boards can't talk.
  5. If F6 E1 comes back, Whirlpool's advice is to schedule service (1-866-698-2538 in the US).

🛠 When to call a pro

  • The code returns after a 1-minute power reset.
  • The next step is checking the harness connections at both the display board and the main control board, which means unplugging the fridge and opening control covers; the main board area carries line voltage.
  • Whirlpool's tech sheet describes a service diagnostics mode (press any three different keys in sequence, three times within 8 seconds) that shows up to five stored fault codes in priority order. It's meant for technicians and the key layout varies by model.
  • If the harness is fine, Sears PartsDirect's order is to replace the user interface control first and the main control board only if the problem persists. Both are model-specific, so match the part number to the model number on the fridge's label.
  • The fridge or freezer is getting warm. Move perishable food and call for service.
