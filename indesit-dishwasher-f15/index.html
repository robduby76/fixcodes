Code: F15🧺 Indesit Dishwasher

Indesit Dishwasher Error Code 15 (F15): Virtual Sensor Error (All Four Code Lights On)

Reviewed 2026-10-26 · Based on 2 manufacturer & service sources

⚡ Quick answer

Error 15 (F15) on an Indesit dishwasher is the virtual sensor error. Indesit Service UK lists it as F15 "Virtual sensor error", and on machines that show codes with lights instead of a display it appears as LED 6, 7, 8 and 9 all lit at once. Indesit's only advice is to book an engineer. On the identical Hotpoint code (both brands are Whirlpool EMEA, formerly Indesit Company, and share this code list), the fault is explained as the wash pump and drain pump readings not matching, with a new wash pump or drain pump as the fix. A power reset and a clean filter are worth trying first, but if F15 keeps coming back it's a pump repair.

What the code means

Indesit Service UK's dishwasher error code list names F15 "Virtual sensor error" and gives the flashing-LED pattern as LED 6 on, LED 7 on, LED 8 on and LED 9 on, with the action to call customer service and book an engineer. Indesit's page doesn't explain the fault further, but Hotpoint UK's dishwasher error code guides, for the sister brand that uses the same F01 to F15 list and the same LED patterns, say F15 means the reading between the wash pump and the drain pump is not consistent, and list replacing the wash pump and replacing the drain pump as the checks. A "virtual sensor" means there's no separate physical sensor: the control board works out what's happening in the tub from how the two pumps behave, and when those signals don't add up it stops the cycle and shows F15. Don't confuse it with other all-lights-looking patterns: Indesit lists F07 (water turbine damaged) as LED 6, 7 and 8 on with LED 9 off, F13 (main board fault) as LED 6, 8 and 9 on with LED 7 off, and F03 (drain failure or timeout) as LED 6 and 7 only. Count the lights carefully before deciding which code you have.

Likely causes

  • A failing wash (circulation) pump whose readings don't match the drain pump, the first part Hotpoint lists for the same F15 code on its sister-brand dishwashers
  • A failing drain pump, the second part Hotpoint lists
  • Loose or damaged pump wiring or connectors, so the board gets a bad signal from one pump (general repair background; an engineer checks this before replacing a pump)
  • Very poor water circulation from a clogged filter or debris in the sump, which can upset the pump readings (general advice, not an Indesit-listed cause)

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Switch the dishwasher off and unplug it or turn it off at the isolator switch for a few minutes, then switch back on and try a short program. This clears a one-off glitch on many machines (general advice).
  2. With the power off, take out and rinse the filter in the bottom of the tub and clear any food, glass or labels from the sump around it.
  3. Make sure the lower spray arm turns freely and the drain hose behind the machine isn't kinked or squashed.
  4. Check the panel lights: Indesit's F15 pattern is LED 6, 7, 8 and 9 all on. If only three of them are lit, it's a different code (F07 or F13, for example), so look that one up instead.
  5. If F15 comes back after a reset and a clean filter, stop there. Indesit's advice is to book an engineer through Indesit Service UK (0344 822 4224 is the number it lists for most dishwasher codes) or use a qualified appliance engineer.

🛠 When to call a pro

  • F15 returns after a power reset and filter clean: on the matching Hotpoint code the parts to replace are the wash pump and the drain pump, and an engineer can test which one is at fault before ordering.
  • The dishwasher also hums without washing, won't drain, or leaks: the pump itself or its seals may be failing.
  • The machine is under warranty: use Indesit's own service so the repair stays covered.
