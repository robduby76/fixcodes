Code: F2E2🌀 Maytag Dryer

Maytag Dryer F2E2: Keypad or Control Error (Meaning, Causes, Fixes)

Reviewed 2026-10-25 · Based on 5 manufacturer & service sources

⚡ Quick answer

F2E2 on a Maytag dryer is a keypad or control error: the dryer's main control can't properly communicate with the user interface (the console keypad and display board). Maytag's tech sheets describe it as the user interface being unable to read its software, or as the interface being disconnected or reporting an internal fault. Reset the dryer by turning off its breaker for one minute, then run a Timed Dry cycle and watch it for a minute. If F2E2 comes back, the connections between the main control and the user interface need to be checked, and the user interface board usually gets replaced.

What the code means

Maytag's Product Help article lists F2E2 as "Keypad or Control" and gives one owner fix: turn off the dryer's circuit breaker for one minute, turn it back on, start a Timed Dry cycle, and watch the dryer for one minute to make sure the code doesn't come back. Maytag fault codes pair an F number (the system) with an E number (the component), and the F2 group is the user interface. In Maytag's service technical sheet for its electronic dryers (W10316958 Rev B), F2E2 is "User Interface Software Error 1": it appears if the user interface (UI) can't read the software stored in its own EEPROM memory chip. The sheet's recommended steps are to verify all connections between the cycle control unit (CCU, the main control board) and the UI, then replace the UI. On newer Whirlpool and Maytag 7.4 and 8.8 cu. ft. dryers covered by Whirlpool technical manual W11416805, F2E2 is called "HMI Disconnected" (HMI is the human-machine interface, the same console board), with the note that the HMI has detected an internal fault; that manual sends technicians to its HMI test. Whirlpool's own help page uses the same "Keypad or Control" wording and reset. F2E2 is different from F2E1, which is a stuck button, and from F2E3, which W10316958 lists as a main control EEPROM that isn't programmed correctly.

Likely causes

  • A temporary control glitch, for example after a power flicker, that Maytag's one-minute breaker reset clears
  • A loose, unseated, or damaged connector or wire harness between the main control (CCU or ACU) and the user interface board
  • The user interface board can't read its own software memory (W10316958's "User Interface Software Error 1")
  • An internal fault in the user interface (HMI) board itself, as described in Whirlpool technical manual W11416805
  • Less commonly, a main control that isn't supplying proper voltage to the user interface, which W11416805's HMI test checks before replacing the HMI
  • Moisture or spills that reached the console electronics

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Reset the dryer the way Maytag describes: turn off the dryer's circuit breaker (or both breakers on an electric dryer) for one minute, turn it back on, start a Timed Dry cycle, and watch for one minute to see whether F2E2 returns.
  2. If the code doesn't return, use the dryer normally. A single F2E2 after a power interruption doesn't always mean a part has failed.
  3. Check that the dryer is plugged in firmly and isn't on an extension cord or a loose outlet, since unstable power can upset the control.
  4. If the console is wet or sticky from a spill, unplug the dryer and let it dry out completely before trying again.
  5. Write down your full model number from the tag inside the door opening. It tells a technician or parts store which tech sheet and user interface board match your dryer.
  6. If F2E2 keeps coming back, stop resetting it. The next steps mean opening the console to check connectors on the control boards, so plan on a repair unless you're comfortable working on unplugged appliance electronics.

🛠 When to call a pro

  • F2E2 returns after the one-minute breaker reset. Maytag's help page says to contact Maytag or schedule service at that point.
  • Checking connections: per W10316958, a technician unplugs the dryer, removes the top panel, and checks that every connector between the CCU and the user interface is fully seated, then replaces the UI if the connections are good.
  • On models covered by W11416805, the HMI test also has the technician remove the fascia and HMI assembly to inspect its connections, then measure the main control's supply voltages: if they're present the HMI and housing assembly is replaced, and if not the main control (ACU) is replaced.
  • The display stays completely dark or the dryer won't accept any selections.
  • The dryer is still under warranty. Schedule Maytag service instead of opening the console.
