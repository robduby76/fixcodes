Code: 23🧺 GE Washer

GE Washer Error Code 23: Door Lock (Lid Lock) Failure

Reviewed 2026-10-24 · Based on 2 manufacturer & service sources

⚡ Quick answer

Error code 23 on a GE washer is a door lock problem. On GE UltraFresh front loaders it's the Critical Door Lock Failure fault: the washer canceled the cycle because it couldn't get the door lock into the position it wanted. On GE top-load (GTW) washers, Sears PartsDirect lists 23 (along with 13, 14 and 24) as a lid lock/switch failure. Start by making sure the door or lid closes freely and nothing is caught in the latch. If the code keeps coming back, the lock assembly or its wiring is the usual fix.

What the code means

On GE UltraFresh front-load washers (GFW510, GFW550, GFW650, GFW850 and related models), GE's Technical Service Guide 31-9327 defines fault code 23 as Critical Door Lock Failure, triggered when the cycle is canceled due to inability to reach the desired door lock state. The door lock assembly holds both the door switch and the locking mechanism. GE's guide explains the control pulses the lock solenoid, waits about a second, then reads the lock feedback to see whether it actually locked or unlocked. If that fails, it retries up to three times, waits a 30-second cool-down, tries four more times, and if those fail too it applies a 180-second cool-down and sets the critical lock fault. So code 23 means the lock repeatedly didn't respond the way the control expected, not just one missed attempt. The usual reasons are a door that isn't fully closed or is sagging, debris blocking the lock, a failed lock assembly, or a wiring or connection problem between the main board and the lock. Code 24 is a related but different fault (the washer sees the door as both open and locked for 5 seconds in a row). On GE top-load washers in the GTW series, Sears PartsDirect's GE error code chart groups 13, 14, 23 and 24 together as a lid lock/switch failure: unplug the washer, check the lid lock/switch wiring, and if the wiring is fine, replace the lid lock/switch assembly.

Likely causes

  • The door or lid isn't fully closed, or the door has dropped slightly so it doesn't close freely into the latch
  • Clothing, lint or other debris blocking the door lock or latch opening
  • A failed door lock (lid lock) assembly: the switch or the lock solenoid inside it
  • A loose, damaged or corroded wire harness or connector between the main control board and the lock assembly
  • Less often, a control board that isn't sending power to the lock, which a technician confirms by checking for 120 VAC while the lock is activated

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Unplug the washer for a minute, plug it back in and try a short cycle. If 23 doesn't come back, it may have been a one-time miss.
  2. Front loaders: close the door firmly and watch whether it swings shut freely. GE says if the door doesn't close freely, lift the door until it does; a sagging door can keep the latch from lining up.
  3. Look at the latch on the door and the lock opening on the washer. Pull out any clothing, lint or debris, and make sure nothing is caught in the door seal near the latch.
  4. Top loaders: make sure the lid closes all the way and nothing is stuck under it or in the lid lock slot. Unplug the washer and check that the lid lock/switch wiring connection is snug, per Sears PartsDirect.
  5. If the door is locked with wet clothes inside, GE's guide describes a manual release: with the washer unplugged, remove the top panel, reach down to the bottom of the lock assembly and push its button in. Only do this if you're comfortable removing the top panel.
  6. If the door closes freely, the latch is clear and 23 keeps coming back, plan on replacing the door lock or lid lock assembly for your exact model.

🛠 When to call a pro

  • Running GE's service mode spin test 14 to confirm whether the door lock actually operates.
  • Checking door switch and lock continuity at connector J513 on the control. GE's guide gives readings of about 127 ohms on the door switch and lock contacts with the door closed and locked, and open readings with the door unlocked and open.
  • Verifying 120 VAC reaches the lock while the control is activating it, and checking the harness from the control to the lock assembly. GE's checklist starts with replacing the door lock and harness, then running these checks if the fault continues.
  • The code returns after a new lock assembly, which points to wiring or the main control board.
