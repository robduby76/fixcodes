Code: F16🧺 Hotpoint Washer

Hotpoint Washing Machine F16 Error Code: Drum Lock Position Fault (Top Loaders)

Reviewed 2026-10-26 · Based on 3 manufacturer & service sources

⚡ Quick answer

F16 on a Hotpoint washing machine is a drum lock position sensor fault, and it only applies to top-loading machines: the drum has stopped in the wrong position or isn't locked in the right position, so you may not be able to get at the drum flaps. Check the drum flaps are properly closed and nothing is caught in them, try one reset, and if F16 comes back, Hotpoint's advice is to book an engineer.

What the code means

Hotpoint UK's washing machine error code guide lists F16 as "Drum lock position sensor fault (top loading machines only)", with the issue described as the drum stopping in the wrong position or not being locked in the correct position, and its advice is to call 0344 822 4224 to book an engineer. Indesit's technical documentation for the WIL10 (the French service file for the shared Hotpoint/Indesit electronics) gives the same meaning: F16 is a drum lock ("blocage du panier") fault on top-loading washers only. On a top loader, the drum has to park with its flaps facing up under the lid so you can open them, and a sensor tells the control board when the drum is in that position and locked. F16 means the board didn't get that confirmation. Front-loading Hotpoint machines don't use F16 this way; if you have a front loader, check the code against your own manual. For contrast, F17 on the same electronics is a door lock fault and F18 is an internal data error on the main board.

Likely causes

  • The drum flaps weren't fully closed and latched, or laundry is caught between the flaps or between a flap and the drum, so the drum can't turn and park normally
  • A faulty drum lock position sensor that no longer reports where the drum has stopped (the part named in Hotpoint's F16 description)
  • Loose or damaged wiring between the position sensor and the main board
  • A fault on the main control board that reads the sensor

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Unplug the machine before reaching into the drum.
  2. Open the lid and check the drum flaps. Hotpoint's top-loader manual (WMTF722H) says to close the drum by holding both flaps in the middle with the rear flap over the front flap, and to make sure they're properly locked: depending on the model, all metal hooks hooked inside the rear flap, the button overlapping the rear flap's edge, or the front flap's slider slightly overlapping the rear flap.
  3. Make sure no laundry is caught between the flaps or between the flaps and the drum, and that the load isn't overhanging the drum. The manual says not to use the flaps to push laundry down.
  4. Don't force the drum round by hand while it's locked.
  5. Plug back in and try a short programme once. On Hotpoint top loaders, a drum-flaps-open warning is cleared by pressing Reset for at least 3 seconds, waiting for the Door open light, closing the flaps and restarting, per the WMTF722H manual.
  6. If F16 returns with the flaps properly closed, stop there and book an engineer, as Hotpoint advises.

🛠 When to call a pro

  • F16 comes back after the flaps are closed properly and the machine has been reset: Hotpoint's listed fix is an engineer visit.
  • The drum is stuck with the flaps facing down or sideways and you can't reach your laundry.
  • You hear grinding or knocking as the drum tries to park.
  • The machine is under warranty: call Hotpoint service on 0344 822 4224 rather than opening it.
