Frigidaire Refrigerator CE Error Code (SY CE, Er CE): Control Board Communication Error (Meaning, Causes, Fixes)

Reviewed 2026-10-22 · Based on 6 manufacturer & service sources

⚡ Quick answer

CE on a Frigidaire refrigerator, usually shown as SY CE (or Er CE on some four-door models), means the display panel (user interface board) and the main control board stopped talking to each other after the fridge had been running. Try a hard reset first by unplugging it for a few minutes. If the code comes back, Frigidaire lists it as a code that needs authorized service; a technician checks the wiring harness between the two boards before replacing either board.

What the code means

Frigidaire's service data sheets (for example 242292100, an ice and water bottom-freezer sheet) define SY CE as a "UI to Main Control Board communication error; after a period in operation." The related SY CF code is the same communication failure on start up. The display usually shows SY in the freezer window and CE in the fresh food window. Frigidaire's owner support pages list SY CE (French-door models) and Er CE (four-door models) among the codes that "could indicate an authorized service is required," and give no owner fix beyond a reset. Sears PartsDirect describes SY CE or SY CF the same way: a communications failure between the electronic control board and the user interface.

Likely causes

  • A loose or backed-out pin in the wire harness connector at the main control board or the display board
  • Pinched, chafed or damaged wires between the two boards, for example where the harness runs through the door hinge on French-door models
  • A main control board fault (Sears PartsDirect lists it as the first board to replace once wiring checks out)
  • A user interface (display) board fault, if the code continues after the main control board is replaced
  • A temporary glitch, such as after a power surge, which a hard reset may clear

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Hard reset: unplug the refrigerator, wait 2 to 3 minutes (Frigidaire's guide) and plug it back in. If you can't reach the plug, switch off its breaker, remembering this cuts power to everything on that circuit.
  2. If your model has a CLEAR ALERTS button, press it after power returns, as Frigidaire's error code guide suggests.
  3. Watch the display for the next day. Keep the doors closed and check with a fridge thermometer that the fresh food side stays near 37°F and the freezer near 0°F.
  4. On French-door models, look at the top hinge area of the door with the display. If the wire bundle there looks pinched, crushed or cut, stop and book service rather than running the fridge.
  5. If SY CE or Er CE comes back after the reset, Frigidaire says to contact them (or your installer if it was installed within the past 30 days) to schedule service.

🛠 When to call a pro

  • The code returns after a hard reset. Frigidaire lists SY CE and Er CE as codes that may need authorized service.
  • The fridge or freezer isn't holding temperature, or the display won't respond.
  • Wiring checks: Frigidaire's service sheet tells technicians to check for pin back-outs and pinched or damaged wires before replacing parts, and to work out whether the fault is the component, the main control board or the wiring.
  • The refrigerator is under warranty. Use the contact options on Frigidaire's owner support site to schedule service.
