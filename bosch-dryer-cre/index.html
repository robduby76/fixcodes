Bosch Dryer CrE Code: Run the Appliance Care Programme (Not a Fault)

Reviewed 2026-10-26 · Based on 3 manufacturer & service sources

⚡ Quick answer

CrE on a Bosch dryer is not an error. Bosch says it means it's time to run the basic appliance care programme, a roughly one-hour cleaning cycle that removes light dirt deposits inside the dryer. The reminder shows for about 5 seconds before a programme starts and again at the end, and it keeps coming back until the care programme has run all the way through. Empty the drum, clean the fluff filter, empty the condensation container, add about 1.5 litres of hot tap water to it, call up the care programme (CP1) and press Start.

What the code means

Bosch's US dryer error code guide lists CrE as a maintenance prompt, not a fault: after a certain period of use the dryer recommends running the basic appliance care program, the notice appears on the display for 5 seconds before the start and at the end of a program, and it keeps showing until the care program has been run completely. Bosch's heat pump dryer manuals (for example WQG24590BY and WQG24591BY) say the same thing in their display table, "CrE: Run the basic appliance care programme", and explain that the basic programme removes light dirt deposits in the appliance and runs for about 1 hour. On these SelfCleaning models the care programme is how the inside of the dryer gets cleaned, so ignoring the prompt can let drying performance slip over time. The same manuals describe a separate intensive care programme (CP2) for stubborn deposits and odours after the dryer has sat unused for more than a month; it runs about 4 hours, needs Bosch's own appliance care product and must not be cancelled. You only need the basic programme (CP1) to clear CrE. Some Bosch models spell the same reminder CArE, and the exact steps to call up the programme differ by model, so check your user manual.

Likely causes

  • The dryer has reached the amount of use after which Bosch recommends the basic appliance care programme (normal, not a fault)
  • The care programme was started but cancelled or interrupted before it finished, so the reminder keeps returning
  • The reminder appears both before a programme starts and after it ends, so it can look like a repeated error even when the dryer is fine

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Make sure the drum is empty and switch the dryer off.
  2. Clean the fluff (lint) filter, then pull out the condensation container horizontally and empty it. If your dryer drains through a drain hose, move the stopper as your manual describes and clean the filter in the condensation container.
  3. Call up the basic care programme. On the WQG24590BY, Bosch says to set the programme selector to position 1, press and hold Iron Dry, turn the selector to position 4, then release Iron Dry; CP1 and the programme time alternate on the display. Your model may use a different button or position, so follow your manual.
  4. Pour about 1.5 litres of hot mains (tap) water into the condensation container, hold it level, and slide it back in until it locks.
  5. Press Start/Reload and let it run to the end (about 1 hour) without interrupting it. When End appears, empty the condensation container, put the drain-hose stopper back if you moved it, refit the container and switch the dryer off. CrE should not come back until the next reminder interval.

🛠 When to call a pro

  • CrE keeps appearing even after the basic care programme has run all the way to End: contact Bosch customer service (1-800-944-2904 in the US) with your model (E-Nr) and FD number.
  • The care programme won't start, stops partway, or shows a different code such as E01 or an electronic fault: look up that code, and call Bosch if it persists.
  • The dryer has started drying poorly or smells after a long idle period: Bosch's intensive care programme (CP2) with its appliance care product is meant for that; if it doesn't help, book service.
