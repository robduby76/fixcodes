Whirlpool Dryer Error Codes: What Each Code Means

Every Whirlpool dryer code explained on FixCodes, 5 in all. Together they cite 25 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
F01 / F-01 / F1 E1Main Control Failure
F01 on a Whirlpool dryer means the dryer's main electronic control has detected a fault in itself.
F3E2Moisture Sensor Issue,
F3E2 on a Whirlpool dryer means a moisture sensor issue: five loads in a row were dried without the dryer registering any data from its moisture sensor strips.
F70Control Communication Failure
F70 on a Whirlpool dryer means the display and button board (the user interface) isn't getting messages from the dryer's main control board.
LocControl Lock Is On (How to Unlock)
Loc (or Lc on some models) on a Whirlpool dryer isn't a fault.
PFPower Failure Interrupted the Cycle
PF on a Whirlpool dryer stands for Power Failure: the drying cycle was interrupted because the power dropped out.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
