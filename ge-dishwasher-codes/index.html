GE Dishwasher Error Codes: What Each Code Means

Every GE dishwasher code explained on FixCodes, 3 in all. Together they cite 10 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
FTDFailure to Drain
FTD on a GE dishwasher (shown as F56 on some models) means failure to drain: the dishwasher could not pump the water out.
H2ONot Getting Enough Water
H2O (often read as H20) on a GE dishwasher means a low-water condition: the dishwasher isn't getting enough water, or any water, during the fill.
IHDelay Start Is Set (How to Cancel It)
IH on a GE dishwasher is really 1H, and it isn't a fault.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
