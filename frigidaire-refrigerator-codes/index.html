Frigidaire Refrigerator Error Codes: What Each Code Means

Every Frigidaire refrigerator code explained on FixCodes, 4 in all. Together they cite 16 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
CEControl Board Communication Error
CE on a Frigidaire refrigerator, usually shown as SY CE (or Er CE on some four-door models), means the display panel (user interface board) and the main control board…
Er FAWater Filter Authentication Error
Er FA on a Frigidaire refrigerator is not a cooling or defrost fault.
H1 / HIRefrigerator or Freezer Too Warm
If your Frigidaire refrigerator is flashing H1, it's really showing HI, the high-temperature alarm.
SY EF / 5Y EFEvaporator Fan Failure
SY EF on a Frigidaire refrigerator means Evaporator Fan Failure: the main control board has detected a problem in the freezer's evaporator fan circuit.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
