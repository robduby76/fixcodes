Whirlpool Oven F6 E1: Oven Over Temperature or Control Fault (Meaning, Causes, Fixes)

Reviewed 2026-10-22 · Based on 6 manufacturer & service sources

⚡ Quick answer

F6 E1 (F6E1) on a Whirlpool range or wall oven means the oven control has flagged a fault in its temperature-control system. On many Whirlpool ranges the service sheets define it as an oven over-temperature condition, and Whirlpool's owner help pages point to the main control (Appliance Manager) or its wiring. Start by turning the breaker off for one minute; if the code comes back, stop using the oven and have the sensor, wiring and control checked.

What the code means

Whirlpool's Product Help pages for ranges and wall ovens list F6 E1 as a possible problem with the Appliance Manager (the main oven control board), the Converter Control on some wall ovens, or the associated wiring, and their only owner fix is a one-minute power reset. Whirlpool's technician tech sheets are more specific. On ranges with the LCX control (tech sheet W10842026) and on models such as the WFG535S0JZ gas range (tech sheet W11333114), F6E1 is "Oven over temperature when heating." Tech sheet W11095707 adds that it sets when the oven temperature is above 601°F (316°C) and that the oven stays locked out until the control reads a temperature below that. On ranges with the Maxwell/MRC control (service manual W11174814), F6 E1 is "Over temp cook" and the listed fix is replacing the control. In practice the control either saw the oven really get too hot, which points to a heating relay stuck on, or it got a false high reading from the temperature sensor or its wiring. Because the meaning varies a little by control, check your model number against its tech sheet, usually found behind the lower kick panel or inside the control panel.

Likely causes

  • A temporary control glitch, for example after a power surge, that clears with a power reset
  • A loose or backed-out terminal at the oven sensor connector on the control board
  • A faulty oven temperature sensor (it should read about 1,000 to 1,200 ohms at room temperature)
  • Damaged wiring between the oven sensor and the control board
  • A failed main oven control (Appliance Manager) board, for example a bake or broil relay stuck on so the oven keeps heating
  • On some wall ovens, a problem with the Converter Control or the wiring between the controls

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. If the oven is hot or you smell burning, turn it off, keep the door closed and let it cool. Don't try to cook with it while the code is showing.
  2. Reset the power the way Whirlpool recommends: turn off the circuit breaker(s) for the oven for one minute, turn them back on, and watch the display for a minute to make sure F6 E1 doesn't come back.
  3. Run a normal Bake cycle at a moderate temperature with an oven thermometer inside. If the oven heats far past the set temperature or keeps heating after it should cycle off, turn it off at the breaker and call for service.
  4. If you're comfortable with basic electrical checks, unplug the range or switch off the breaker, remove the rear access cover, and make sure the oven sensor connector is fully seated. Whirlpool's tech sheets list a backed-out terminal at this connector as a first check.
  5. With power off, the sensor can be tested with a multimeter: about 1,000 to 1,200 ohms at room temperature is normal per Whirlpool's tech sheets. A reading far outside that range means the sensor should be replaced.

🛠 When to call a pro

  • F6 E1 comes back after the one-minute breaker reset.
  • The oven gets much hotter than the set temperature, or heats when it's supposed to be off. That points to a stuck relay on the control board and is a fire risk.
  • The sensor and its wiring test good. Whirlpool's tech sheets then call for replacing the control board.
  • The code appears during or right after Self-Clean. Some Whirlpool controls use a related over-temperature code for Clean, and a technician should read the fault history in Diagnostics mode.
  • The oven is under warranty. Contact Whirlpool (1-866-698-2538) or schedule service rather than opening it up.
