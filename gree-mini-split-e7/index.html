Code: E7🔧 Gree Mini Split

Gree Mini Split Error Code E7: Mode Conflict Between Indoor Units (Meaning, Causes, Fixes)

Reviewed 2026-10-24 · Based on 4 manufacturer & service sources

⚡ Quick answer

E7 on a Gree multi-zone mini split means mode conflict: two indoor heads are asking the one outdoor unit for modes it can't run at the same time, such as one room on cool and another on heat. Gree lists it as an operation status, not a hardware fault, so the fix is almost always just setting the heads to compatible modes.

What the code means

Gree's multi-zone service manuals (Multi21+, Free Match and Super Free Match) list E7 as mode conflict, also called mode shock. One outdoor unit can only cool or heat at a time, so the mode of the first indoor unit running becomes the base mode. If you then turn on another head in a conflicting mode, that head shows E7 and its indoor fan stops. Cooling and dry conflict with heating. Fan mode also conflicts with heating, but there heating always wins: if a head is in fan mode and another is switched to heat, the fan-mode head is the one that stops and shows E7, no matter which started first. If a head is on auto, Gree judges the conflict by the mode auto is actually running in. On Free Match units the indicator lamp blinks 7 times for E7. The single-zone Gree service manuals we checked (Jasmine, GoCool and console) don't list E7, so this code is a multi-zone one.

Likely causes

  • One indoor head is set to cool or dry while another is set to heat. The head turned on later shows E7 and its fan stops, per Gree's mode relationship table.
  • One head is in fan mode while another is heating. Heating takes priority, so the fan-mode head shows E7 even if it was running first.
  • A head left on auto has switched to heating (or cooling) and now conflicts with another head's fixed mode, since Gree judges auto by the mode it's actually running.
  • A schedule, timer or app setting on one head turns it on in a different mode from the others without anyone noticing.

Safe DIY checks

⚠ Before you start

E7 is a settings conflict, so the fix needs only the remote or app. Don't open the indoor or outdoor units to chase an E7; if a different code appears with it, leave electrical and refrigerant checks to a qualified technician.

  1. Check the mode on every indoor head served by the same outdoor unit, using each remote or the app.
  2. Set all running heads to the same season: all cooling or dry, or all heating. Fan mode can share with cooling or dry, but not with heating.
  3. If you want one room on fan only while the others heat, accept that the fan-mode head will stop with E7; turn it off instead.
  4. Turn the conflicting head off and back on in a compatible mode. E7 is an operation status, so it should clear once the modes no longer conflict.
  5. Avoid auto mode on one head while others are on fixed modes in shoulder seasons, and check timers or app schedules that start a head in a different mode.

🛠 When to call a pro

  • Confirm that every head on the outdoor unit is set to a compatible mode, including heads on auto, timers or app schedules, before suspecting anything else.
  • Read all stored codes. On Free Match units you can show the code on the indoor display by pressing the light button 6 times within 3 seconds, and the manual notes that multiple faults display in turn.
  • If E7 shows alongside real fault codes such as E6 (communication) or sensor errors, troubleshoot those first using the service manual flowcharts; E7 itself is listed as an operation status, not a hardware malfunction.
