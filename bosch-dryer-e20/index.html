Code: E20🌀 Bosch Dryer

Bosch Dryer E20 Error Code: Control Module Memory or Software Fault

Reviewed 2026-10-26 · Based on 4 manufacturer & service sources

⚡ Quick answer

E20 on a Bosch dryer is a control module fault: Bosch service material for WTMC dryers describes it as an EEPROM (memory) error or an invalid software update, and the dryer stops and can't be restarted. It isn't caused by lint or venting. Try one power reset of at least 5 minutes; if E20 comes back, the control module usually needs to be replaced or reprogrammed by a Bosch technician. Don't confuse it with E20 on a Bosch washing machine, which means unexpected heating.

What the code means

Bosch's public dryer error code guide doesn't list E20 by itself, so the meaning comes from Bosch service documentation for the US WTMC dryers. The fault table reproduced on Appliantology from Bosch's WTMC service material lists E:20 as an EEPROM error, with the solution 'replace faulty control module' and the effect that the dryer stops and can't be restarted. The neighbouring codes E:21 to E:26 in the same table are also control module faults (checksum, invalid update, model variant, software version, data table). MyPros+, quoting the Bosch WTMC8330US service manual p. 21, describes E:20 as control fault 1 (update invalid): the process software was set or programmed incorrectly. Both point to the same thing: the dryer's control electronics can't read or trust their own software or settings. That's why a lint, vent or hose fix won't clear it, and why the repair is board-level. Bosch's US guide says its other electronic fault codes (E06, E08, E09, E24, E25, E28, E36, E90) need an authorized technician, and the same applies here. Note that on a Bosch washing machine, E20 or F20 means something different: Bosch says it indicates unexpected heating. See also the related Bosch dryer pages for E24 and E90.

Likely causes

  • A control module EEPROM (memory) error (Bosch WTMC service fault table via Appliantology)
  • Process software set or programmed incorrectly, for example after an invalid software update (Bosch WTMC8330US service manual p. 21 via MyPros+)
  • A replacement control module that wasn't programmed to match the dryer (inferred from the 'update invalid' meaning; confirm with a technician)
  • A failed control module, which Bosch's service table lists as the fix (Bosch WTMC service fault table via Appliantology)

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Write down the exact code and your model number (E-Nr) from the rating label inside the door.
  2. Power reset: unplug the dryer or switch off its breaker for at least 5 minutes, then power it back on and try a short program.
  3. If the control board was replaced or reprogrammed recently, tell the technician who did it, since an invalid update can show as E20.
  4. If E20 returns, stop there. Bosch's service table says the dryer stops and can't be restarted, and the fix is the control module.

🛠 When to call a pro

  • E20 comes back after a power reset: call Bosch Customer Support at 1-800-944-2904 (US) or book an authorized technician, and give them your E-Nr.
  • Ask them to confirm the code in service test mode and check whether the control module can be reprogrammed before replacing it.
  • If a new control module is fitted, it must match your dryer's E-Nr and be programmed correctly, or a control fault code can return.
