Code: F13🧺 Hotpoint Dishwasher

Hotpoint Dishwasher Error Code 13 (F13): Main Board Fault

Reviewed 2026-10-26 · Based on 3 manufacturer & service sources

⚡ Quick answer

Error 13 (F13) on a Hotpoint dishwasher means the main control board has a fault. On models that show codes with lights instead of a display, it appears as LED 6, LED 8 and LED 9 on with LED 7 off. Hotpoint's fix is a replacement main board, and its advice is to book an engineer on 0344 822 4224. A power reset is worth one try first, but if F13 keeps coming back, the board is the part to replace. This code applies to UK and European Hotpoint dishwashers (Whirlpool EMEA, formerly Indesit Company), not the GE-made Hotpoint dishwashers sold in the US.

What the code means

Hotpoint UK's dishwasher error code guides (standard and integrated) list F13 as "Main board fault", with the LED pattern LED 6 on, LED 7 off, LED 8 on and LED 9 on, and the action is to call Hotpoint's customer service centre to book an engineer. Hotpoint's fault explanation for a failed main board is short: if the main board is not working, you will need to replace it, and Hotpoint links to its genuine spare parts shop for the replacement. On the integrated dishwasher guide's flashing-LED chart (the LED 1 to LED 5 layout used on some panels), the main board failure is shown as LED 1, 2 and 3. Indesit Service UK, Hotpoint's sister brand, lists F13 the same way (Main board fault, LED 6, 8 and 9 on) on its dishwasher code list, because both brands share the same electronics. Don't confuse F13 with F12 (LED 8 and 9 on only), which is a communication error between the main board and the display, or F09 (software error, main board not programmed).

Likely causes

  • A failed main control board, which is the only cause Hotpoint gives for F13 and why its fix is replacing the board
  • A one-off electronic glitch after a power cut or surge that a full power reset clears (general advice; if the code returns, treat it as a board fault)
  • Water or steam reaching the board from a leak, which can damage it (general repair background; an engineer checks for this before fitting a new board so the new one doesn't fail too)

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Check the lights: on light-only panels, LED 6, 8 and 9 on with LED 7 off is Hotpoint's F13 pattern. LED 8 and 9 alone is F12, a board-to-display fault, which is a different code.
  2. Switch the dishwasher off at the wall or the isolator switch, wait a few minutes, switch it back on and run a short program. This clears a one-off glitch on many machines (general advice, not a Hotpoint step for F13).
  3. Look under and around the machine for signs of a leak. If you find water, leave the machine off and mention it when you book the repair.
  4. If F13 comes back, stop there. The main board is inside the machine and is a mains-voltage repair, so call Hotpoint on 0344 822 4224 or book a qualified engineer.
  5. If you're ordering the board yourself for an engineer to fit, have the model and service number from the label on the edge of the door; boards are matched and programmed to the model.

🛠 When to call a pro

  • F13 returns after a power reset: Hotpoint's fix is a new main board, and an engineer can confirm it's the board and not a wiring fault before you pay for one.
  • There are signs of water, scorching or a burnt smell inside the door or base: something else may have damaged the board and needs fixing first.
  • The machine is under warranty: use Hotpoint's own service so the repair stays covered.
