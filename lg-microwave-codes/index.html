LG Microwave Error Codes: What Each Code Means

Every LG microwave code explained on FixCodes, 8 in all. Together they cite 24 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
AC1Auto Cook Bacon Setting, Not an Error
Ac-1 (often read as AC1 or AC-1) on an LG microwave is not a fault code.
E10Key Short on the Touch Panel
E10 (shown as E-10) on an LG microwave means a key short: the control has detected a button on the touch panel or keypad membrane that is stuck or electrically shorted.
F3Touch Panel or Key Fault
F3 on an LG microwave points to the touch button panel.
F4Humidity Sensor Error
F4 on an LG microwave is a humidity sensor error.
F5Damper Switch Error
F5 (shown as F-5) on an LG microwave is a damper switch error: the control board asked the vent damper to move and its switch never confirmed the new position.
F10Key Held or Shorted for Over a Minute
F10 (shown as F-10) on an LG microwave means the control has read a key on the touch panel as pressed for more than a minute, so a button is stuck down or shorted.
F11Inverter Communication Error

LOCChild Lock Is On (How to Unlock It)
LOC (or just L) on an LG microwave isn't a fault.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
