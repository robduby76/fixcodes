Goodman Furnace Error Codes: What Each Code Means

Every Goodman furnace code explained on FixCodes, 9 in all. Together they cite 21 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

Three short flashes then a pause on a Goodman furnace control board LED means the inducer (draft) blower is running but the pressure switch has not closed.

7P1 / 1DL (IdL)It's Really IdL (Idle)
If your Goodman or Amana furnace display seems to say 7P1, you're almost certainly reading IdL upside down.
A06Blower Airflow Readout, Not an Error
A06 on a Goodman or Amana variable-speed furnace isn't a fault.
b1 (B1)Blower Motor Communication Fault
A b1 code on a Goodman variable-speed gas furnace means the furnace control board has lost communication with the ECM circulator blower motor.
