LG Dishwasher Error Codes: What Each Code Means

Every LG dishwasher code explained on FixCodes, 7 in all. Together they cite 27 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
6E / bEIt's Really bE, Too Many Suds
LG doesn't list a 6E code.
AELeak Detected, Water in the Base
AE or E1 on an LG dishwasher means water got into the base pan under the tub and lifted the leak float switch.
CLControl Lock (Child Lock) Is On
CL on an LG dishwasher isn't a fault.
IENot Filling With Water
IE on an LG dishwasher is a water inlet error: the tub didn't get enough water.
LEWash Motor Error
LE on an LG dishwasher means the wash (cleaning) motor isn't running normally.
nEVario Motor (Spray Diverter) Error
An nE code on an LG dishwasher means the Vario system, the small motor and disk that switch the wash water between the spray arms, isn't turning or reporting its…
OEDishwasher Not Draining
OE on an LG dishwasher is a water outlet (drain) error: the tub didn't fully drain.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
