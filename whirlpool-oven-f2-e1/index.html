Whirlpool Oven F2 E1 Error Code: Stuck or Shorted Keypad (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 5 manufacturer & service sources

⚡ Quick answer

F2 E1 on a Whirlpool range or wall oven points to the keypad (touchpad). Whirlpool's service tech sheets call it a stuck key or a shorted keypad, meaning the control thinks a button is being held down. Start with Whirlpool's one-minute breaker reset, and on a range make sure nothing (like a wobbly or backwards grate) is resting on the controls. If F2 E1 keeps coming back, the usual fix is a new keypad, and the main control only if that doesn't solve it.

What the code means

In Whirlpool's error codes, the F number names the system and the E number names the part, and F2 is the keypad group. Whirlpool tech sheet W11393923A (ranges with the MRC control) lists F2 E0 as keypad disconnected, F2 E1 as stuck key and F2 E2 as a Cancel key error, and its fix for any F2 code is to replace the user interface (keypad membrane). Tech sheet W10842026 calls F2 E1 a shorted keypad and has the technician check the keypad's ribbon connection to the main control (connector P11) before replacing parts, keypad first and main control second. On some newer ranges with separate Start and Light buttons, Whirlpool's tech sheet W11202265 says F2 E1 means the Start or Light button has lost function, often because a button was pressed for too long. Whirlpool's Product Help pages for ranges and wall ovens say there may be a problem with the user interface or keypad, the control, or the associated wiring. Older Whirlpool oven controls used the F2 codes a little differently, so go by the tech sheet for your exact model.

Likely causes

  • A key that's being pressed or held down, for example by a pan, a towel, or on a range a grate that's sitting crooked or backwards (Whirlpool's range help page says to check the grates first)
  • A keypad (touchpad membrane) that has worn out or shorted internally, so the control reads a button as pressed all the time; Whirlpool's tech sheets list it as the most likely failed part
  • A loose, unplugged or damaged keypad ribbon cable where it plugs into the main control
  • On ranges with separate Start and Light buttons, a sticky button or a user interface board that has lost that button's function
  • Less often, a failed main control board, which Whirlpool lists after the keypad

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Make sure nothing is touching the control panel. On a range, Whirlpool says to check that the grates are installed correctly and level: when the range is cool, rock each grate corner to corner and side to side, and if it wobbles it may be in backwards, so try switching the grates. Then cycle power to clear the code.
  2. Do Whirlpool's reset: turn off the oven's circuit breaker(s) for one minute, turn them back on, and watch the display for one minute to make sure F2 E1 doesn't return. Then check that the oven works normally.
  3. Wipe the control panel with a barely damp cloth and dry it. Spills and grease around the keys can make a button stick.
  4. On models with physical Start and Light buttons, press each one after power comes back and listen for a tone. Whirlpool's tech sheet W11202265 says no tone means the button has lost function.
  5. If you're handy and the power is off at the breaker, you can remove the control panel cover and check that the keypad ribbon cable is fully seated in the main control and isn't cracked or torn. Whirlpool's tech sheet says to allow 60 seconds after power-up for the control to recognize the keypad.
  6. If the code keeps returning, replace the keypad (touchpad membrane), ordering it by your full model number. Whirlpool's tech sheet W10842026 only moves on to the main control if a new keypad doesn't fix it.

🛠 When to call a pro

  • F2 E1 comes back after the reset and you're not comfortable taking the control panel apart.
  • The oven turns on, beeps or changes settings by itself. Turn the breaker off and leave it off until it's checked.
  • A new keypad didn't clear the code, which points to the main control board.
  • The oven is a built-in wall oven that has to be pulled out to reach the controls, or it's still under warranty. Use Whirlpool's contact or schedule-service options instead of opening it.
