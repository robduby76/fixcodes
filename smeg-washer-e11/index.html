Code: E11🧺 Smeg Washer

Smeg Washing Machine E11 Error Code: Motor Control (Triac) Fault

Reviewed 2026-10-26 · Based on 4 manufacturer & service sources

⚡ Quick answer

E11 on a Smeg washing machine or washer dryer is a motor control fault: the electronics that switch the drum motor on and off (the motor triac on the main board) have shorted or gone open circuit. The drum usually stops turning or the programme stops part way through. Smeg UK puts E11 in the group of codes that need an engineer visit, so after one power reset the realistic fix is a check of the motor, its wiring and the main control board.

What the code means

Smeg UK's washing machine and washer dryer help page lists E11 among the codes (with E01-E04, E07-E11 and others) where you will need an engineer visit to resolve the issue. It doesn't describe the fault itself, but the service-level code tables do. Pacifica, a UK appliance repair network that covers Smeg, lists E11 as "motor control triac in short circuit or interrupted", and UK Whitegoods' table for Smeg washing machines and washer dryers from about 2003 on calls it a "motor triac short error" that can be a short circuit to the motor or the PCB. UK Whitegoods adds the detection rule: the board flags E11 when it sees more than 300 motor tacho signals a second while the drum should be turning at under 90 RPM, which means the motor is running faster than the board asked for because the switch that controls it is stuck on. In plain terms, the board has lost control of the motor. Neighbouring codes help narrow it down: E10 is motor over-current, E12 is a motor tacho (speed sensor) fault on these tables, and E13 is the door lock. Smeg's own help page lists E12 with water supply checks on some models, so codes do vary by generation; always go by the code your model's manual gives.

Likely causes

  • Motor control triac on the main control board shorted or open circuit (the fault the code describes)
  • Water or a burnt track on the main control board around the motor drive circuit
  • Short circuit in the drive motor or its wiring, which can also take out the triac
  • Loose, burnt or corroded connector between the motor and the main control board
  • Mains supply problem, which UK Whitegoods lists as the first check

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Turn the machine off, unplug it, wait about five minutes and plug it back in. If a one-off glitch caused E11, a fresh start of a short programme will run normally.
  2. Make sure the machine is plugged straight into a wall socket rather than an extension lead or adapter, since UK Whitegoods lists the mains supply as the first check.
  3. If there's water left in the drum, drain it through the pump filter flap before going any further, and take out any heavy waterlogged laundry.
  4. If E11 comes back, stop there and leave the machine unplugged: Smeg's instruction for E11 is an engineer visit, and the checks that follow need the back panel off near mains-voltage parts.
  5. Note the model and serial number from the label inside the door before you call, so the engineer can bring the right board or motor parts.

🛠 When to call a pro

  • E11 returns after a power reset, which per Smeg UK needs an engineer visit.
  • You smell burning or see scorch marks, or the drum spins wildly fast on its own.
  • The motor, its connector or the main control board needs testing or replacing, which means working near mains voltage.
  • The machine is under warranty: Smeg Service UK lists 0330 094 7779 for in-warranty repairs, and Smeg also has a find-an-engineer service for out-of-warranty machines.
