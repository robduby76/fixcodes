Frigidaire Refrigerator Er FA Error Code: Water Filter Authentication Error (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 5 manufacturer & service sources

⚡ Quick answer

Er FA on a Frigidaire refrigerator is not a cooling or defrost fault. It's the water filter authentication error used on refrigerators with the PurePour Connect system: the fridge couldn't confirm that a genuine, correct, unexpired filter is properly installed. Water and ice still dispense while the code shows. The fix is almost always the filter itself: reseat it until it clicks, or install a new genuine PurePour Connect filter of the type your model takes.

What the code means

Frigidaire's Use & Care guides for refrigerators with PurePour Connect authentication (Frigidaire lists models GRMC2273 and GRMG2272, which use the PurePour Connect PWF-2 filter) explain that the refrigerator contains a water filter authentication system meant to protect against counterfeit filters, and that using any other filter can cause an error (Er FA) to appear on the control display. Frigidaire lists four situations that trigger it: an authentic but expired filter is removed and reinserted, an authentic but incorrect filter is installed, a non-authentic filter is installed, or the filter is not installed properly. When that happens, the display may show the filter authentication error code and Replace Water Filter appears. Frigidaire says you can still use the dispenser while the error is showing. Pressing and holding Water Filter for 3 seconds dismisses (delays) the alert, but only twice: on the third appearance the code stays on the display until a new authentic filter is installed. After a correct filter goes in, Frigidaire says authentication can take up to 30 seconds, then the filter status updates on its own. Frigidaire's product page for the PurePour Connect filter describes the same thing: if a counterfeit or incorrect filter is installed, an error message appears on the control panel.

Likely causes

  • The filter isn't fully seated: it has to slide all the way in and click into the snap-in connector at the back of the housing (Frigidaire lists improper installation as a cause)
  • A non-genuine or counterfeit filter is installed, which the authentication system is designed to reject
  • A genuine Frigidaire filter of the wrong type for this model is installed (for example, a PurePour Connect PWF-1 in a refrigerator that takes the PWF-2)
  • An old, expired genuine filter was taken out and put back in, which Frigidaire says triggers the error
  • The error was dismissed twice already, so on the third appearance it stays on until a new authentic filter is installed

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Don't panic about the food: Er FA is a filter message, and Frigidaire says the dispenser still works while it shows. Check that the fridge and freezer feel cold as normal.
  2. Reseat the filter. The filter sits at the top right of the fresh food compartment. Turn off the ice maker, pull the filter cover forward so it drops down, push on the end of the filter to release it, then slide it back in until it stops and push firmly until you hear it click into the snap-in connector.
  3. Wait up to 30 seconds. Frigidaire says the authentication can take that long, and the filter status on the display updates by itself once it's done.
  4. Check what filter is installed. Frigidaire's guides say to reorder the same filter type that's in your refrigerator and name the PurePour Connect filter by model family, so confirm the filter type for your exact model number in your Use & Care guide or on Frigidaire.com.
  5. If the filter is old, generic or the wrong type, replace it with a new genuine PurePour Connect filter of the type your model takes. Remove the two clear plastic caps on the new filter's connector before sliding it in.
  6. After a new filter, close the cover, dispense into a glass while checking the housing for leaks (some sputtering is normal), and keep flushing for about 4 minutes, as Frigidaire directs. Then turn the ice maker back on.
  7. If you need water before you can get a new filter, press and hold Water Filter for 3 seconds to dismiss the alert. Frigidaire allows this twice; the third time, the code stays on until a new authentic filter is installed.

🛠 When to call a pro

  • Er FA stays on even after a new, genuine filter of the correct type has been installed, clicked fully into place and given the 30 seconds to authenticate.
  • The filter housing leaks, or the filter won't seat or lock into the connector.
  • Er FA appears together with other codes, or the refrigerator isn't cooling. Er FA on its own is a filter message, so a cooling problem points to a separate fault.
  • The refrigerator is still under warranty. Use the contact options on Frigidaire's owner support site to schedule service.
