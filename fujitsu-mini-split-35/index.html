Code: 35🔧 Fujitsu Mini Split

Fujitsu Mini Split Error Code 35: Manual Auto Button Error (Meaning, Causes, Fixes)

Reviewed 2026-10-24 · Based on 4 manufacturer & service sources

⚡ Quick answer

Error 35 (E:35) on a Fujitsu (Halcyon, Airstage) mini split is a MANUAL AUTO button error: the indoor unit has read its MANUAL AUTO button as pressed for 60 seconds or more in a row. It usually means the button is stuck in, held down by something, or has failed. Fujitsu's fix order is the button first, then the indoor indicator board, then the indoor main board.

What the code means

Fujitsu's service manuals list E:35 as "MANUAL AUTO button error (Indoor unit)" and say it's detected when the MANUAL AUTO button is on continuously for 60 seconds or more. The MANUAL AUTO button is the small button on the indoor unit used to run the system without the remote. On units without a wired remote, the indoor unit shows the error as 3 Operation light flashes and 5 Timer light flashes, with the Economy light flashing continuously. The Airstage ASEH07KJCAL service manual lists four possible causes: the button stays pressed, the button has failed, the indoor indicator PCB has failed, or the indoor main PCB has failed. Fujitsu's 410A mini-split troubleshooting guide describes the same 60-second condition and points technicians to a check of the button's on/off switching with a meter.

Likely causes

  • The MANUAL AUTO button on the indoor unit is stuck in or is being held down, for example by a front panel or cover that isn't seated right.
  • The MANUAL AUTO button itself has failed and reads as pressed even when it isn't.
  • A short circuit or corrosion on the indoor unit indicator PCB, the small board the button and lights sit on.
  • A failed indoor unit main PCB, which Fujitsu lists as the last cause once the button and indicator board check out.

Safe DIY checks

⚠ Before you start

Switch off power at the breaker before opening the indoor unit or removing the front panel to look at the button. Testing the button and replacing the indicator or main board is work for a licensed HVAC technician, since the indoor unit board carries line voltage.

  1. Turn the system off and look at the MANUAL AUTO button on the indoor unit. Make sure it isn't stuck in and that nothing (the front panel, a cover or an object) is pressing on it.
  2. If the panel was recently removed for cleaning, reseat it so it sits evenly and doesn't touch the button.
  3. Turn the system off at the breaker for a few minutes, then back on, and see whether the code returns. The error is set when the button reads as pressed for 60 seconds straight.
  4. Check for moisture or signs of water around the button area, since Fujitsu's manuals call out corrosion on the indicator board.
  5. If the button moves freely and the code comes back, call the installer or a licensed HVAC technician.

🛠 When to call a pro

  • The button stays pressed or doesn't switch on and off cleanly when tested with a resistance meter. Fujitsu says to replace the MANUAL AUTO button.
  • The button tests fine, or replacing it didn't help, and the indicator PCB shows a short or corrosion. Fujitsu's next step is replacing the indoor unit indicator PCB.
  • The code persists after the button and indicator PCB. Fujitsu's last step is replacing the indoor unit main PCB.
  • The system is new or under warranty. Contact the installer or Fujitsu General America technical support (866-952-8324) first.
