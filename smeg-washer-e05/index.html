Code: E05🧺 Smeg Washer

Smeg Washing Machine E05 (E5) Error Code: Water Supply, Heater or No Load (Depends on Model)

Reviewed 2026-10-28 · Based on 6 manufacturer & service sources

⚡ Quick answer

E05 (shown as E5 on some displays) doesn't mean the same thing on every Smeg washing machine. Smeg UK's own help page tells owners to check the water supply hose for kinks or blockages and clean the filters first. On older models such as the SWM65, the user manual says E05 means the heater or the heat sensor has failed. On many Smeg machines from about 2003 on, the service code tables list E5 as "no load", meaning the machine couldn't balance the laundry to spin. Check the error table in your own manual, try the hose and filter checks, and call an engineer if the code comes back.

What the code means

Smeg uses different code tables on different generations of washing machine, so E05 has three documented meanings. Smeg UK's washing machine and washer dryer help page puts E05 in a group with E06 and E12 and gives one instruction for all three: first check the water supply hose to make sure it isn't blocked or kinked, then check that the filters are clean and unblocked, and if that doesn't fix it, contact an engineer. That's the right first step on any Smeg because it's what Smeg itself says. The Smeg SWM65 user manual gives a model-specific meaning: E05, shown by the 2nd and 4th lights blinking, means "the heater of your machine or the heat sensor has failed", and the instruction is to shut the machine down, unplug it, turn off the tap and contact an authorised service agent. On the code family that UK Whitegoods lists for Smeg washing machines and washer dryers from about 2003 on, E5 is "washing machine has detected no load": the machine couldn't distribute the laundry well enough to spin safely, either because the load was unbalanced, too small or missing. UK Whitegoods says this is more information than a fault and clears when you restart. Pacifica, a UK repair network that covers Smeg, also lists E5 as "no load" on its Smeg table. Other Smeg manuals, such as the LBW50CIT, only list E01 to E04 and don't include E05 at all. Note the model number from the label inside the door and look up its manual on Smeg's site to see which table applies.

Likely causes

  • Water supply hose kinked, squashed behind the machine or blocked (Smeg UK's first check for E05)
  • Dirty or blocked filters, such as the mesh filter where the supply hose connects and the pump filter (Smeg UK's second check)
  • Tap not fully open or low mains water pressure
  • On SWM65-type models: a failed heating element or heat (temperature) sensor, per the user manual
  • On models using the 2003-on code table: a load the machine couldn't balance to spin, such as a single heavy item, a very small load, or an empty drum
  • On models using the 2003-on code table: the machine not standing level or rocking on its feet

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Turn the machine off and unplug it before touching anything. Look up your model's manual (model number is on the label inside the door) to see which E05 meaning applies.
  2. Make sure the tap is fully open, then pull the machine out and check the water supply hose along its whole length for kinks, crushing or blockage, as Smeg UK advises for E05.
  3. Turn the tap off, unscrew the supply hose at the back of the machine and rinse the small mesh filter at the inlet, then refit the hose hand-tight and check for leaks.
  4. Clean the pump filter behind the small flap at the bottom front. Put a towel and shallow tray down first, because water will come out.
  5. If the code appeared at the spin stage, open the door when it unlocks, spread the laundry out, add or remove items so the load isn't one heavy lump or nearly empty, and restart a rinse and spin. UK Whitegoods says the no-load E5 clears on restart.
  6. Check the machine stands level and doesn't rock; adjust the feet if needed.
  7. If you have an SWM65-type model where E05 means a heater or heat sensor failure, or the code comes back after these checks, stop there: Smeg's instruction is to unplug, turn off the tap and contact an authorised service agent.

🛠 When to call a pro

  • E05 comes back after the hose, filter and load checks, which per Smeg UK needs an engineer.
  • Your manual says E05 is a heater or heat-sensor failure (as on the SWM65), since testing those parts means working near mains voltage inside the machine.
  • The washes come out cold, or the machine trips the electrics when it heats.
  • The machine is under warranty: Smeg Service UK lists 0330 094 7779 for in-warranty repairs, and Smeg also has a find-an-engineer service for out-of-warranty machines.
