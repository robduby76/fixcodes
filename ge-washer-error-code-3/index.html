Code: 3🧺 GE Washer

GE Washer Error Code 3: Locked Rotor, Motor Not Turning (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 3 manufacturer & service sources

⚡ Quick answer

Error code 3 on a GE front-load washer is a locked rotor fault: for 5 seconds straight the control tried to spin the drum but didn't see any signal that the motor was turning. Either something is physically stopping the drum or motor, the motor overheated and its thermal cutoff tripped, or the motor speed (Hall) sensor signal isn't reaching the control. Start by unplugging the washer, checking that the drum turns freely by hand, and giving it about 45 minutes to cool before trying again. If it keeps coming back, the motor, Hall sensor wiring or a control board needs a technician.

What the code means

GE Appliances' Technical Service Guide 31-9327 for UltraFresh front-load washers lists fault code 3 as "Locked Rotor Monitor", with the trigger condition "For 5 straight seconds control not seeing signal changes indicating the motor is turning while trying to spin. Could mean the motor isn't rotating or control didn't get the signal because of lack of connection." GE's newer mini-manual 31-3000358 lists the same code 3 Locked Rotor Monitor with the same definition and checks. The Hall sensor is the part on the motor that reports how fast it's turning, so code 3 can mean a real jam, a motor that stopped, or a lost speed signal. The 31-9327 guide also says the motor has a thermal cutoff (TCO): if it's tripped, wait about 45 minutes for it to reset and make sure the motor moves freely. On these models stored codes are read in Consumer Fault Code Mode: from idle with all lights off, hold Start for 10 seconds until all lights come on, then press Start to step through the codes; a blinking dash means there are no more. This page covers GE front-load washers; GE top-load models use different code lists, so don't assume code 3 means the same thing there.

Likely causes

  • Something jamming the drum or motor, such as a sock, bra wire or other item caught between the drum and the tub
  • The motor overheated and its thermal cutoff (TCO) tripped, which GE says takes about 45 minutes to reset
  • A loose, unplugged or damaged Hall sensor connection, so the control never gets the motor speed signal
  • A bad Hall sensor on the motor
  • A failed motor winding, which GE's guide checks by measuring the resistance of each of the motor's three phases
  • A door lock problem, which GE's guide also lists as a check for this code
  • A failed inverter board or main board, which GE lists if the motor and sensor check out but the washer still won't spin

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Unplug the washer for a few minutes, then plug it back in and try a Drain & Spin cycle.
  2. If the washer was running a long or heavy cycle, leave it off for about 45 minutes so the motor's thermal cutoff can reset, as GE's service guide describes.
  3. With the washer unplugged and empty, turn the drum by hand. It should turn smoothly. If it binds, scrapes or won't turn, look around the drum and door seal for anything caught, and don't keep restarting it.
  4. Make sure the load isn't badly overloaded or one soaked heavy item, which makes the motor work harder.
  5. Check that the door closes and latches firmly, since GE's guide includes a door lock check for this code.
  6. Read the stored codes in Consumer Fault Code Mode (hold Start 10 seconds from idle) and note any other codes alongside 3 for your technician.

🛠 When to call a pro

  • The drum won't turn by hand, or turns with grinding or scraping, which can mean something is stuck between the drum and tub or a bearing problem.
  • Running the service mode spin test (test 14 in guide 31-9327, test 11 in mini-manual 31-3000358). GE says if the drum starts spinning normally and then stops after about 5 seconds, the Hall sensor is bad or disconnected; if it spins about 15 seconds, the Hall sensor is probably not the cause.
  • Checking the Hall sensor connection and position on the motor, and measuring the resistance of each motor winding.
  • Replacing the motor, inverter board or main board when the checks point to them.
  • Code 3 keeps coming back after the 45-minute cool-down even with a free-turning drum.
