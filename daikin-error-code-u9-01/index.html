Daikin Error Code U9-01: Another Indoor Unit on the System Has an Error (Meaning, Causes, Fixes)

Reviewed 2026-10-24 · Based on 3 manufacturer & service sources

⚡ Quick answer

U9-01 on a Daikin VRV or multi-indoor-unit system means the unit showing it is fine, but at least one other indoor unit on the same F1-F2 communication wiring has its own error (or the system has incompatible units connected). Daikin's fix is to find the indoor unit showing a different code and solve that one first. Check each indoor unit's remote or display, make sure none has lost power, and if you can't find the real code or U9-01 won't clear, have a Daikin-trained HVAC technician troubleshoot the system.

What the code means

Daikin's VRV IV+ heat pump service manual (ESIE18-14) lists U9-01 as "Other indoor unit has error," triggered by a system mismatch with non-compatible indoor units, or when at least one other indoor unit on the same F1-F2 wiring has an error. The code resets automatically once the cause is gone. Daikin's ventilation (VAM/EKVDX) service manual adds that a unit showing U9-01 keeps operating, while the related U9-02 means the unit stops, with the reset depending on the error at the other indoor unit. Daikin's own simplified malfunction-code list describes U9 as a transmission malfunction from another part of the system, naming a transmission error between other indoor and outdoor units, a defective expansion valve or circuit board in another indoor unit, and improper transmission wiring. In short, U9-01 is a pointer to a problem elsewhere, not a fault in the unit that shows it.

Likely causes

  • Another indoor unit on the same system has its own error code. Daikin lists this as the main trigger and says to solve that unit's code first.
  • An indoor unit has lost power or has a malfunctioning circuit board, so the outdoor unit counts fewer indoor units than it should. Daikin names a power blackout or faulty PCB on an indoor unit as a possible cause.
  • Non-compatible indoor units combined on one system, which Daikin calls a system mismatch.
  • A fault or break in the F1-F2 transmission (communication) wiring between the indoor units and the outdoor unit.
  • A faulty main circuit board in the outdoor unit, which Daikin's checklist tests after the indoor units and before the wiring.
  • A defective electronic expansion valve in another indoor unit, listed in Daikin's simplified U9 cause list.

Safe DIY checks

⚠ Before you start

VRV and multi-zone systems run on high-voltage power, often three-phase, and the field settings and board checks are meant for trained technicians. Don't open the outdoor unit, change field settings or work on the transmission wiring yourself; switch off the correct breakers and let a qualified HVAC technician handle anything past checking codes and power.

  1. Walk to every indoor unit and remote controller on the system and look for an error code other than U9-01. That other code is the real problem; look it up and troubleshoot it.
  2. Check that every indoor unit has power. A tripped breaker, switched-off disconnect or unplugged unit can make the outdoor unit lose track of it.
  3. If you find and fix the other unit's problem, give the system a few minutes. Daikin says U9-01 resets automatically.
  4. If the system was recently installed, expanded, or had an indoor unit swapped, tell your installer. Daikin says mixing non-compatible indoor units triggers this code.
  5. If no other unit shows an error and U9-01 keeps coming back, call a Daikin dealer or qualified HVAC technician rather than resetting it over and over.

🛠 When to call a pro

  • Following Daikin's order of checks: other indoor units' error codes, then the unit combination against the Daikin Databook combination table.
  • Counting connected indoor units with the outdoor unit's field setting (1-10 on VRV IV+) and, if fewer are detected than installed, finding the unit with a power loss or failed board.
  • Running the outdoor unit's forced fan operation (field setting 2-5 set to 1 on VRV IV+) to see which indoor unit doesn't respond.
  • Checking the outdoor unit's main circuit board, then testing the F1-F2 transmission line between the indoor units and outdoor unit.
  • Contacting the Daikin helpdesk if every check passes, as Daikin's service manual advises.
