Rheem Furnace Error Codes: What Each Code Means

Every Rheem furnace code explained on FixCodes, 9 in all. Together they cite 11 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
0Standby, No Call for Heat
A steady 0 (zero) on a Rheem or Ruud furnace's 7-segment display means standby: the furnace has power, has no active fault, and isn't getting a call from the thermostat.
11Failed Ignition
Code 11 on a Rheem (or Ruud) gas furnace with a two-digit display means Failed Ignition: the furnace tried to light the burners and the control never sensed a flame.
30Open Fuse on the Control Board
Code 30 on a Rheem or Ruud gas furnace means the small fuse on the furnace control board has blown.
57High Pressure Switch Open
Code 57 on a two-stage Rheem or Ruud gas furnace means the high pressure switch is open when it should be closed.
58Water Sensor Circuit Open
Code 58 on a Rheem or Ruud gas furnace means the control board can't see a complete water sensor circuit.
59Water Sensed in the Collector Box
Code 59 on a Rheem or Ruud condensing (90%+) gas furnace means "Water Sensed": the control board has detected water in the collector box where condensate is supposed to…
66Blower Cutback, Static Pressure Too High
Code 66 on a Rheem or Ruud variable-speed gas furnace means the blower motor has hit the top of its allowed speed or torque and still can't push the airflow the furnace…
68No Communications with the Blower Motor
Code 68 on a Rheem or Ruud communicating gas furnace means the furnace control board can't talk to the ECM blower motor.
93Internal Control Fault Detected
Code 93 on a Rheem or Ruud gas furnace with a two-digit display means "Internal Control Fault Detected." It's a critical fault: the furnace won't run in any mode until…

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
