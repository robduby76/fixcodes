P2610: ECM/PCM Internal Engine Off Timer Performance (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 2 cited source(s)

⚡ Quick answer

P2610 means the engine computer has a problem with its internal timer that measures how long the engine has been off between drives. OBD-Codes.com lists computer programming errors, a faulty engine computer, wiring or connector faults and a bad crankshaft position sensor as causes. RepairPal says it is typically an internal computer problem or a fault in the computer's power or ground circuit, and that low battery voltage can also set it.

🚨 Safety first

A flashing check engine light means a severe misfire: slow down and stop driving soon. A red brake or oil pressure warning needs immediate attention. Pull over safely and don't keep driving.

What P2610 means

The engine computer (called the ECM or PCM) keeps an internal timer that measures the time between when the engine is shut off and when it is started again. RepairPal says that measurement is used to evaluate emissions controls, and OBD-Codes.com says it also helps calculate fuel delivery, ignition timing and transmission shift patterns. The sources describe the failure a little differently. OBD-Codes.com says P2610 sets when the computer cannot tell that the engine has been shut off, or for how long, for example if it keeps seeing an engine speed signal or ignition voltage after the key is off. RepairPal's page gives two explanations: in one place that the computer stayed awake too long or not long enough after shutdown to run its emissions self-tests, and in another that the processor could not access the timer. RepairPal also calls the code "Control Module Ignition Off Timer Performance". They also differ on causes: OBD-Codes.com includes the crankshaft position sensor and its wiring, while RepairPal says the code can only be caused by the computer or its circuit.

Severity: can I keep driving?

Drive with caution, fix soon

Get it checked soon. RepairPal rates P2610 as Urgent, and OBD-Codes.com says it should be addressed with some urgency because the engine-off timer feeds fuel, ignition timing and shift calculations. Most cars drive normally at first, so it is usually safe to drive to a shop, but don't ignore it: OBD-Codes.com says drivability problems can show up later, and an unresolved code can keep you from passing an emissions inspection.

Common symptoms

  • Check engine light on (RepairPal, OBD-Codes.com)
  • Often no obvious symptoms at first (OBD-Codes.com)
  • Reduced engine performance (OBD-Codes.com)
  • Lower fuel economy (OBD-Codes.com)
  • Drivability problems may develop over time (OBD-Codes.com)

Likely causes

Roughly most to least common, based on the sources below. Your vehicle may differ.

  1. An internal engine computer problem (RepairPal, OBD-Codes.com)
  2. Engine computer programming errors or outdated software (OBD-Codes.com, RepairPal)
  3. A problem with the engine computer's power or ground circuit (RepairPal)
  4. Low battery voltage (RepairPal)
  5. Open or shorted wiring or connectors (OBD-Codes.com)
  6. A faulty crankshaft position sensor or shorted sensor wiring (OBD-Codes.com)

Diagnostic steps you can do

⚠ Before you start

Work on a cool engine, parked on level ground with the parking brake set. Never work under a car supported only by a jack.

  1. Check the battery and charging system first; RepairPal says low battery voltage can set this code.
  2. Read and write down all stored codes and freeze frame data. If crankshaft position sensor codes are also set, OBD-Codes.com says to fix those before P2610.
  3. Clear the code and drive normally to see whether it comes back; RepairPal notes the engine computer can have one-off glitches.
  4. With a scan tool showing live data, check engine RPM with the key on and the engine off. OBD-Codes.com says anything other than 0 points to the crankshaft position sensor or its wiring.
  5. Inspect the engine computer's connectors, power and ground wiring for corrosion, damage or loose connections.
  6. Check for technical service bulletins and software updates for your vehicle.

Typical fixes

  • Charge or replace a weak battery, or repair a charging problem, then clear the code (RepairPal)
  • Update (reflash) the engine computer software with the manufacturer's latest calibration (RepairPal, OBD-Codes.com)
  • Repair open or shorted wiring, connectors, or the computer's power and ground circuits (RepairPal, OBD-Codes.com)
  • Replace a faulty crankshaft position sensor or repair its wiring (OBD-Codes.com)
  • Replace the engine computer only after everything else checks out; it usually needs programming to the vehicle (RepairPal, OBD-Codes.com)

Repair costs vary widely by vehicle, region, parts brand and shop, so we don't quote prices. Get a written estimate after diagnosis.

🛠 When to call a pro

  • The code comes back after you clear it and the battery tests good
  • Other engine computer codes such as P0606 are set too
  • The engine computer needs a software update or replacement, which usually takes dealer-level programming tools
  • You notice stalling, poor performance or shifting problems

FAQs

Is P2610 serious?

RepairPal rates it Urgent, and OBD-Codes.com says to address it with some urgency. Most cars run normally at first, but OBD-Codes.com says performance and fuel economy can suffer, so get it diagnosed soon.

Can a weak battery cause P2610?

Yes. RepairPal says low battery voltage can set P2610, so test the battery and charging system before suspecting the engine computer.

Does P2610 mean I need a new engine computer?

Not necessarily. Both sources say to check the battery, wiring, power and ground circuits and software updates first, and OBD-Codes.com adds the crankshaft position sensor. Replacing the computer is the last step.

How much does it cost to fix P2610?

Neither source gives a repair cost. It ranges from a battery or software update to wiring repair or an engine computer replacement, so get a diagnosis and a written estimate.
