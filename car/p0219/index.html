P0219: Engine Overspeed Condition (Meaning, Causes, Fixes)

Reviewed 2026-10-26 · Based on 2 cited source(s)

⚡ Quick answer

P0219 means the engine computer has seen the engine spinning faster than its maximum allowed RPM. OBD-Codes.com says it is often caused by the engine actually being over-revved, but a faulty crankshaft, camshaft or transmission speed sensor, wiring, or the PCM can also set it. RepairPal rates it 'Moderate' and says a PCM software update is a common fix.

🚨 Safety first

A flashing check engine light means a severe misfire: slow down and stop driving soon. A red brake or oil pressure warning needs immediate attention. Pull over safely and don't keep driving.

What P0219 means

The engine computer (PCM) watches engine speed using the crankshaft position sensor, the camshaft position sensor and the transmission speed sensors. OBD-Codes.com explains that when RPM goes over the maximum limit, most engines first use a rev limiter, cutting fuel injector pulses and/or retarding ignition timing to bring the RPM down. If the PCM can't bring RPM back to an acceptable level within a set time, it stores P0219 and may turn on the check engine light. RepairPal adds that the PCM may put the vehicle into limp home mode to protect the engine, and that setting this code may void the vehicle's warranty, because the PCM records that the engine was over-revved. The code is generic to OBD-II vehicles, but repair steps vary by make and model. Search interest shows people look it up most for Ford vehicles, so check technical service bulletins (TSBs) for your vehicle.

Severity: can I keep driving?

Drive with caution, fix soon

Get it checked soon. RepairPal rates P0219 'Moderate', meaning it may not threaten safety right away but should be diagnosed within a reasonable time. OBD-Codes.com is a little more cautious: because over-revving can cause catastrophic engine damage, it says the code should be addressed with some urgency. Until it's checked, avoid revving the engine hard, and on a manual transmission don't downshift into a gear that sends the RPM past the red line.

Common symptoms

  • Check engine light on
  • Often no drivability symptoms at all (OBD-Codes.com)
  • Reduced power from limp home mode (RepairPal)
  • The engine may be allowed to over-rev repeatedly (OBD-Codes.com)
  • Knock sensor activity or knock sensor codes (OBD-Codes.com)
  • Clutch slipping on manual transmission vehicles (OBD-Codes.com)

Likely causes

Roughly most to least common, based on the sources below. Your vehicle may differ.

  1. The engine was over-revved, on purpose or by accident, for example a missed shift on a manual transmission (OBD-Codes.com)
  2. Faulty crankshaft position (CKP) or camshaft position (CMP) sensor (OBD-Codes.com)
  3. Faulty transmission input or output speed sensor (OBD-Codes.com)
  4. Open or shorted wiring in the CKP, CMP or transmission speed sensor circuits (OBD-Codes.com)
  5. PCM software that needs updating (RepairPal's only listed cause)
  6. A faulty PCM or a PCM programming error (OBD-Codes.com, only after the other causes are ruled out)

Diagnostic steps you can do

⚠ Before you start

Work on a cool engine, parked on level ground with the parking brake set. Never work under a car supported only by a jack.

  1. Think back to whether the engine was revved hard, redlined, or downshifted into too low a gear. OBD-Codes.com says this is the first thing to rule out, especially on manual transmissions.
  2. On a manual transmission, check whether the clutch slips (the RPM jumps without the car speeding up). OBD-Codes.com says the clutch should be working properly before you diagnose this code.
  3. Read all stored codes and freeze frame data and write them down, especially any crankshaft, camshaft or transmission speed sensor codes.
  4. Look up technical service bulletins and open safety recalls for your year, make and model. RepairPal lists a PCM software update as a common fix, which a dealer can check for.
  5. Clear the code and drive normally without high revs. If it does not come back, OBD-Codes.com's approach suggests it was a one-time over-rev; if it comes back, the sensors and wiring need testing.

Typical fixes

  • No repair may be needed if the code came from a one-time over-rev and does not return
  • Update the PCM software if a manufacturer update applies
  • Repair a slipping clutch on manual transmission vehicles
  • Replace a faulty crankshaft, camshaft or transmission speed sensor
  • Repair open, shorted or corroded wiring and connectors in the speed sensor circuits
  • Repair or reprogram the PCM if testing points to it

Repair costs vary widely by vehicle, region, parts brand and shop, so we don't quote prices. Get a written estimate after diagnosis.

🛠 When to call a pro

  • OBD-Codes.com's test sequence when the code resets: test the CKP, CMP and transmission speed sensors with a multimeter and oscilloscope per the factory procedure; check reference voltage and ground at each sensor connector; disconnect the related controllers and check circuit resistance and continuity; suspect the PCM or its programming only when everything else is within specification.
  • The sources disagree on causes and urgency: RepairPal lists only a PCM software update as a common cause and rates the code 'Moderate', while OBD-Codes.com lists driver over-revving, sensor and wiring faults and the PCM, and says it should be addressed with some urgency because over-revving can do catastrophic damage.
  • RepairPal notes the code may void the vehicle's warranty, so if the engine was never over-revved and the vehicle is under warranty, ask the dealer to check for a software update or a false speed signal before accepting a warranty denial.

FAQs

Can I drive with P0219?

Usually yes, gently. RepairPal rates it 'Moderate' and OBD-Codes.com says there are often no drivability symptoms. But avoid high revs until it's checked, because over-revving can seriously damage the engine, and the car may be in limp mode with reduced power.

What usually causes P0219?

OBD-Codes.com says the first thing to rule out is the engine actually being over-revved, such as a missed shift on a manual transmission. Faulty crankshaft, camshaft or transmission speed sensors, wiring problems and the PCM can also set it. RepairPal lists a PCM software update as the common fix.

Can P0219 void my warranty?

RepairPal says setting this code may void the vehicle's warranty, because it shows the engine was spun past its limit. If you didn't over-rev the engine, a faulty sensor or software problem may have set it, so ask the dealer to diagnose it.

Will P0219 clear on its own?

If the code was set by a one-time over-rev and nothing is wrong, clearing it and driving normally should keep it off, per OBD-Codes.com's approach. If it keeps coming back, something like a speed sensor or the PCM needs to be checked.
