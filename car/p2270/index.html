P2270: O2 Sensor Signal Stuck Lean (Bank 1 Sensor 2) (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 3 cited source(s)

⚡ Quick answer

P2270 means the engine computer sees the oxygen sensor after the catalytic converter on Bank 1 (sensor 2) stuck at, or leaning toward, a lean reading. OBD-Codes.com says the most common fixes are an exhaust leak, a wiring problem, or the sensor itself; RepairPal and OBD-Codes.com also list fuel and vacuum problems and, less often, a failed engine computer.

🚨 Safety first

A flashing check engine light means a severe misfire: slow down and stop driving soon. A red brake or oil pressure warning needs immediate attention. Pull over safely and don't keep driving.

What P2270 means

OBD-Codes.com explains that P2270 refers to the post-catalytic converter oxygen sensor on Bank 1, sensor 2. This downstream sensor is used to monitor how well the catalytic converter is working. When the powertrain control module (PCM) sees this sensor's signal stuck lean or biased lean (reading as though there is too much air in the exhaust), it sets P2270. Bank 1 is the side of the engine with cylinder 1; on 4-cylinder engines there is only one bank. Ford may call this sensor the Catalyst Monitor Sensor. OBD-Codes.com describes P2270 as a generic OBD-II code for 1996 and newer vehicles (brands such as Chevy, Subaru, GMC, Ford, Mini, VW and Mazda) and notes it is very similar to P2195. Note on sources: RepairPal's page describes the sensor as the one between the engine and the catalytic converter and says it should fluctuate at least 10 times per second. That describes the upstream sensor, while the code's own title (and OBD-Codes.com and KBB) name Bank 1 Sensor 2, which sits after the converter, so this page follows the Sensor 2 description. KBB's page also describes lean as too low in oxygen, which is the reverse of the usual meaning (lean means extra oxygen in the exhaust), so that wording is not repeated here. P2271 is the matching stuck-rich code for the same sensor, and P2272 is the stuck-lean code for Bank 2 Sensor 2.

Severity: can I keep driving?

Drive with caution, fix soon

Get it diagnosed soon. RepairPal rates P2270 Moderate, meaning it may not threaten safety right away but should be checked within a reasonable time. KBB says these codes typically aren't very serious for driving safety but will usually cause you to fail an emissions test. If the engine runs rough, misfires, or the check engine light flashes, keep driving to a minimum and get it checked, since those point to a bigger problem than the sensor.

Common symptoms

  • Check engine light on (OBD-Codes.com, KBB)
  • Often no drivability problem, since this is not the upstream sensor (OBD-Codes.com, KBB)
  • Engine may run rough in some cases (OBD-Codes.com)
  • Decreased engine performance and increased fuel consumption (RepairPal)
  • Likely emissions test failure (KBB)

Likely causes

Roughly most to least common, based on the sources below. Your vehicle may differ.

  1. Contaminated or failed Bank 1 Sensor 2 oxygen sensor (OBD-Codes.com, RepairPal, KBB)
  2. Exhaust leak near the oxygen sensor (OBD-Codes.com)
  3. Sensor wiring or circuit problem (OBD-Codes.com, RepairPal, KBB)
  4. Loosely installed sensor (OBD-Codes.com)
  5. Vacuum leak (RepairPal)
  6. Incorrect fuel pressure or a faulty fuel injector (OBD-Codes.com)
  7. Engine coolant leak or faulty purge solenoid valve (OBD-Codes.com)
  8. Failed engine computer (PCM) (OBD-Codes.com, RepairPal)

Diagnostic steps you can do

⚠ Before you start

Work on a cool engine, parked on level ground with the parking brake set. Never work under a car supported only by a jack.

  1. Read and write down all stored codes; OBD-Codes.com says to fix multiple codes in the order they appear.
  2. Inspect the downstream sensor wiring and connectors for corrosion, rubbed or chafed wires, bent or loose pins, burnt spots or crossed wires (OBD-Codes.com).
  3. Look and listen for exhaust leaks near the sensor and repair them (OBD-Codes.com).
  4. Make sure the sensor is tight in its bung, since a loose sensor is a listed cause (OBD-Codes.com).
  5. Check for technical service bulletins (TSBs). OBD-Codes.com mentions Ford TSB 14-0084 (some 2010-2012 F-150, Navigator, Ranger, E-Series and others, sensor replacement for P2270 or P2272) and Chrysler bulletin 18-011-08 (certain 2008-2010 Compass, Patriot, Sebring, Avenger and Caliber, PCM reprogram).

Typical fixes

  • Repair an exhaust leak near the sensor
  • Repair damaged sensor wiring or connectors
  • Replace the Bank 1 Sensor 2 oxygen sensor if testing confirms it; OBD-Codes.com recommends an OEM (manufacturer brand) sensor
  • Repair a vacuum leak, fuel pressure, injector, purge valve or coolant leak problem if testing points there
  • Reprogram the PCM where a manufacturer bulletin calls for it

Repair costs vary widely by vehicle, region, parts brand and shop, so we don't quote prices. Get a written estimate after diagnosis.

🛠 When to call a pro

  • Checking the sensor needs a scan tool with live data: OBD-Codes.com says the rear sensor normally fluctuates between 0 and 1 volt on a warm engine in closed loop, and with P2270 it is likely stuck near 0 V; revving the engine should make it react
  • Harness resistance checks need a digital volt-ohm meter and the manufacturer's specifications (OBD-Codes.com)
  • Fuel pressure testing at the fuel rail, injector and purge valve checks, and inspecting coolant passages for leaks (OBD-Codes.com)
  • If you remove the sensor, OBD-Codes.com says to inspect it for fuel, oil or coolant contamination, which points to an engine problem to fix first
  • The code returns after you fix wiring and exhaust leaks

FAQs

Is P2270 serious?

Usually not for driving safety. RepairPal rates it Moderate, and KBB says it typically isn't very serious to drive with but will usually fail an emissions test. Get it diagnosed soon, and sooner if the engine runs rough.

Where is Bank 1 Sensor 2?

It's the oxygen sensor after the catalytic converter on the side of the engine with cylinder 1 (OBD-Codes.com). On a 4-cylinder engine there's only one bank, so it's simply the sensor after the converter.

Should I just replace the oxygen sensor?

Not before checking. OBD-Codes.com says the most common fixes are an exhaust leak, a wiring problem or the sensor itself, so check for leaks and wiring damage and confirm the sensor is stuck with live data before buying one.

What's the difference between P2270 and P2195?

OBD-Codes.com says they are very similar. P2195 is a stuck-lean code for Bank 1 Sensor 1, the upstream sensor before the converter, while P2270 is for Sensor 2, after the converter.

How much does it cost to fix P2270?

None of the sources give a repair cost. It can range from fixing an exhaust leak or wiring to replacing the oxygen sensor, so get a diagnosis and a written estimate first.
