U0422: Invalid Data Received From Body Control Module (Meaning, Causes, Fixes)

Reviewed 2026-10-24 · Based on 4 cited source(s)

⚡ Quick answer

U0422 means a control module received data from the body control module (BCM) that it considers invalid, such as a fault or unknown value instead of a real one. It is not the same as lost communication (that is U0140). Common causes are network (CAN bus) problems, bad BCM connectors or wiring, a BCM fault, or on some GM models a harmless startup timing glitch.

🚨 Safety first

A flashing check engine light means a severe misfire: slow down and stop driving soon. A red brake or oil pressure warning needs immediate attention. Pull over safely and don't keep driving.

What U0422 means

Modern cars pass information between computers over a data network. The body control module (BCM) runs things like lights, locks and door switches and shares their status with other modules. RepairPal defines U0422 as Invalid Data Received From Body Control Module. U0422 is stored by the module that received the bad data, not by the BCM, so the first step is finding out which module stored it. The sources show how much that varies. In Ford's 2024 Bronco Raptor service manual, the power steering control module (PSCM) sets U0422:00 when it receives a 'fault' or 'unknown' message from the BCM instead of valid information, while monitoring the high-speed CAN network with more than 10 volts supplied. Ford says this points to a power mode message problem, that the module reporting the code is not the problem module, and not to install a new power steering assembly for it. Ford's 2019 Super Duty information says the steering angle sensor module sets U0422 when it gets invalid data in the BCM's personality (configuration) message. GM bulletin 16-NA-407 explains that on some 2017-2018 Buick LaCrosse, Cadillac XT5, Chevrolet Bolt EV, Chevrolet Equinox and GMC Terrain models, heavy network traffic at startup can make the BCM mark the door switch signal unavailable, and the chassis control module sets U0422 after 1 second. GM says to ignore that stored code unless it is current or comes with BCM codes U1534 or U1538. RepairPal does not list specific causes or symptoms for U0422.

Severity: can I keep driving?

Drive with caution, fix soon

Get it checked soon. RepairPal rates U0422 Moderate, meaning it may not threaten safety right away but should be diagnosed in a reasonable time. How much it matters depends on which module stored it. GM says a stored (history) U0422 on some 2017-2018 models needs no service at all, while on a Ford Bronco the power steering module stores it when it gets bad power-mode data from the body control module. If a steering, brake or other warning comes on with it, or body features act up, have it diagnosed before relying on the car.

Common symptoms

  • Often no symptom; the code may only be stored in the module's history (GM bulletin 16-NA-407)
  • A warning light or message from the module that stored it, such as power steering or stability control, depending on the vehicle
  • Other network (U) codes or BCM codes stored at the same time
  • Note: the generic engine-code scanners many people own may not read U0422 at all, because it is often stored in body or chassis modules

Likely causes

Roughly most to least common, based on the sources below. Your vehicle may differ.

  1. A problem on the high-speed CAN data network (Ford Bronco manual)
  2. A fault in the body control module itself (Ford Bronco manual)
  3. Corroded, bent, pushed-out or spread pins at the BCM or gateway module connectors, or an intermittent connection (Ford Super Duty information)
  4. Other BCM or gateway module faults that make the BCM send bad data; Ford says to diagnose all BCM and gateway codes first
  5. On some 2017-2018 GM models, a startup timing condition with the door switch status that needs no repair unless the code is active or BCM codes U1534 or U1538 are also set (GM bulletin 16-NA-407)
  6. The sources differ: Ford's power steering procedure points to the network or the BCM and says not to replace the power steering assembly, while GM says a stored code on the listed models can simply be ignored

Diagnostic steps you can do

⚠ Before you start

Work on a cool engine, parked on level ground with the parking brake set. Never work under a car supported only by a jack.

  1. Use a scan tool that reads all modules (body, chassis and steering, not just the engine) and note which module stored U0422 and what other codes are present.
  2. Check whether the code is current or only stored in history. On the GM models in bulletin 16-NA-407, a history-only U0422 with no BCM codes U1534 or U1538 needs no service.
  3. Fix any BCM, gateway or other network codes first, as Ford's procedure directs.
  4. With the ignition off, look for corrosion or water at the BCM connectors if you can reach them safely.

Typical fixes

  • Repair the network (CAN bus) fault or BCM-related wiring and connectors found during testing
  • Diagnose and repair the BCM or gateway codes that caused the bad data
  • Repair or replace the BCM only after testing points to it
  • On the GM models covered by bulletin 16-NA-407, clear and ignore a stored code that is not active and has no BCM codes U1534 or U1538 with it

Repair costs vary widely by vehicle, region, parts brand and shop, so we don't quote prices. Get a written estimate after diagnosis.

🛠 When to call a pro

  • A power steering, brake or stability warning is on with U0422
  • The code keeps coming back as current or several modules report network codes
  • Network testing needs a full-system scan tool and the vehicle's wiring diagrams
  • Don't replace the module that stored the code for U0422 alone; Ford's power steering procedure specifically says not to install a new power steering assembly for this code

FAQs

Is U0422 serious?

RepairPal rates it Moderate. It depends on which module stored it. On some GM models a stored U0422 needs no service, but if it comes with a steering or brake warning, get it checked soon.

Is U0422 the same as U0140?

No. U0140 means a module lost communication with the BCM. U0422 means it is still hearing from the BCM but the data it got was invalid, such as a 'fault' or 'unknown' message.

Does U0422 mean my BCM is bad?

Not necessarily. Ford lists a network problem or the BCM as possible sources and says to check connectors and other BCM codes first. GM documented a startup timing glitch that sets it with nothing wrong.

Why can't my basic scanner see U0422?

U0422 is often stored in a body, chassis or steering module, which many basic engine-code readers can't access. You need a scan tool that reads all modules.

How much does it cost to fix U0422?

None of the sources gives a repair cost. It can range from nothing (a stored code GM says to ignore) to network wiring repair or a BCM, so get a diagnosis and a written estimate first.
