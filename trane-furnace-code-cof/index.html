Trane Furnace Code COF: Continuous Fan Readout, Not an Error (What It Means)

Reviewed 2026-10-23 · Based on 1 manufacturer & service sources

⚡ Quick answer

COF on the three-digit display of a Trane furnace control board is not an error code. It means Continuous Fan: the thermostat is asking for the blower to run on its own, with no heating or cooling call. While it's running, the display alternates every 2 seconds between COF, ARF (airflow) and a three-digit number, so COF, ARF, 070 means the blower is moving about 700 CFM. COF also appears as a setup menu item that sets how strong the continuous fan runs. Real faults show up as an E code flashing in the rotation.

What the code means

Newer Trane variable-speed gas furnaces (for example the S8V2 2-stage models) have an integrated furnace control (IFC) with a seven-segment display. Trane's installation, operation and maintenance manual (FNR-SVX003A-EN) lists COF in its Status Codes column as "Continuous Fan", alongside IdL (idle), Ht1 and Ht2 (gas heat), CL1 and CL2 (cooling), HP1 and HP2 (heat pump) and dFt (defrost). Its system status menu defines COf as "Demand for continuous fan" and shows the example COF, ARF, 070: the status alternates between the system mode and the airflow request every 2 seconds, and the number is multiplied by 10 for actual airflow. If an error occurs, an E code flashes alternately with the mode and airflow, so COF on its own means the furnace is healthy and simply running the blower. Separately, the control's menu has a COF item, described in the display-code table as "Blower Constant Fan Airflow Multiplier %", which sets continuous-fan airflow as a percentage (the manual's chart shows 25, 50, 75 and 100) and carries the note "Do not adjust COF above 75%."

Likely causes

  • Normal operation: the thermostat's fan is set to On (or a fan circulate schedule is running), so the furnace runs the blower without heating or cooling
  • The number shown after ARF is the continuous-fan airflow divided by 10 (070 = 700 CFM), not a fault number
  • You may be looking at the COF setup menu item (continuous fan airflow percentage) if someone pressed the Menu button on the control board
  • If an E code (E3.1, E4.0 and so on) also flashes in the sequence, that E code is the actual fault to look up

Safe DIY checks

⚠ Before you start

Turn off power at the furnace/HVAC service switch and the breaker before opening panels. Shut the gas valve before any work near the burners, and never disconnect or alter the gas line. If you smell gas, leave the house and call your gas utility.

  1. Watch the display for 10 to 15 seconds through the sight glass. If it cycles only through COF, ARF and a number, the furnace is reporting normal continuous-fan operation and nothing needs fixing.
  2. If you don't want the blower running all the time, set the thermostat fan from On to Auto. The display should go back to IdL (idle) until the next heating or cooling call.
  3. If the fan is too loud or too strong on continuous, that's controlled by the COF airflow percentage in the control menu. Trane says not to set it above 75%; if you're not comfortable with the Menu and Option buttons, have a technician change it.
  4. If an E code appears in the rotation, write it down exactly (for example E4.0) and look that code up instead. The Err menu shows active errors and the L6F menu shows the last 6 faults.
  5. If the display shows COF but the blower isn't actually running, or you hear it running with the thermostat fan on Auto, turn the thermostat off and see whether the display changes, then call a technician if the blower behavior doesn't match the display.

🛠 When to call a pro

  • An E code keeps appearing alongside the COF readout, or the furnace locks out.
  • The continuous-fan airflow (COF percentage) needs adjusting and you're not comfortable working inside the furnace with the panel off. Trane offers a Diagnostics mobile app for its furnaces, and in communicating mode the app is required.
  • The blower keeps running with the thermostat fan on Auto and no heating or cooling call, or won't run at all on a fan call.
  • The system is communicating (Link) rather than 24-volt; Trane's manual says the Menu and Option buttons are disabled in communication mode and the diagnostics app must be used.
