Maytag Oven F1 E1 Error Code: Oven Control Board Fault (Meaning, Causes, Fixes)

Reviewed 2026-10-25 · Based on 5 manufacturer & service sources

⚡ Quick answer

F1 E1 (F1E1) on a Maytag range or wall oven points to the electronic oven control, not to a heating element or the door. Maytag's own help pages say there may be a problem with the oven control or its wiring and tell you to do a one-minute breaker reset. If F1 E1 comes back after that reset, the usual fix is a new oven control board, ordered by your full model number.

What the code means

Maytag's Product Help page for ranges says F1 E1 means there may be a problem with the Oven Control or the associated wiring. For wall ovens, Maytag names the Oven Appliance Manager Control (the main oven control board) or the associated wiring. Maytag's technician tech sheets, as indexed by MyPros+, describe it in more detail, and the exact wording depends on which control your oven has. On ranges with the older 4-digit LCC electronic control (tech sheet W10357516) and on newer ranges covered by tech sheet W11326821, F1E1 is listed as an internal board failure or A/D error, meaning the board's own circuit that converts sensor readings into numbers has failed its self-check. On some wall ovens and oven combos (tech sheet W10796081, for example model MEW9527FB), F1E1 is listed as Upper RTD Uncalibrated, meaning the control doesn't have valid calibration data for the upper oven temperature sensor. That's still a control fault, which is why Maytag's wall-oven help page points to the control rather than the sensor. Either way, every F1 code on these sheets is a control-board code. A plain F1 or a dashed F1-1 to F1-9 code on older Maytag ranges is a different family, covered on our Maytag oven F1 page, and F1 E0 has its own page too.

Likely causes

  • A temporary glitch in the oven control after a power surge, brownout or outage, which Maytag's one-minute breaker reset clears
  • A failed electronic oven control board (internal board failure or A/D error on range controls), which is what Maytag's service literature points to when the code keeps coming back
  • On some wall ovens, the control reporting that its upper oven sensor calibration data is missing or invalid (Upper RTD Uncalibrated), which is still a control-board problem
  • A loose, damaged or burned wiring connection at the control board, which Maytag's help pages list alongside the control itself

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Turn off the oven's circuit breaker(s) for one minute, turn them back on, and watch the display for one minute. If F1 E1 doesn't come back, run a short bake to make sure the oven heats normally. This is Maytag's own reset.
  2. If the code comes right back, don't keep cycling the power over and over. A returning F1 E1 points to the control board.
  3. If you're handy and the breaker is off, you can remove the control panel cover and check that the harness connectors are fully seated on the control board. Look for burned, melted or corroded pins. Don't take live voltage readings yourself.
  4. A technician can enter diagnostics on many of these ovens with CANCEL, CANCEL, START within 5 seconds to read the stored fault codes and test the relays before replacing anything.
  5. If the code still returns, replace the electronic oven control (on wall ovens, the oven appliance manager control), ordering it by your full model number. Boards are model-specific.

🛠 When to call a pro

  • F1 E1 returns after the one-minute breaker reset. The usual fix is a new control board, and a technician can confirm it in diagnostics first.
  • The oven heats when it shouldn't, keeps heating after you cancel, or the display acts erratically. Turn the breaker off and leave it off until it's serviced.
  • It's a built-in wall oven or oven combo, which has to be pulled from the cabinet to reach the control.
  • The oven is under warranty. Call Maytag at 1-800-344-1274 or schedule service rather than opening it up.
