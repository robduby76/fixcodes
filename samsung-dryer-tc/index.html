Code: tC🌀 Samsung Dryer

Samsung Dryer Error Code tC (tE, tS, tC5): Temperature Sensor Error (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 7 manufacturer & service sources

⚡ Quick answer

tC on a Samsung dryer is a temperature sensor (thermistor) error: the control isn't getting a sensible reading from the sensor that measures the dryer's air temperature. Samsung's first fix is the same as for overheating codes: clean the lint screen and check the exhaust vent for a restriction. If tC keeps coming back after that, the thermistor, its wiring or the control board needs a technician.

What the code means

Samsung's US and Canadian error code guides group tC with tS, t5, tO, t0, tE, tE3, tC5, tCS, 1 tC, 1tC5 and 1tCS as temperature errors, meaning a problem with the temperature or the sensors that measure it. Samsung Canada notes that a code that looks like an upside-down F is really a t. The owner's manual for Samsung's DV6000 series dryers describes tC as "The Thermistor1 resistance is very low or high" and tC5 as the same fault on Thermistor2; Samsung UK's code table calls tC/tE an air temperature sensor problem and, on heat pump dryers, tC5/tE5 a compressor temperature sensor problem. A Samsung support answer adds that tE/tC is set when the control board gets no signal back from the thermistor for at least five seconds, so the fault can be the thermistor itself, its wiring or the board. tC can also appear as the result of the vent blockage test on some models, where the manual simply says it's a temperature sensor error and to contact service.

Likely causes

  • A clogged lint screen trapping heat in the dryer, which Samsung lists as the most common cause
  • A restricted, crushed or lint-packed exhaust vent
  • On heat pump or condenser models, a dirty heat exchanger (Samsung UK lists cleaning it for tC/tE)
  • A failed thermistor whose resistance reads very low or very high
  • A loose, damaged or disconnected thermistor wire, so the control board gets no signal back
  • A fault on the dryer's control board (PBA)

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Write down the exact code (tC, tE, tS, tC5 and so on) and your model number; the variants point to different sensors on some models.
  2. Clean the lint screen. If it looks clogged or coated, wash it as your manual describes and let it dry before putting it back.
  3. Check the exhaust vent: pull the dryer out carefully, look for crushed or kinked duct, and clear lint from the duct and the outside vent hood. Samsung says cleaning the lint screen and vent is what usually corrects these codes.
  4. On a heat pump or condenser dryer, clean the heat exchanger as your manual describes.
  5. Reset the dryer only after you've done the cleaning: unplug it or switch off the breaker for 1 to 5 minutes, then power it back on and run a cycle. On heat pump models with tC5, Samsung UK says to wait two to three minutes before turning the power back on.
  6. If the code comes back, stop resetting it. Samsung says repeated resets wipe the error history a technician uses, so request service through Samsung or a qualified repair tech.

🛠 When to call a pro

  • Unplugging the dryer and checking the thermistor's resistance; Samsung's support guidance for its agents says a healthy dryer thermistor reads about 10K ohms at room temperature.
  • Inspecting the thermistor harness and connector back to the control board for loose pins, broken wires or heat damage.
  • Replacing the thermistor if it reads open, shorted or far off value, or the control board (PBA) if the sensor and wiring check out.
  • On heat pump models with tC5 or tE5, checking the compressor temperature sensor named in Samsung UK's code table.
  • Confirming the vent system meets the length and duct type in the dryer's installation instructions so restricted airflow doesn't keep tripping temperature codes.
