Samsung Washer Sud Error Code (Sd, 5Ud, SUdS): Too Many Suds (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 7 manufacturer & service sources

⚡ Quick answer

Sud on a Samsung washer means it detected too many suds. Samsung says the washer pauses for a short time to let the suds die down, then continues the cycle on its own, and that the code doesn't mean service is needed. The cause is how detergent is being used: non-HE detergent, too much detergent, or detergent buildup from earlier loads.

What the code means

Samsung's US error-code list groups SUd, 5UD, Sd, 5d, SUdS and 5Ud5 together as the excessive suds error (5 is how S looks on the display). The washer has detected an over-sudsing condition and stops for a short period so the suds can dissipate. The cycle then continues automatically, and the code may flash again at the end of the cycle as a reminder. Samsung's service table describes the same thing as Foaming Detected: Sud or SUdS shows while the washer is removing the foam, End shows when that is finished, and the normal cycle then carries on. Samsung calls this a normal operation, not a fault. Heavy suds can also cause Samsung's water level or leakage codes (such as LE or 1E), so if you see one of those after a soapy wash, the same fixes apply.

Likely causes

  • Non-HE (regular) detergent. Samsung washers require HE detergent
  • Too much HE detergent, or filling past the MAX line in the detergent drawer
  • Detergent residue left in the washer from earlier loads with too much or non-HE detergent (Samsung says even one such load can cause buildup)
  • Powder detergent that has built up in the drawer or drum
  • Too much fabric softener or bleach, which Samsung also lists as a cause of over-sudsing

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Let the washer keep going. It pauses on its own to let the suds settle and then finishes the cycle, so no reset is needed.
  2. If clothes come out soapy, run a Rinse+Spin cycle with no detergent.
  3. Clear old detergent residue: run an empty cycle with no detergent, softener or bleach. If suds appear, the residue is the cause, so keep running empty cycles until no suds show up.
  4. Samsung UK and Ireland also suggest an Eco Drum Clean cycle (or a hot cotton cycle) with no detergent and no laundry. Repeat Eco Drum Clean if powder detergent has built up.
  5. Use only HE detergent. Samsung warns against regular, organic or natural detergents and HE detergents with vinegar or baking soda.
  6. Use the least detergent that gets clothes clean, and never go past the MAX line in the drawer or the detergent maker's dose for the load size. If the bottle calls for more than the MAX line, use a smaller load or a more concentrated detergent.
  7. Using liquid detergent? Make sure the liquid detergent tray is in the drawer. Using powder? Take that tray out.
  8. If Sud keeps showing, clean the drain pump (debris) filter and the mesh filters in the water supply hose, then run a Spin cycle to drain the washer, as Samsung Ireland suggests.

🛠 When to call a pro

  • Sud or a leak code keeps appearing even though empty cycles no longer make any suds. Samsung says to request service at that point.
  • The washer stops and won't drain or continue after the suds are gone, or it moves on to a drain code such as 5C.
  • You keep clearing the code by resetting. Samsung advises against repeated resets because they wipe the error history a technician uses to diagnose the washer.
  • The washer is under warranty. Use Samsung's support center to request service rather than opening it up.
