Frigidaire Oven Error Code 22 (F22 / F022): Control Board and Relay Board Not Communicating (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 4 manufacturer & service sources

⚡ Quick answer

F22 (shown as F022 or read as "error 22") on a newer Frigidaire, Frigidaire Gallery or Frigidaire Professional range means the oven user interface board (the control behind the display) and the oven relay board have stopped talking to each other. Frigidaire's service data sheets say to cut the power for 30 seconds first, then test the wiring harness between the two boards, then replace the relay board, and replace the user interface board only if the error still comes back.

What the code means

Frigidaire ranges with the newer PUX electronic oven control define F022 as a communication failure between the oven user interface board and the oven relay board. The user interface board reads your key presses and runs the display; the relay board switches the bake and broil elements or gas valves, the fans and the door lock. They talk over a wiring harness (connector MACS1 or MACS2 on the service sheet). When the messages between them stop, the control can't run the oven, so it shows the error. The Frigidaire Professional range data sheet lists the same F22 definition (communication failure between the OUI and the oven control) and adds checking for correct supply voltage. Nearby codes on the same controls are F020 (oven user interface to cooktop user interface), F023 (user interface to the touch panel) and F019 (user interface can't configure the relay board). These are the newer controls' definitions; if your oven is older, check the tech sheet tucked behind the kick panel or control panel for your model before buying parts.

Likely causes

  • A brief glitch, power surge or brownout that clears after the power is cycled
  • Low or unstable supply voltage to the range
  • A loose, unplugged or damaged wiring harness between the oven user interface board and the oven relay board (MACS1 or MACS2 connector)
  • A failing oven relay board, which Frigidaire lists as the first board to replace
  • A failing oven user interface board, if the error persists after the relay board is replaced

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Reset the power: unplug the range for 30 seconds, or switch its breaker off and back on (that resets everything else on that circuit too). This is Frigidaire's first step, and it clears many false error codes.
  2. If the code cleared, run a short bake and watch whether it comes back. A one-time F22 after a storm or outage is often nothing more.
  3. Make sure the range has its own properly sized circuit and isn't on an extension cord or a loose outlet; the Professional data sheet starts by verifying correct voltage.
  4. If the code returns, write down the exact code (F22 or F022, plus any F19, F20 or F23 that show up with it) and the model number from the label; boards are model-specific.
  5. Unplug the range (and shut off the gas on a gas range) before any panel comes off. Checking the harness and boards is wiring work.

🛠 When to call a pro

  • Testing the wiring harness and connectors between the oven user interface board and the oven relay board (MACS1 or MACS2), including reseating the plugs.
  • Checking supply voltage at the range.
  • Replacing the oven relay board if the harness is good, which Frigidaire's service sheet lists before the user interface board.
  • Replacing the oven user interface board if F22 still comes back after the relay board is replaced.
