Code: F04🔥 Goodman Gas Furnace

Goodman F04 Code: Blower Speed 4 Setting, Not a Fault (Meaning, What to Check)

Reviewed 2026-10-25 · Based on 2 manufacturer & service sources

⚡ Quick answer

F04 on a Goodman (or Amana or Daikin) furnace's 7-segment display usually isn't an error at all. On Goodman's two-stage furnaces with the nine-speed ECM blower, the control shows blower speeds as Fxx, so F04 simply means blower speed number 4. It's the factory default speed for first-stage cooling and one of the allowed speeds for gas heat. If the system isn't working, F04 isn't the problem: look for a code that starts with E, which Goodman shows under the Err (active alarm) and F10 (last 10 faults) menus.

What the code means

Goodman's service instructions for the GR9T96/GD9T96 two-stage furnace (also sold as Amana AR9T96/AD9T96) explain that when you open a blower speed menu, the display shows "the selected speed number as Fxx (xx: Blower speed number)," with speeds F01 through F09. Each mode has its own stored speed: FSd for continuous fan, AC1 and AC2 for first- and second-stage cooling, and gA1 and gA2 for low- and high-stage gas heat. In Goodman's speed tables, F04 is the default for low-stage cooling (Y or Y1 from the thermostat), one of three allowed speeds for low-stage heat (F01 default, F03, F04), and one of three for high-stage heat (F02 default, F04, F05). The same menus and tables appear in the service instructions for the Daikin DR96TN/DD96TN furnace. Real faults look different. Goodman lists Err as the active alarm menu and F10 as the last 10 faults menu, and both show codes as Exx. During normal running the display shows things like IdL (idle), 1AC or 2AC (first- or second-stage cooling). So a display showing 1AC together with F04 is describing first-stage cooling at blower speed 4. Note that a few third-party code lists call F04 a high-limit fault on Goodman furnaces; Goodman's own literature for these boards doesn't support that, and the limit fault on these furnaces is EE3.

Likely causes

  • You (or the display) are in a blower speed menu, and F04 is the stored speed number for that mode. Goodman's menus show speeds as F01 through F09.
  • The furnace is cooling on first stage, where Goodman's factory default blower speed is F04.
  • An installer set low-stage or high-stage gas heat to speed F04, which Goodman allows on both stages.
  • If the house isn't heating or cooling, the real cause is a separate fault. Goodman shows those as E codes (for example EE3 for an open limit) under the Err menu, or a problem outside the furnace, such as the outdoor unit, when the furnace shows a normal cooling call.

Safe DIY checks

⚠ Before you start

Turn off power at the furnace/HVAC service switch and the breaker before opening panels. Shut the gas valve before any work near the burners, and never disconnect or alter the gas line. If you smell gas, leave the house and call your gas utility.

  1. Read the whole display sequence, not just F04. Write down any code that starts with E, plus mode words like IdL, 1AC or 2AC.
  2. If the display shows 1AC or 2AC and the indoor blower is running but the air isn't cold, the furnace is doing its part. Check that the outdoor unit is running and its breaker or disconnect is on.
  3. If the furnace won't heat, look for an E code. On these Goodman boards the Err menu shows the active alarm and F10 shows the last 10 faults.
  4. Replace a dirty air filter. It doesn't change F04, but restricted airflow is behind several real Goodman faults, including the EE3 limit code.
  5. Don't change blower speed settings just to make F04 go away. Speeds are set to match the cooling coil and the furnace's temperature rise, and the wrong speed can cause comfort or limit problems.

🛠 When to call a pro

  • The furnace shows an E code alongside or instead of F04. That code is the one to report when you book service.
  • The display shows a normal cooling call (1AC or 2AC) but the outdoor unit won't run or blows warm air.
  • You think the blower speed is set wrong, for example the system is noisy or the coil freezes. A technician should set the cooling and heating speeds using Goodman's airflow and temperature-rise tables for your model.
  • The system is under warranty. Call your Goodman, Amana or Daikin dealer.
