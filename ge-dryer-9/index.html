Code: 9🌀 GE Dryer

GE Dryer Error Code 9: Dry Load Detection Trip (UltraFresh GFD/GFV Dryers)

Reviewed 2026-10-25 · Based on 3 manufacturer & service sources

⚡ Quick answer

On GE UltraFresh GFD and GFV dryers (the ones that pair with GE's UltraFresh washers), fault code 9 is Dry Load Detection Trip: the control's dry-load detection algorithm tripped. GE's technical service guide says to check the outlet and inlet thermistors, the two temperature sensors in the airflow, and replace them if needed. Start with the harness connections, then test each thermistor's resistance with the dryer unplugged.

What the code means

Error codes aren't the same across every GE dryer, so check your model number first (it's on the label inside the door opening). GE's Technical Service Guide for the UltraFresh dryer (publication 31-9349, January 2021, covering GFD55, GFD65, GFD85 and GFV55 models) lists fault code 9 as Dry Load Detection Trip, with the trigger condition 'the dry load detection algorithm has been tripped' and the action 'check and replace outlet/inlet thermistor, if necessary.' GE doesn't explain in that guide what the algorithm looks for; because its fix points at the temperature sensors, the code means the control read air temperatures it didn't trust while judging how dry the load was. On these dryers you can read stored codes yourself in Consumer Fault Code Mode: from idle with all lights off, hold the Start pad for 10 seconds until all lights come on, then press Start to step through the stored codes; the display blinks '--' at the end of the list. In the same table, 1 and 2 are inlet and outlet thermistor failures (readings out of range), 10 is empty drum detection and 11 is a blocked vent, so a 9 logged alongside 1, 2 or 11 points you to the same sensors or the vent. Some older GE dryers use different code lists, and one repair site describes code 009 on older GFD-series dryers as a drive motor problem, so if your model isn't in the UltraFresh range, check the tech sheet stored inside the dryer.

Likely causes

  • A failed or out-of-spec outlet thermistor on the back of the blower housing (GE's listed check)
  • A failed or out-of-spec inlet thermistor on the supply duct at the back of the dryer (GE's listed check)
  • A loose, corroded or damaged harness between a thermistor and the main board's J302 connector
  • Restricted airflow from a full lint screen or blocked vent, which throws off the air temperatures the control reads (a blocked vent also logs code 11)

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Unplug the dryer (and shut off the gas on a gas model) before reaching inside or moving it.
  2. Read the stored codes: from idle with all lights off, hold Start for 10 seconds until every light comes on, then press Start to step through them. Write them down for any service call.
  3. Clean the lint screen and check the duct behind the dryer isn't crushed or kinked, and that the outside vent flap opens freely.
  4. Run a normal cycle with a typical damp load. If code 9 doesn't come back and no other codes are logged, keep an eye on it.
  5. If you're comfortable working on appliances: with the dryer unplugged, check the thermistor connectors are fully seated. GE says resistance can be measured from the main board at the J302 connector: inlet thermistor on the two purple wires (pins 3 and 4), outlet thermistor on the two blue wires (pins 1 and 2).
  6. Both thermistors should read about 95,000 to 105,000 ohms at 77 F (25 C), about 76,000 to 84,000 ohms at 86 F (30 C), and about 118,000 to 132,000 ohms at 68 F (20 C), per GE's table. A reading far outside that, or an open circuit, means that thermistor or its wiring is bad.
  7. Replace a thermistor that tests bad with the part for your exact model number. Reaching either one means removing the top panel, front panel, front drum support, blower wheel and drum, per GE's guide.

🛠 When to call a pro

  • Both thermistors and their wiring test good and code 9 keeps coming back: a technician can use the dryer's Service Mode, which has separate outlet and inlet thermistor tests that display live temperatures, to see which sensor misreads.
  • You don't want to remove the drum to reach the sensors: book service with your model number.
  • You smell burning, see scorched wires, or the dryer runs very hot: unplug it and leave it off until it's inspected.
  • Any time you smell gas, leave the dryer off, shut off the gas and call for service.
