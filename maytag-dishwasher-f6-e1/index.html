Maytag Dishwasher F6 E1 (F6E1) Error Code: Control Panel Can't Talk to the Main Control

Reviewed 2026-10-25 · Based on 3 manufacturer & service sources

⚡ Quick answer

F6 E1 on a Maytag dishwasher means the control panel you press (the user interface) has power but isn't getting a response from the main control board underneath. Maytag's help page calls it a user interface or main control error and says to cut power for 30 seconds, then schedule service if the code comes back. Maytag's technical manual traces it to a loose connection or broken wire in the harness between the two boards, or a failed communication circuit on the main control.

What the code means

Maytag Product Help lists F6E1 as "User Interface Error, Main Control", and its only owner step is a power cycle before scheduling service. Whirlpool Corporation's technical manual W11499711 for KitchenAid and Maytag 24 inch microfiltration dishwashers gives the service detail: Function 6 is User Interface and Error 1 is "No Response from ACU" (the ACU is the main control board), meaning the user interface has power but cannot communicate with the main control. The manual lists three causes: a loose connection between the user interface and the main control, a broken terminal or wire in the harness between them, or a failed communication circuit on the main control. It also ties F6E1 to keys that won't respond or odd key, light or display behavior, pointing to loose connections or bent connector pins between the keypad and the control. On models with a numeric display the code shows as F6 then E1; on models with only status lights, the Clean or Complete light blinks 6 times, pauses 2 seconds, then blinks once. The same code means the same thing on Whirlpool-built sister models (see our Whirlpool F6 E1 page).

Likely causes

  • A loose connection between the user interface (control panel in the door) and the main control board
  • A broken terminal or wire in the harness that runs between the user interface and the main control
  • Bent, damaged or contaminated connector pins between the keypad and the control
  • A main control board with no setting file loaded, which the manual's board LED chart shows as a solid LED and fixes by re-flashing with a service tool
  • A failed communication circuit on the main control board

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Reset the control the way Maytag describes: unplug the dishwasher for 30 seconds, or turn off its breaker for 30 seconds if it's hard-wired, then restore power.
  2. Run a cycle and see whether F6E1 comes back. Maytag's help page says to schedule service if it returns.
  3. If the keys or lights were acting strangely before the code appeared, note that for the technician. Maytag's manual links F6E1 to keys that won't respond and unusual key, light or display behavior.
  4. If you're comfortable working on appliances and have unplugged the dishwasher or shut off its breaker first, the manual's harness check is the connection between P1 on the main control and the user interface: reseat any loose connector and look for broken wires or bent pins. Leave live-voltage checks and board re-flashing to a technician.

🛠 When to call a pro

  • F6E1 comes back after a 30-second power reset. Maytag's help page says to schedule service.
  • A technician can read the diagnostic LED on the main control first. Per the manual, a slow blink means the board is working and should not be replaced, and a solid LED means the setting file needs to be re-flashed with Whirlpool's service tool.
  • The harness connections are good but the code keeps returning. The manual's last step is replacing the main control board, which has to match your full model number.
  • You find damaged or contaminated pins or a broken wire in the door harness. The manual says to repair or replace the harness or the parts with damaged pins.
