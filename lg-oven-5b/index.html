LG Oven 5b (Sb) on the Display: Sabbath Mode, Not an Error (How to Turn It Off)

Reviewed 2026-10-25 · Based on 4 manufacturer & service sources

⚡ Quick answer

If your LG range or oven shows what looks like "5b," it is almost certainly "Sb" on the seven-segment display, and LG says Sb means Sabbath mode is on. It is not a fault. In Sabbath mode the oven keeps baking until the mode is turned off and the function buttons stop responding, which is why it can look like the oven is stuck. On most LG ranges you turn it off by pressing and holding Settings for three seconds.

What the code means

LG's Sabbath Mode (sb) help article and owner's manuals explain that when Sabbath mode is activated, the oven does not turn off until the mode is deactivated, all function buttons are inactive, and "Sb" appears in the display (on some models, in both the cooktop and oven displays). LG built the mode so the oven can be used on the Jewish Sabbath and holidays without lights, tones or display changes. On a seven-segment display, a capital S looks the same as the number 5, so many owners read Sb as "5b" or "5B." LG's range error codes are listed separately and use F-codes such as F9 and F19; Sb is a status message, not one of them.

Likely causes

  • Sabbath mode was turned on, usually by pressing and holding Settings for three seconds while baking (on LSEL6333 and LSEL633CF models the button is Start Time).
  • A button was held down by accident during cleaning or while setting a bake, which switched Sabbath mode on without anyone noticing.
  • Power came back after an outage while Sabbath mode was on; LG says the display returns in Sabbath mode with the oven off.

Safe DIY checks

⚠ Before you start

In Sabbath mode the oven stays on and keeps heating until the mode is turned off or the bake is cancelled, and if no cook time is set it will not shut itself off. Don't leave it unattended longer than you mean to, and keep the door closed before engaging the mode, as LG advises.

  1. Read the display carefully: if it shows Sb (which can look like 5b), the oven is in Sabbath mode, not reporting a fault.
  2. To turn Sabbath mode off, press and hold Settings for three seconds. On LG models LSEL6333 and LSEL633CF, press and hold Start Time for three seconds instead, as LG's help article describes.
  3. To stop the bake itself at any time, turn the oven mode knob to OFF, or press CLEAR/OFF on models with a keypad; LG's manuals say CLEAR/OFF is the one button that still works in Sabbath mode on those models.
  4. If you changed the temperature while in Sabbath mode and nothing seemed to happen, wait: LG's manual says there is a 15-second delay before the oven recognizes the change, and no tones sound.
  5. If the oven light was on when Sabbath mode started, it stays on until Sabbath mode ends, per LG's manual. Turn the light off before activating the mode if you need it off.
  6. Unplug the meat probe before using Sabbath mode; LG says the probe function isn't available in it. If Sb won't clear with the button hold, check your owner's manual for your model's exact button, then look up any F-code that appears separately.

🛠 When to call a pro

  • No repair is needed for Sb; LG describes it as Sabbath mode, a normal feature on current LG ranges.
  • If the control truly will not respond to the documented button hold or to the mode knob or CLEAR/OFF, and no Sb is showing, that is a control or keypad problem for LG service rather than Sabbath mode.
