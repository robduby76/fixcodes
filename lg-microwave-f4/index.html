Code: F4🔧 LG Microwave

LG Microwave F4 Error Code: Humidity Sensor Error (What to Do)

Reviewed 2026-10-25 · Based on 6 manufacturer & service sources

⚡ Quick answer

F4 on an LG microwave is a humidity sensor error. That sensor is what runs the automatic programs (Sensor Cook, Sensor Reheat, Popcorn and similar), which time the food by the steam it gives off. LG lists F4 as needing service. Unplug the microwave for a couple of minutes and plug it back in first, since LG says error codes can be temporary. If F4 keeps coming back, book a technician to test the sensor, its wiring and the control board. Until then, ordinary timed cooking at a set power level often still works on many models.

What the code means

LG's microwave error code guide in its help library lists F4 as a humidity sensor error and marks it as needing service, alongside F1 (main board), F2 (thermistor), F3 (control panel), F5 (damper switch) and F11 (inverter communication). LG's general advice for any F code on its microwaves is that the symptom may be a temporary error, so unplug the cord, plug it back in and see whether the same code reappears; if it persists, call for an inspection. The humidity sensor matters because of how LG's sensor programs work: LG's owner's manuals explain that the sensor system works by detecting built-up steam from the food, and LG's help library says sensor cook and sensor reheat settings measure the humidity the food releases to decide when it is done. A sensor that can't be read, or reads out of range, leaves those programs with nothing to go on, so the control stops and shows F4. Service-level references describe the check the same way: the control watches the sensor warm up and settle to a reference voltage at the start of a sensor program, and flags F4 when it doesn't. The usual fixes are a new humidity sensor, a repaired sensor connector or harness, and, if a new sensor doesn't clear it, the control board. Note that on some older LG models the same sensor fault showed as E-4 rather than F4, and F5 on current LG models is a damper switch error, not a sensor code.

Likely causes

  • A failed or degraded humidity sensor (the part LG's error guide names)
  • A loose, corroded or damaged connector or wire between the sensor and the control board
  • Grease and steam film built up on the sensor, which sits in the exhaust air path
  • A control board that can't read the sensor correctly
  • A temporary control glitch that clears after a power reset

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Unplug the microwave (or switch off its breaker) for two to three minutes, then plug it back in and try a sensor program again. LG says an error can be temporary.
  2. Test a plain timed cook: put a cup of water in, set a time and power level, and press Start. If it heats normally, the microwave is still usable for timed cooking while you arrange a repair.
  3. When you use sensor programs, follow LG's container rules: a microwave-safe dish, loosely covered with a vented lid or vented plastic wrap, never a tight-sealed cover, and the outside of the dish and inside of the oven dry, since beads of moisture can mislead the sensor.
  4. Keep the interior clean, especially after greasy foods like bacon. LG suggests wiping spatters right away and boiling a cup of water for 2 to 3 minutes to loosen stubborn soil.
  5. On an over-the-range model, make sure the vent grille and grease filters aren't clogged so steam can move through the unit.
  6. Don't open the cabinet to reach the sensor. Microwaves contain a high-voltage capacitor that can hold a dangerous charge even when unplugged.

🛠 When to call a pro

  • F4 returns after a power reset: LG lists this code as needing service, so book a technician to test the humidity sensor and its wiring.
  • A new humidity sensor didn't clear F4: the control board or the harness between them needs testing.
  • The microwave won't run at all, not even timed cooking, or shows other F codes: unplug it and book service.
  • You see sparking, smell burning or the oven runs with the door open: stop using it and call for repair right away.
