Code: F01🌀 Maytag Dryer

Maytag Dryer F01 Error Code (F-01 / F1 E1): Main Control Failure (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 6 manufacturer & service sources

⚡ Quick answer

F01 (shown as F-01, or F1 alternating with E1 on newer models) on a Maytag dryer means the main electronic control has detected a problem with itself. Maytag's fix is a power reset: turn the dryer's breaker off for 5 minutes, turn it back on, start a timed dry cycle and watch it for one minute. If F01 comes right back, the main control board usually needs to be replaced, ideally by a technician.

What the code means

On Maytag's electronic dryers, including Bravos models, F-01 is the main electronic control board failure code. Sears PartsDirect's Maytag Bravos error list calls it "Main electronic control board failure", and the Whirlpool-built tech sheet W10156037A that covers these Maytag and Whirlpool dryers lists F-01 as Primary Control Failure with the repair "Replace the machine control electronics." Newer Maytag dryers show the code as F1 alternating with E1. Maytag's dryer error-code guide says any code that alternates between F# and E# means the control has found a problem that needs service, and Maytag's F1 E1 and F01 help pages give the same first step: a 5-minute breaker reset, then a timed dry cycle while you watch for the code. On the newer F1 E1 platform, Whirlpool's technical manual W11416805 calls it a Main Control (ACU) fault and notes it can also be triggered when no voltage is detected at the heater relay, so a technician checks for loose wires at the heater and the relays on the control before replacing the board. A one-time F01 after a storm or outage that clears with the reset isn't a reason to buy a board.

Likely causes

  • A temporary glitch in the main control, often after a power outage, surge or brownout, that clears with a power reset
  • A failed main electronic control board (the most common cause when F01 keeps coming back)
  • On newer F1 E1 models, no voltage detected at the heater relay, from loose wiring at the heater or a relay problem on the control (Whirlpool technical manual W11416805)
  • Loose or damaged wire harness connections at the control board

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Turn off the dryer's circuit breaker(s) for 5 minutes. Electric dryers use two breakers or fuses, so switch off both. If you can't reach the breaker, unplug the dryer for 5 minutes instead, as Sears PartsDirect suggests.
  2. Turn the breaker(s) back on, start a timed dry cycle and watch the dryer for one minute to make sure F01 (or F1 E1) doesn't come back. These are Maytag's own steps.
  3. If the code cleared, keep using the dryer and note whether it returns, especially after storms or outages.
  4. If F01 comes right back, write down the full model and serial number from the label inside the door and contact Maytag or schedule service. Replacement boards must match your exact model.
  5. If you're handy and the board is out of warranty, unplug the dryer before opening the top or console, photograph every connector before removing it, and use an anti-static strap when handling the new board.

🛠 When to call a pro

  • F01 or F1 E1 returns right after the 5-minute power reset.
  • The dryer is under warranty. Opening it yourself can complicate a claim, so call Maytag first.
  • Checking the heater wiring and heater relays on F1 E1 models before condemning the board, as Whirlpool's technical manual directs.
  • Your model's original board is discontinued. Swapping in a superseded part number can need different connectors, which is a job for a technician.
  • You see scorch marks on the board or smell burning. Turn off the breaker and don't run the dryer until it's inspected.
