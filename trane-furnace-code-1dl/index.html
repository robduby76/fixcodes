Trane Furnace Code 1DL (IdL): Idle, Not an Error (Meaning and What to Check)

Reviewed 2026-11-12 · Based on 2 manufacturer & service sources

⚡ Quick answer

1DL (also shown as IdL or 1dL) on a Trane furnace's seven-segment display is not a fault. It means the furnace is idle: the thermostat isn't asking for heating, cooling, or fan, so the control board is simply waiting. If the furnace isn't heating, the real clue is usually somewhere else, such as the thermostat call or a different error code.

What the code means

Trane's installer's guide for the A801X-style integrated furnace control (88-A801X003-1C-EN) lists IdL as "Idle" on the display and says the seven-segment LED reads "IDL" = Idle, no thermostat demand (and, in its legend, no demand for cooling, heating, or fan). Trane's S8V2 manual (FNR-SVX003A-EN) says the same thing for "1 DL" and also lists IdL as Idle. Both manuals tell the installer to wait for IdL / 1 DL to appear before changing menu settings, which confirms it's the resting state after any call for heat, cooling, or fan has finished and the fan off delay has run out. The characters can be misread: the display shows a letter I or the number 1, then d, then L, so people search for it as 1DL, 1dL, or IDL. It is the same thing. If the display shows E followed by numbers (for example E2.1 or E3.4), that's an actual error, and it will appear in the Err (active alarm) menu.

Likely causes

  • No call from the thermostat: the house is at or above the set temperature, so the furnace has nothing to do (Trane: idle, no thermostat demand)
  • The call just ended and the indoor blower's off delay has finished, so the board has dropped back to idle (Trane's sequence of operation ends on 1 DL after the blower off time)
  • Thermostat set to Off, or set to Cool/Fan Auto with no cooling demand, so the furnace sees no demand
  • The thermostat isn't actually sending a heat call: dead batteries, loose R or W wire at the furnace board, or a wrong setting at the thermostat. The furnace stays on 1 DL even though you want heat
  • Display misread: the first character looks like a 1, an I, or an l, but all of these mean the same Idle state

Safe DIY checks

⚠ Before you start

Turn off power at the furnace/HVAC service switch and the breaker before opening panels. Shut the gas valve before any work near the burners, and never disconnect or alter the gas line. If you smell gas, leave the house and call your gas utility.

  1. Don't try to fix 1DL itself. It's the normal resting message, so there's nothing wrong with the furnace if that is all you see.
  2. If you want heat, set the thermostat to Heat and raise the setpoint a few degrees above the room temperature. Within about a minute the display should change from 1 DL to a heat-call status and the inducer should start.
  3. If the display stays on 1 DL with the thermostat clearly calling for heat, replace the thermostat's batteries (if it has them) and confirm the thermostat is in Heat mode, not Off or Emergency/Auto changeover.
  4. Check the furnace power switch and the door switch. The display lights, so power is present, but a stuck door switch or tripped breaker elsewhere can cause odd behavior.
  5. Watch the red LED or display through a full heat call. If a code such as E-something or flashes appears, look up that code. Our pages on Trane 2, 3, and 4 flashes cover the common lockouts.
  6. Don't jumper R to W at the furnace board unless you know how. If the furnace heats when a technician does that test, the problem is the thermostat or its wiring, not the furnace.

🛠 When to call a pro

  • The thermostat is calling for heat (you can see the screen, setpoint above room temperature) but the board stays on 1 DL after several minutes. That points at thermostat wiring, a bad thermostat, or the board's input, which should be tested with a meter.
  • The display flips between 1 DL and an E code. Read the code from the Err menu and look it up.
  • You smell gas, hear clicking with no flame, or see scorching near the burners. Leave the house and call your gas utility from outside.
  • You aren't sure which control board you have. Trane's model names cover many boards and displays. Have the model number from the rating label ready.
