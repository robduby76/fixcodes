Code: F01🧺 Hotpoint Washer

Hotpoint Washer F01 Error Code: Control Board (Motor Triac) Fault

Reviewed 2026-10-25 · Based on 5 manufacturer & service sources

⚡ Quick answer

F01 on a Hotpoint washing machine is an electronic circuit board fault: the machine won't run, or some or all functions can't be selected. Hotpoint's own first step is to unplug the machine for at least 2 minutes, plug it back in, wait 30 seconds and try again. Hotpoint's service manuals say F01 is a short circuit in the motor triac (the part on the main module that switches power to the motor) and tell engineers to check the motor and module connections. If F01 comes back after a reset, Hotpoint recommends booking an engineer. This code applies to UK and European Hotpoint machines (Whirlpool EMEA, formerly Indesit Company), not the GE-made Hotpoint washers sold in the US.

What the code means

Hotpoint UK's washing machine error code guide lists F01 as "Electronic circuit board fault", with the symptom that the washing machine is not operating and some or all functions are not selectable. Its advice is to disconnect the machine from the mains for a minimum of 2 minutes, reconnect, wait 30 seconds and try starting it again, and to book an engineer if the fault remains. Hotpoint's washer dryer error code guide gives the same meaning and advice. The Indesit Company service manuals for Hotpoint machines (for example the WML540GUK.R and HVL200UK service information) are more specific: F01 is "Motor triac short circuit: check motor and module connections." The triac is the electronic switch on the main control module that drives the motor, so the fault sits between the module and the motor. A loose or damaged connection in that circuit is checked before the module is condemned. If the module does need replacing, parts suppliers note that new Hotpoint/Indesit modules come unprogrammed and must be set up for the specific machine, which is one reason Hotpoint points owners to an engineer. F01 here is a UK and European Hotpoint code. Hotpoint washers sold in North America are made by GE Appliances and use different codes, so check your model's handbook if you're in the US or Canada.

Likely causes

  • A temporary electronic glitch on the control board (what Hotpoint's unplug-and-wait reset is meant to clear)
  • Loose, corroded or burnt connection at the motor plug or the module connector (Hotpoint's service manual says to check motor and module connections)
  • Shorted motor triac on the main electronic module (the fault the service manual names)
  • Failed main control module

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Switch the machine off and unplug it from the wall socket (not just the on/off button).
  2. Leave it unplugged for at least 2 minutes, as Hotpoint advises.
  3. Plug it back in, wait 30 seconds, then select a short programme and start it.
  4. If the machine was mid-wash and the door stays locked, run a rinse and spin or drain programme once it responds, or drain it through the pump filter at the bottom front before opening the door.
  5. If F01 comes straight back, stop there unless you are trained: the remaining checks are on the motor wiring and the main module inside the machine, with mains voltage present when it's plugged in.

🛠 When to call a pro

  • F01 returns after the 2-minute power reset: Hotpoint recommends booking an engineer.
  • You smell burning or see scorch marks near the motor or control module.
  • The drum never turns on any programme, or the machine trips the house electrics.
  • The machine is under warranty: contact Hotpoint service rather than opening it up.
  • An engineer replaces the main module: it has to be programmed for your model, so a bare board from a parts shop won't simply plug in and work.
