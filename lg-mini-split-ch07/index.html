LG Mini Split CH07 Error Code: Indoor Units Set to Different Modes (Meaning, Fixes)

Reviewed 2026-10-24 · Based on 3 manufacturer & service sources

⚡ Quick answer

CH07 on an LG multi-zone mini split or ductless air conditioner means the indoor units connected to the same outdoor unit are set to conflicting modes, such as one room on Cool or Dry while another is on Heat. LG calls it the Different Operation Mode error. It is a settings conflict, not a broken part: set every indoor unit to heating, or every unit to cooling or dehumidifying, and the code clears. If it won't clear, LG says to switch off the breaker for about 3 minutes, then restart the units in one matching mode.

What the code means

LG Canada's support article describes CH07 (CH-07) as the "Different Operation Mode Error": it appears whenever any indoor unit is set to a different Cool/Heat mode than the others. All indoor units connected to a single outdoor unit must run in cooling mode or in heating mode at the same time, because the outdoor unit can only do one or the other. LG USA's error code guide gives the same meaning and adds that it shows up on 2-in-1 systems (a standing unit plus a wall unit) and on ceiling units in different rooms. LG's table shows Cool and Dry can run together, but either one paired with Heat triggers CH07; Fan and Air Purification modes can run at any time. On a wired remote it shows as the two-digit code 07 (CH07); without a wired remote, the indoor unit that caused the conflict shows it on its front display. LG's owner's manual for the PQRCVCL0QW wired remote notes that a different-mode condition is not a failure: the remote shows CH07 and asks you to change the mode. Cooling-only systems don't show it.

Likely causes

  • One indoor unit set to Heat while another unit on the same outdoor unit is set to Cool or Dry (dehumidify), which LG lists as the cause.
  • A household member, schedule, timer or app turning on a second room in the opposite mode, for example the living room cooling while the bedroom heats.
  • Auto mode on one unit switching to heating while another unit is cooling (or the reverse), which creates the same conflict.

Safe DIY checks

⚠ Before you start

Fixing CH07 only means changing the mode on each unit and, if needed, resetting the breaker. Don't open the indoor or outdoor units: LG warns that disassembly or replacing internal parts yourself can cause fire, electric shock, serious injury or death. Leave wiring and controller configuration checks to a licensed HVAC technician.

  1. Check the mode on every indoor unit connected to the same outdoor unit, including units in other rooms and any controlled by an app or wired remote.
  2. Set them all to Heat, or set them all to Cool or Dry. LG says Cool and Dry can run together, but neither can run at the same time as Heat.
  3. Fan and Air Purification modes can run on any unit at any time, so use those on a unit that needs air movement but shouldn't heat or cool.
  4. If CH07 stays on, switch off the air conditioner's breaker, wait about 3 minutes, turn it back on, then start each indoor unit one by one and pick the same mode for all of them, as LG's steps describe.
  5. If schedules or Auto mode keep causing it, change them so the rooms on one outdoor unit don't call for heat and cooling at the same time.
  6. If every unit is in the same mode and CH07 still appears after a power reset, contact LG Support or your installer, since the code may be showing for another reason.

🛠 When to call a pro

  • Confirming that every indoor unit and controller on the system reports the same operating mode, including central or wired controllers that may override the handheld remotes.
  • Checking that the system is a heat pump and not configured as cooling-only, since LG's manual says cooling-only models don't show the different-mode display.
  • Reviewing schedules, group control and mode-priority settings on wired or central controllers so units don't start in opposite modes.
  • If CH07 remains with all units matched, checking the communication wiring and addressing between the indoor units and the outdoor unit and reading the outdoor unit's 7-segment display, using the LG service manual for the specific model.
