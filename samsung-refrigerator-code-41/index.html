Code: 41🧊 Samsung Refrigerator

Samsung Refrigerator Error Code 41: Family Hub Software or Communication Error (Meaning, Causes, Fixes)

Reviewed 2026-10-21 · Based on 4 manufacturer & service sources

⚡ Quick answer

Code 41 on a Samsung refrigerator points to the Family Hub screen, not the cooling system. Samsung lists 41 (or 42) with flashing blue interior lights as a Family Hub software or system error, and 41C as a glitch after a software update. Start by rebooting the Family Hub with the switch inside the top of the right door; if the code keeps coming back, it needs service.

What the code means

Samsung's error code guides list three related versions of this code. 41 or 42 together with blue interior lights flashing means a software or system error on the Family Hub, and Samsung's fix is to reboot the Family Hub with the power switch inside the top of the right-hand door. 41C applies only to 3-door French door Family Hub models and shows up after a software update; Samsung says one 41C right after an update is normal and you can tap OK to dismiss it, but a repeat means service. Samsung Canada's support notes describe 41E or 41C in the main control panel as a communication error between the main board and the display board, where a technician checks the two boards and the wiring between them. Samsung also warns not to unplug the fridge or keep poking the panel to make a code go away unless a guide tells you to, because that erases the error history a technician uses to diagnose it.

Likely causes

  • A software or system crash on the Family Hub screen (code 41 or 42 with flashing blue interior lights)
  • A glitch after a Family Hub software update on 3-door French door models (code 41C)
  • An incomplete or missing software update
  • A communication fault between the main control board and the display board, such as a loose connector or damaged wiring (41E or 41C on the main control panel)
  • A defective main board or display board

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Take a photo of the code and note your model number before doing anything. Samsung says resetting the fridge erases its stored error history.
  2. If the code is 41 or 42 and the interior lights are flashing blue, reboot the Family Hub with the switch located inside the top of the right-hand door. Turn it off, wait a moment, and turn it back on.
  3. If the code is 41C, check that the latest Family Hub software update has fully downloaded and installed. The first time 41C appears after an update, tap OK to dismiss it.
  4. On Family Hub models you can see current and past codes by running Self Check: open Apps, tap Fridge Manager, tap Fridge Settings, tap Self Check, then tap Start.
  5. Don't unplug the refrigerator or repeatedly press buttons to clear the code unless Samsung's steps tell you to.
  6. Keep an eye on the food temperatures. The 41 codes concern the Family Hub, but if the fridge or freezer stops cooling, treat that as a separate problem and request service.

🛠 When to call a pro

  • Code 41 or 42 keeps returning after you reboot the Family Hub. Samsung says to request service.
  • 41C appears more than once after the software update is installed.
  • The code is 41E or 41C on the main control panel. That's a board-to-board communication fault, and checking the main and display boards and their wiring is technician work inside the refrigerator's electronics.
  • The Family Hub screen stays blank or frozen after a reboot.
  • The fridge is still under warranty. Opening the control boards yourself could complicate a warranty repair.
