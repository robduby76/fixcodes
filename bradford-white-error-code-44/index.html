Code: 44🚿 Bradford White Tankless Water Heater

Bradford White Error Code 44: Possible Recirculation Pump Failure (Infiniti GR)

Reviewed 2026-10-24 · Based on 2 manufacturer & service sources

⚡ Quick answer

Error code 44 on a Bradford White Infiniti GR condensing tankless water heater means "possible pump failure." The GR has a built-in recirculation pump, and code 44 points at that pump or the recirculation flow sensor that watches it. Bradford White lists 44 as a hard lock, so the heater stops until it is reset. The manual's fix is short: check the pump, check the recirculation flow sensor, and replace the pump if the problem keeps coming back.

What the code means

Bradford White's Infiniti GR (RTGR199) installation and operation manual defines error code 44 as "Possible pump failure" with the remedies "1. Check pump. 2. Check Recirculation Flow Sensor. 3. If the problem persists, replace the pump." It is a hard lock, which Bradford White defines as a lockout that requires a manual reset (a soft lock resets itself when the issue subsides). The GR is the Infiniti model with a built-in recirculation pump and temperature sensor; the control reads the pump's circulated flow through a separate recirculation flow sensor (FLUX2, connector CN15 on the board), apart from the main water flow sensor. Code 44 is a GR code: the Infiniti GS manual, which has no built-in pump, doesn't list it. A related GR code, 46 "Low recirculation flow," means the pump runs but not enough water moves around the loop, and its checks (return and cold water filters, loop length, recirculation setting) are worth knowing if 44 and 46 show up together.

Likely causes

  • The built-in recirculation pump has failed or is not running
  • A faulty recirculation flow sensor, or a loose connection at its board connector (CN15)
  • Restricted flow through the recirculation loop, such as a clogged recirculation return filter, which Bradford White ties to low-flow code 46
  • A recirculation loop that is too long for the built-in pump (Bradford White's limit in External mode is 500 ft equivalent length of 3/4 inch pipe or 200 ft of 1/2 inch pipe)

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Write down the code, then press the Power button to try to clear it and see whether it returns.
  2. Check which recirculation mode the heater is set to (Internal, External, On-Demand or Crossover). If you don't use recirculation, ask your installer whether it should be switched off.
  3. If you are comfortable with it, clean the recirculation return filter and cold water inlet filter as your manual shows, with the water shut off at the isolation valves first.
  4. Don't keep resetting the heater if code 44 comes straight back. Bradford White's next steps involve checking and possibly replacing the pump inside the cabinet, which is work for a qualified technician.

🛠 When to call a pro

  • Check the built-in recirculation pump and its wiring at the control board.
  • Check the recirculation flow sensor and its connection (CN15, FLUX2). The GR's diagnostic display can show the circulated flow rate from the internal pump (rCLF) and has a burner trial with internal circulation (PP1) for testing.
  • If the pump checks out but flow is low, work through the code 46 list: return and cold water filters, loop length within specification, and the recirculation setting for loops without a dedicated return line.
  • If the problem persists, replace the pump, as Bradford White's table directs.
  • Bradford White technical support is listed on its service literature at 800-334-3393.
