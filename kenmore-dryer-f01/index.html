Code: F01 / F-01 / F:01🌀 Kenmore Dryer

Kenmore Dryer F01 (F-01 / F:01): Main Control Board Failure (Meaning, Causes, Fixes)

Reviewed 2026-10-22 · Based on 6 manufacturer & service sources

⚡ Quick answer

F01 on a Kenmore dryer means the main electronic control board has detected a failure in itself. Sears PartsDirect's first step is to unplug the dryer for 5 minutes. If F01 comes right back, the Kenmore service sheet calls for replacing the main control board.

What the code means

Kenmore's service tech sheet for electronic dryers such as the Kenmore Elite 110.78062801 lists F-01 as a Primary Control Failure: it flashes when the dryer's machine control electronics fail, and the recommended procedure is to replace the machine control electronics. Sears PartsDirect, Kenmore's longtime parts and repair arm, lists the same code (shown as F:01 or F-01 on Kenmore Elite and Elite Oasis dryers) as a main electronic control board failure. The code appears when you try to start a drying cycle or when the dryer is in its diagnostic test mode. F01 is a code from Kenmore's Whirlpool-built dryers, whose model numbers begin with 110; Kenmore dryers made by other companies (for example 417 for Frigidaire and 796 for LG, per the PartSelect prefix chart) use their own code lists, so check the first three digits of your model number before following this page. Don't confuse F01 with F-02 (a stuck button or keypad fault) or F70/F71 (lost communication between the main board and the console boards), which point to different parts.

Likely causes

  • A failed main electronic control board (machine control electronics), the repair Kenmore's tech sheet lists for F-01
  • A power surge, brownout or outage that left the control in a fault state, which a 5-minute power reset can clear
  • Loose, corroded or poorly seated connectors on the control board harness; iFixit's Kenmore guide says to check connections before replacing any control
  • A tripped breaker or blown fuse on the dryer's circuit, or a damaged power cord

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Unplug the dryer, or switch off its circuit breaker (electric dryers use a double breaker), and leave it off for 5 minutes, as Sears PartsDirect recommends.
  2. Restore power, start a cycle, and watch whether F01 comes back.
  3. Check your breaker panel and fuses. If the dryer's breaker has tripped or a fuse is blown, reset or replace it once.
  4. Make sure the power cord is fully plugged in and the cord and outlet aren't scorched or damaged. If they are, stop and have an electrician look at it.
  5. Find your full model number on the label inside the door opening or on the back. Confirm it starts with 110 before ordering a board, and order the board that matches that exact model number.

🛠 When to call a pro

  • F01 comes back right after a 5-minute power reset. Kenmore's tech sheet and Sears PartsDirect both point to replacing the main control board at that point.
  • Replacing the main control board. It means opening the console or cabinet, and boards are sensitive to static, so handle the new one by its edges and use an anti-static wrist strap.
  • Checking wiring or voltage inside the dryer. Electric dryers run on 240V, so that's work for a qualified technician.
  • The breaker trips again after you reset it, or you smell burning or see scorched wiring. Stop using the dryer.
  • The dryer is still under warranty. Kenmore's Customer Care line is 1-844-553-6667.
