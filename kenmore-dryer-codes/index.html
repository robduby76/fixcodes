Kenmore Dryer Error Codes: What Each Code Means

Every Kenmore dryer code explained on FixCodes, 6 in all. Together they cite 24 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
d80 / D80Exhaust Vent About 80% Blocked
d80 on a Kenmore dryer means the dryer has sensed that the exhaust duct is about 80% blocked.
d90 / D90Exhaust Vent About 90% Blocked
d90 on a Kenmore dryer means the dryer has sensed that the house exhaust duct is about 90% blocked.
E1 / E2 / tE1 / tE2Thermistor Failure
E1 on a Kenmore dryer means the control has detected a failed thermistor, the temperature sensor it uses to regulate heat.
F01 / F-01 / F:0101): Main Control Board Failure
F01 on a Kenmore dryer means the main electronic control board has detected a failure in itself.
F4 E1 / F4E1Heater Relay or Heater Connection Problem

PFPower Failure During the Cycle
PF on a Kenmore dryer means Power Failure: the power dropped out while the dryer was running, so the cycle stopped.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
