Candy Washer Error Codes: What Each Code Means

Every Candy washer code explained on FixCodes, 7 in all. Together they cite 11 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
E01Door Lock Fault
E01 (shown as E:01 on some displays) on a Candy washing machine means the machine can't confirm the door is closed and locked, so it won't start or carry on the wash.
E02Machine Can't Fill With Water
E02 (shown as E2 on many displays) on a Candy washing machine means the machine can't load water: it didn't reach the right water level in the time allowed.
E03Not Draining Water
E03 (shown as E3 on some displays) on a Candy washing machine means the machine can't drain the water out of the drum.
E07Door Lock Problem, Door Stuck Locked
E07 (shown as E7 or E:07, or as 7 LED flashes on models without a display) on a Candy washing machine points to a problem with the door or the door lock.
E09Motor Control (Triac) Fault on the Main Board
E09 (shown as E:09 on some displays) on a Candy washing machine means the main board can't drive the drum motor properly.
E13Power Board and Display Not Communicating
E13 (shown as E:13 on some displays) on a Candy washing machine means the main power board and the display board have stopped talking to each other, so the machine…
E20Water Level Sensor (Pressure Switch) Reading Fault
E20 (shown as E:20 on some displays) on a Candy washing machine means the control board is having trouble reading the water level.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
