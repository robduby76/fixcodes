LG Oven F11 Error Code: Communication Error (or No Heating on Some Older Models)

Reviewed 2026-10-23 · Based on 3 manufacturer & service sources

⚡ Quick answer

On most LG ranges and wall ovens, F11 is a communication error: the main control board and another control board inside the range stopped talking to each other. Start with CLEAR/OFF and a 30-second breaker reset. If it keeps coming back, it needs service. On a handful of older LG models, F11 instead means the oven isn't heating, so check your model number first.

What the code means

LG's Help Library error code list says F11 indicates a communication error on its ranges. LG's technician site, LG Error Codes, adds that on electric ranges and wall ovens the code is set when the main PCB (control board) and the system PCB lose communication for more than 10 seconds, and its fix is to check the connections at both boards. The same LG page carries an important exception: on a few older models, F11 means the oven is not heating rather than a communication problem. Those are the gas ranges LRG3021, LRG3091, LRG3093, LRG3095 and LRG3097, and the electric ranges LRE3012, LRE30451, LRE30453, LRE30955, LSE3090 and LSE3092. The LG LSE3092ST owner's manual confirms this, listing F-11 as 'No heating' in its oven fault table. On those models, LG says to troubleshoot F11 the same way as F9 (oven not heating).

Likely causes

  • A power glitch or brief brownout that interrupted communication between the control boards
  • A loose, backed-off or damaged connector or harness between the main control board and the system (display or cooktop) board
  • A failed display or system board, or a failed main control board
  • On the older models LG lists (LRG3021, LRG3091, LRG3093, LRG3095, LRG3097, LRE3012, LRE30451, LRE30453, LRE30955, LSE3090, LSE3092): the oven is not heating, the same problem LG reports as F9 on other models

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Find your model number. If it's one of the older models listed above, F11 means the oven isn't heating; see our LG oven F9 page for those steps instead.
  2. Press CLEAR/OFF and try the original function again, as LG's error code list says.
  3. If F11 comes back, switch the range's circuit breaker off, wait 30 seconds, and switch it back on. On the older no-heat models, LG's owner's manual says to touch CLEAR/OFF, reprogram the oven, and if the fault recurs, write down the code and contact a service agent.
  4. If the oven keeps heating while a fault code is showing, or anything smells hot or burnt, leave the breaker off until it's been serviced.
  5. If the code still returns after a reset, LG says the unit needs service. Book a repair with LG or a qualified appliance technician and give them the model number and the F11 code. Reaching the control boards means removing panels on a live 240-volt appliance, so leave that to the technician.

🛠 When to call a pro

  • With power disconnected, checking and reseating the connectors at the main PCB and the system PCB, which is LG's stated fix for the communication error on electric ranges and wall ovens.
  • Inspecting the communication harness between the boards for damaged pins, heat damage or pinched wires.
  • Replacing the display/system board or main control board if the connections are good and the code persists.
  • On the older no-heat F11 models: working through LG's oven-not-heating checks (wiring, heating element or bake igniter, and the oven temperature sensor) per the model's service manual.
