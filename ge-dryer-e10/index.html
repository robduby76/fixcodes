Code: E10🌀 GE Dryer

GE Dryer Error Code 10 (E10): Control Memory Fault or Blower Motor, Depending on Model (Meaning, Causes, Fixes)

Reviewed 2026-10-25 · Based on 5 manufacturer & service sources

⚡ Quick answer

Error code 10 on a GE dryer is shown as E10, and GE uses it for two different faults depending on the dryer. On GE DSXH47EG/DSXH47GG dryers (the knob-and-button models covered by GE technical service guide 31-9148), E10 is a communication failure with the control's EEPROM memory: clear the code and run the dryer, and if it comes back, GE says to replace the control board. On GE Profile DPVH880EJ/GJ dryers, E10 means the blower motor isn't rotating properly, so check for a blocked or jammed blower and lint-packed vent, then have the blower motor and its wiring tested.

What the code means

Check your model number first (on the label at the left side of the door opening on DSXH47 models, or inside the door opening on most GE dryers), because E10 isn't the same fault on every GE dryer. In GE's Technical Service Guide for the DSXH47EG and DSXH47GG dryers (publication 31-9148, December 2006), the error code chart lists E 10 as Communication failure - EEPROM, with the action: clear code, exit mode and start dryer; if the error persists, replace the control board. The same chart lists E 11 (checksum) and E 12 (memory) as related communication failures with the same fix, so all three point at the electronic control rather than a sensor or motor. GE's tech sheet for model DSXH47EG1WW (publication 31-16529) words E10 as General EEPROM Fault, a problem with communication between the EEPROM and the microprocessor. On these dryers the control flashes the status lights and beeps; codes are read in a service sequence with the cycle knob at 3 o'clock, then Select + Pause Cancel for 6 seconds and Start + Pause Cancel for 4 seconds, and the lights flash the two digits after the E. In GE's Technical Service Guide for the GE Profile DPVH880EJ/GJ dryer (publication 31-9167), E10 means the blower motor is not rotating properly. That dryer has a separate 120 VAC, 1/8 hp, 1.6 A blower motor with a tachometer on the back that reports speed to the main board; if the board doesn't see the blower turning at the right speed, it logs E10. On that model E11 is blocked airflow and E12 is the drum motor. Other GE models may use E10 differently, so if yours isn't one of these, check the tech sheet stored inside the dryer cabinet.

Likely causes

  • DSXH47 dryers: the control board's microprocessor can't read or write its EEPROM memory, sometimes after a power glitch or surge
  • DSXH47 dryers: a failing electronic control board, if the code returns after it's cleared (GE's listed fix)
  • Profile DPVH880 dryers: blower wheel jammed or dragging because of lint, a sock, or debris in the blower housing
  • Profile DPVH880 dryers: failed blower motor or its speed tachometer, so the main board can't see the motor turning
  • Profile DPVH880 dryers: loose, damaged, or unplugged wire harness at the blower motor (it has 2 harnesses) or at the main board
  • Profile DPVH880 dryers: a heavily restricted vent run, which also triggers E11 blocked airflow on that model

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Unplug the dryer (and shut off the gas supply on a gas model) before reaching inside or moving it.
  2. Write down your full model number so you know which E10 meaning applies.
  3. For a possible memory fault, reset the control: unplug the dryer or switch off its breaker for about a minute, plug it back in, and start a normal cycle. GE's DSXH47 guide says to clear the code and start the dryer before replacing anything.
  4. If the dryer runs normally afterward, keep an eye on it. A one-time E10 after a power outage or surge may not come back.
  5. Clean the lint screen, and check behind the dryer that the transition duct isn't crushed or kinked and the outside vent hood flap opens freely.
  6. On a Profile DPVH880, listen when you start a cycle: a hum with no airflow at the vent, or a grinding or scraping sound, suggests the blower is jammed or the motor has failed.
  7. If you're comfortable with it and the dryer is unplugged, reseat the wire connectors on the back of the control board. Don't probe live circuits.
  8. If E10 returns on a DSXH47 after a reset, or the blower won't run on a DPVH880, stop using the dryer and plan a repair.

🛠 When to call a pro

  • E10 keeps coming back on a DSXH47 dryer after a reset: GE's guide says to replace the electronic control board.
  • On a Profile DPVH880, a technician can use the dryer's service test mode to run the blower and read its speed, and measure the blower motor windings (GE lists roughly 5 ohms start and 4 ohms run) to confirm a failed motor before replacing it.
  • The blower housing has to come apart to clear a jam; on the DPVH880 that means removing the drum, so it's a bigger job than most DIY fixes.
  • You smell burning or see scorched wires or connectors.
  • Any time you smell gas, leave the dryer off, shut off the gas, and call for service. GE Appliances Factory Service books repairs at repair.geappliances.com.
