KitchenAid Oven F3E1 (F3 E1) Error Code: Oven Temperature Sensor Shorted (Meaning, Causes, Fixes)

Reviewed 2026-10-22 · Based on 5 manufacturer & service sources

⚡ Quick answer

F3E1 (shown as F3 E1) on a KitchenAid range or wall oven points to the oven temperature sensor circuit: the sensor, its wiring, or the oven control. Whirlpool's service tech sheets define F3 E1 as a shorted temperature sensor, meaning the control reads a resistance that's too low. Start with KitchenAid's own fix: turn the breaker off for one minute, turn it back on, and watch for a minute to see if the code returns.

What the code means

KitchenAid's Product Help pages for ranges and wall ovens say F3 E1 means there may be a problem with the oven temperature sensor, the control, or the associated wiring (on wall ovens, KitchenAid names the lower oven temperature sensor). The F3 family covers the oven sensor: in Whirlpool Corporation tech sheets for these electronic oven controls, F3 E0 is an open sensor and F3 E1 a shorted sensor, with E2 and E3 used for over-temperature in cook and clean modes. Whirlpool tech sheet 8302066 gives the threshold: the control flags F3 E1 when the sensor reads about 825 ohms or less, against a normal of about 1,080 ohms at 70°F (rising roughly 2 ohms per degree F). Whirlpool tech sheet 8053296 lists the sensor range as about 1,000 ohms at 32°F to 2,697 ohms at 900°F and also says to check from the sensor connector to the sensor casing for a short. On double ovens with this control, tech sheet 8302066 notes the fault shows on the side of the display that matches the affected oven. Newer KitchenAid tech sheets such as W11393917 list only F3E0 for main sensor open or shorted, so the exact code can differ by control generation.

Likely causes

  • A failed oven temperature sensor that has shorted internally, so its resistance reads too low
  • Sensor wiring that is pinched, damaged, or shorted to the oven body or sensor casing
  • A loose, corroded, or poorly seated connector between the sensor and the control (Whirlpool's tech sheet names connector corrosion as the most common cause of control problems)
  • A failed electronic oven control, when the sensor and wiring test good
  • A temporary glitch that a one-minute power reset clears

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Turn off the oven's circuit breaker(s) for one minute, turn them back on, and watch the display for one minute. If F3 E1 doesn't come back, check that the oven heats normally (this is KitchenAid's own reset).
  2. If the code returns, stop using the oven. The control can't read oven temperature correctly with a sensor fault.
  3. With the breaker off, look at the sensor probe on the back wall of the oven cavity. Make sure it isn't bent or touching anything and that its mounting screws are tight.
  4. If you're comfortable with a multimeter, and still with power off, unplug the sensor connector (usually reached by removing the rear panel or the sensor's mounting screws and pulling the lead forward) and measure it. Whirlpool's tech sheets give about 1,000 to 1,200 ohms at room temperature (about 1,080 ohms at 70°F). A reading well below that, around 825 ohms or less, matches F3 E1.
  5. Also check for a short from either sensor pin to the sensor's metal casing; there should be no continuity.
  6. Inspect the sensor harness for melted insulation or pinched spots and reseat the connector firmly. Replace the sensor if it reads low or shorted, using the part number for your model.
  7. Restore power and run a bake cycle. If the sensor and wiring test good and F3 E1 keeps returning, the oven control is the next suspect.

🛠 When to call a pro

  • F3 E1 returns after the one-minute breaker reset and you'd rather not open the oven or use a meter.
  • The sensor tests good but the code persists, which points to the wiring harness or the electronic oven control.
  • The oven heats when it shouldn't or overheats. Turn the breaker off and keep it off until it's serviced.
  • Work behind the oven or on the control board, especially on a built-in wall oven that has to be pulled from the cabinet.
  • The oven is still under warranty. Use KitchenAid's contact or schedule-service options instead of opening it.
