Code: F5🧺 Kenmore Washer

Kenmore Washer F5 Error Code: Lid Lock or Lid Switch Fault (F5 E1, F5 E2, F5 E3, F5 E4)

Reviewed 2026-10-23 · Based on 3 manufacturer & service sources

⚡ Quick answer

F5 on a Kenmore top-load washer points to the lid lock and lid switch. It shows up on Whirlpool-built Kenmore 110-series top-loaders, and the second half of the code (E1 to E4) tells you whether the lid isn't sensed, won't lock, won't unlock, or wasn't opened between cycles. Debris in the lock area is the easy fix; a worn lid lock/switch assembly is the usual part.

What the code means

Sears PartsDirect, Kenmore's longtime parts and repair arm, lists F5 as the lid lock family on Kenmore 110-series vertical modular top-load washers. F5 E1 is a lid switch fault and appears if Start is pressed with the lid open. F5 E2 is a lid lock fault, where the lock can't engage the lock strike. F5 E3 is a lid unlock fault, where the lid stays locked. F5 E4 means the lid was not opened between cycles, because the washer was started several times without the control seeing the lid open. On these washers the lid lock light flashes when a fault happens, and the full code can be read in diagnostic mode. LG-built Kenmore 796-series washers use a different code list, so check the model number on the label first.

Likely causes

  • Pressing Start with the lid open (F5 E1)
  • Laundry, a sock or other debris caught in the lid lock or the lock strike (F5 E2)
  • Detergent or fabric softener buildup around the lid lock
  • Weight or force on the lid, such as a laundry basket sitting on top, keeping the lock from releasing (F5 E3)
  • Running several cycles in a row without opening the lid (F5 E4)
  • A lid lock/switch assembly that no longer senses the lid or locks and unlocks properly
  • A bent or damaged lock strike on the lid

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Close the lid firmly and press Start again. F5 E1 often just means Start was pressed with the lid up.
  2. For F5 E4, open the lid, close it again and restart. The washer expects to see the lid open between loads.
  3. Unplug the washer and look at the lid lock and the strike on the lid. Remove anything caught there and wipe away detergent or lint buildup with a damp cloth.
  4. Take anything off the top of the washer so nothing presses on the lid while it tries to unlock.
  5. Reset the control by unplugging the washer for 5 minutes, then plug it back in. That is Whirlpool's reset step for F5 E3 on its top-load washers, which share the same control.
  6. If you want to confirm which F5 code was stored, Sears PartsDirect shows how to enter diagnostic mode with the cycle dial and read the code from the status lights.

🛠 When to call a pro

  • The lid lock area is clean and the code comes back. Sears PartsDirect says the lid lock/switch assembly will usually need to be replaced for F5 E1, F5 E2 and F5 E4.
  • The lid is stuck locked with a load inside (F5 E3). Sears PartsDirect says to lift the top panel and unlock the lid manually without breaking the lock or strike, then replace any damaged parts. Unplug the washer first, and call a technician if you aren't comfortable opening the cabinet.
  • The lock strike on the lid is bent or cracked and won't line up with the lock.
  • The washer is still under warranty. Kenmore's Customer Care line is 1-844-553-6667.
