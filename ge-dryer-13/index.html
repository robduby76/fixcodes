Code: 13🌀 GE Dryer

GE Dryer Error Code 13: Door Switch Signal Stuck Closed (UltraFresh GFD/GFV Dryers)

Reviewed 2026-10-25 · Based on 2 manufacturer & service sources

⚡ Quick answer

On GE UltraFresh GFD and GFV dryers, fault code 13 is Door Switch Signal Stuck Closed: five cycles have run and the control never saw the door switch signal go open, so it thinks the switch is stuck closed. GE's technical service guide says to check and replace the door switch, its harness or the main board as needed. Start by watching what the control reads when you open and close the door.

What the code means

Error codes aren't the same across every GE dryer, so check your model number first (it's on the label inside the door opening). GE's Technical Service Guide for the UltraFresh dryer (publication 31-9349, January 2021, covering GFD55, GFD65, GFD85 and GFV55 models) lists fault code 13 as Door Switch Signal Stuck Closed. The trigger condition is that five cycles are run and the DOOR_STATE signal in the hardware door switch detection circuit has not gone open. In plain terms, the dryer expects to see the door open between loads, and after five cycles without that, it decides the door switch or its circuit is stuck reading 'closed.' GE's action is to check and replace the door switch, harness and/or main board if necessary. The same table has two close cousins: 8, Door Latch Stuck, set when the DOOR_LATCH signal hasn't gone open after five cycles (check the door switch and/or harness), and 14, Door Latch Pulsing Error, a malfunction of the door switch detection circuit. You can read stored codes yourself in Consumer Fault Code Mode: from idle with all lights off, hold the Start pad for 10 seconds until all lights come on, then press Start to step through them; the display blinks '--' at the end. Older GE dryers use different code lists, so if your model isn't in the UltraFresh range, check the tech sheet stored inside the dryer. For other GE dryer codes see our E1, E10 and E11 pages.

Likely causes

  • A door switch that is stuck or welded closed, so the control never sees the door open (GE's first listed check)
  • A damaged, pinched or shorted harness between the door switch and the main board (GE's listed check)
  • A main board whose door-sensing circuit has failed (GE lists the board after the switch and harness)
  • Less likely: something holding the switch plunger in, such as a misaligned door or debris around the switch, so it never releases

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Unplug the dryer (and shut off the gas on a gas model) before reaching inside or moving it.
  2. Read the stored codes: from idle with all lights off, hold Start for 10 seconds until every light comes on, then press Start to step through them. Note whether 8 or 14 is logged too, since those point at the same door switch circuit.
  3. Open the door fully and look at the door switch area on the front panel. Make sure nothing is jamming the switch and the door isn't sagging or rubbing.
  4. Open and close the door normally between loads for a few cycles. If code 13 doesn't come back, keep an eye on it.
  5. If you're comfortable with service menus: enter Service Mode from idle by holding the Start pad while turning the cycle knob 180 degrees, then releasing Start. Turn the knob to test 11 (Door Open/Close Test) and press Start. The display should show 'dc' with the door closed and 'do' with it open. If it shows 'dc' with the door open, the switch, its wiring or the board's sensing circuit is the problem.
  6. Test 12 (Door Latch) should show 'LC' with the door open and 'LS' after you close the door and press Start. Test 13 in Service Mode clears all fault codes; the display shows '--' when cleared. Hold Start for 3 seconds, or press Power, to exit.
  7. With the dryer unplugged, a stuck switch can be confirmed with a multimeter on continuity: it should change state as you press and release the plunger. GE's guide says the door switch is attached to the front panel and its connector is unplugged as you lift the front panel off (control panel and top cover come off first, then four 1/4-inch hex screws on top and four T15 Torx screws).

🛠 When to call a pro

  • The new switch and harness check out and the Service Mode door test still reads closed with the door open: the main board's sensing circuit is the remaining item on GE's list, and a technician should confirm it before you buy a board.
  • You don't want to take off the control panel and front panel: book service with your model number and the codes you read.
  • You smell burning, see scorched wires, or the drum keeps turning with the door open: unplug the dryer and leave it off until it's inspected.
  • Any time you smell gas, leave the dryer off, shut off the gas and call for service.
