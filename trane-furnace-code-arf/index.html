Trane Furnace Code ARF: Airflow Readout, Not an Error (What It Means)

Reviewed 2026-10-23 · Based on 1 manufacturer & service sources

⚡ Quick answer

ARF on the three-digit display of a Trane furnace control board is not an error code. It stands for Airflow, and it's part of the normal status readout: while the furnace is running, the display alternates every 2 seconds between the operating mode (for example Ht1), ARF, and a three-digit number. Multiply that number by 10 to get the airflow in cubic feet per minute (CFM) the control is calling for, so ARF then 080 means about 800 CFM. Real faults show up as an E code (like E3.1 or E4.0) flashing alongside the readout.

What the code means

Newer Trane variable-speed gas furnaces (for example the S8V2 2-stage models) have an integrated furnace control (IFC) with a seven-segment display. Trane's installation, operation and maintenance manual (FNR-SVX003A-EN) lists ArF in its Status Codes column as "Airflow", next to the operating modes IdL (idle), Ht1 and Ht2 (1st and 2nd stage gas heat), CL1 and CL2 (cooling), HP1 and HP2 (heat pump heating), COF (continuous fan) and dFt (defrost). Its system status menu explains that while there is a call for heat, cooling or fan, the display alternates every 2 seconds between the system mode and the airflow request, and that the number after ARF is multiplied by 10 for actual airflow (ARF 080 = calculated airflow of 800 CFM). The sequence of operation gives examples such as Ht1, ARF, 080 for 800 CFM in 1st stage gas heat and Ht2, ARF, 112 for 1,120 CFM in 2nd stage. Trane notes that if an error occurs, an E code will flash alternately with the system mode and airflow request, so ARF on its own means the furnace is running normally and reporting its blower airflow. When the thermostat is satisfied the display returns to IdL (idle).

Likely causes

  • Normal operation: the thermostat is calling for heat, cooling, heat pump heat or continuous fan, and the control is showing the airflow it's asking the blower for
  • The number shown after ARF is the airflow divided by 10 (080 = 800 CFM, 140 = 1,400 CFM), not a fault number
  • If an E code (E3.1, E4.0 and so on) also flashes in the sequence, that E code is the actual fault to look up

Safe DIY checks

⚠ Before you start

Turn off power at the furnace/HVAC service switch and the breaker before opening panels. Shut the gas valve before any work near the burners, and never disconnect or alter the gas line. If you smell gas, leave the house and call your gas utility.

  1. Watch the display for 10 to 15 seconds through the sight glass. If it cycles only through a mode (such as Ht1, CL1 or COF), ARF and a number, the furnace is reporting normal operation and nothing needs fixing.
  2. To read the airflow, multiply the number after ARF by 10. A higher number during 2nd stage heat or cooling is expected, because the blower ramps up for higher stages.
  3. If an E code appears in the rotation, write it down exactly (for example E3.2) and look up that code instead. The control's Err menu shows active errors and the L6F menu shows the last 6 faults.
  4. If the house isn't heating or cooling even though the display shows normal ARF readouts, check the basics: thermostat mode and setpoint, a clean furnace filter, open supply and return vents, and the outdoor unit's breaker for cooling.
  5. Don't change airflow settings (CPC, CPH, gHC, COF) in the control menu unless you know the right values for your system. Trane says to leave continuous fan at 75% or below and that zoning or variable-speed outdoor units need 400 CFM per ton.

🛠 When to call a pro

  • An E code keeps appearing alongside the ARF readout, or the furnace locks out.
  • Airflow settings need to be matched to a new outdoor unit, zoning system or duct changes. Trane recommends its Link mobile app for setting airflow and checking gas manifold pressure.
  • The blower is noisy, rooms aren't getting enough air even though ARF shows the expected value, or temperature rise is outside the range on the furnace rating plate. A technician can check static pressure and the airflow tables in the manual.
  • The system is communicating (Link) rather than 24-volt; Trane's manual says the Menu and Option buttons are disabled in communication mode and the diagnostics app must be used.
