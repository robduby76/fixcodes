Lennox Furnace Error 203 (E203): Unit Size Code Not Programmed (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 5 manufacturer & service sources

⚡ Quick answer

Error 203 on a Lennox variable-speed furnace means the integrated control board doesn't have a valid unit size (capacity) code programmed, so it doesn't know which furnace model it's installed in. It shows up most often right after a control board is replaced. Lennox treats it as a critical alert, and the fix is to program the correct unit size code for your furnace model, then cycle power to confirm it stuck.

What the code means

Lennox service literature for its SureLight variable-speed furnaces (SL280UHNV, SL280DFNV and similar) defines E 203 as 'Appliance capacity / size is NOT programmed. Invalid unit codes refer to configuration flow chart.' Each furnace model has a one-character unit size code (for example A, b, C, d, E or F on SL280 models, or 0 to 7 on EL296UH models) that tells the control the furnace's capacity and blower size. At power-up the seven-segment LED normally flashes that code; if it shows three horizontal bars followed by a continuous E203, the control doesn't recognize any unit size code. Lennox says E203 is a critical alert that clears only after a valid unit code is read following a reset, and warns that field replacement controls may need to be configured by hand. A related code, E202, means a code is programmed but it's the wrong one for the blower motor.

Likely causes

  • A new or replacement integrated control board that was never programmed with the furnace's unit size code (Lennox warns field replacement controls may need manual configuration)
  • A previous attempt to program the code that didn't save, because the 10-second window expired or the button was held less than 5 seconds
  • The unit size code was lost or corrupted in the control's memory
  • A failed integrated control board that won't store or recognize the code (only after programming has been repeated correctly)

Safe DIY checks

⚠ Before you start

Turn off power at the furnace/HVAC service switch and the breaker before opening panels. Shut the gas valve before any work near the burners, and never disconnect or alter the gas line. If you smell gas, leave the house and call your gas utility.

  1. Confirm the code: cycle power to the furnace and watch the seven-segment LED through the sight glass at power-up. A single letter or number is the stored unit size code; three horizontal bars followed by a steady E203 means no code is recognized.
  2. Find your exact furnace model number on the nameplate inside the furnace, then look up its unit size code in the 'Program Unit Capacity/Size Mode' chart in your installation instructions or service literature. Don't guess; picking the wrong code leads to E202 and incorrect blower airflow.
  3. Put the furnace in idle: turn the room thermostat to OFF so there's no heating, cooling or fan call. On a communicating system, Lennox says to remove the thermostat from the system while applying power and reprogramming.
  4. Push and hold the button next to the seven-segment display until a solid 'P' appears, then release it. The 'P' starts blinking.
  5. Push and hold the button again. The control steps through the unit size codes, showing each for about 3 seconds. Release the button when the correct code for your model is shown.
  6. The selected code flashes for 10 seconds. During that window, press and hold the button for 5 seconds to store it; the control saves it and resets. If the window runs out or you release too soon, the control goes back to idle without saving, so repeat the steps.
  7. Verify it saved: cycle the 24V power to the furnace control. At power-up the LED should display your unit size code. If three bars show again, the programming has to be repeated.

🛠 When to call a pro

  • E203 keeps returning after you've programmed and verified the correct unit size code. The integrated control may need replacing.
  • You can't find your model in the unit size code chart, or the nameplate model doesn't match the furnace's literature. A Lennox dealer can confirm the right code.
  • The code was just installed on a new control board and the furnace still won't run, or other error codes appear.
  • The furnace is on an iComfort or other communicating system that needs to be re-commissioned after the board is configured.
  • You smell gas: leave the house and call your gas utility from outside.
