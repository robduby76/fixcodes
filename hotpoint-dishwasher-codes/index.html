Hotpoint Dishwasher Error Codes: What Each Code Means

Every Hotpoint dishwasher code explained on FixCodes, 4 in all. Together they cite 8 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
F05Pressure Switch Fault (Fill Not Confirmed)
F05 on a Hotpoint dishwasher (the UK and European Hotpoint made by Indesit Company, now Whirlpool EMEA) means a pressure switch fault.
F13Main Board Fault
Error 13 (F13) on a Hotpoint dishwasher means the main control board has a fault.
F15Virtual Sensor Error, Wash and Drain Pump Readings Don't Match
Error 15 (F15) on a Hotpoint dishwasher is the virtual sensor error: the control board's readings from the wash pump and the drain pump don't agree with each other.
HNo Water Coming In (Tap Shut-Off Alarm)
An H on a Hotpoint dishwasher display, usually with beeping, means the machine isn't detecting water coming in.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
