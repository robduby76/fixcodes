GE Microwave Error Codes: What Each Code Means

Every GE microwave code explained on FixCodes, 6 in all. CodeWhat it means

F3 on a GE microwave means the control is reading a touchpad key as pressed when it shouldn't be.
F4Open Humidity Sensor
F4 on a GE microwave is a humidity sensor fault.
FOODDoor Not Opened Reminder
"FOOD" (or "Insert Food") on a GE microwave is not a fault.
LOCControl Panel Is Locked (How to Unlock It)
"LOC" on a GE microwave is not a fault.
PFPower Failure Notice, Not a Fault (How to Clear It)
PF on a GE microwave stands for power failure.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
