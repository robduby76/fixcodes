GE Washer Error Codes: What Each Code Means

Every GE washer code explained on FixCodes, 8 in all. Together they cite 14 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. CodeWhat it means
3Locked Rotor, Motor Not Turning
Error code 3 on a GE front-load washer is a locked rotor fault: for 5 seconds straight the control tried to spin the drum but didn't see any signal that the motor was…
18Washer Not Draining (Front Load and Top Load)
Error code 18 on a GE washer means it couldn't get the water out.
19Paused Too Long or Water in the Tub While Off
Error code 19 on a GE washer means the washer either sat paused for more than 24 hours, or it found water in the tub while it was turned off for more than 24 hours.
23Door Lock (Lid Lock) Failure
Error code 23 on a GE washer is a door lock problem.
26Out of Balance in Final Spin
Error code 26 on a GE front-load washer means the load went out of balance during the final spin and the washer couldn't reach its top spin speed.
27Inverter Overheated (Front Load) or Lid Open With Water (Top Load)
Error code 27 means different things on different GE washers.
32Can't Unlock the Door (Front Load, Also Code 77)
Error code 32 on a GE front-load washer means the washer canceled the cycle because it couldn't unlock the door.
