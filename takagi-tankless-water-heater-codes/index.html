CodeWhat it means
101Abnormal Combustion Warning (Before a 991 Shutdown)
Error code 101 on a Takagi tankless water heater is a warning that combustion isn't right: the air-fuel mix is running gas rich, usually because the heater isn't getting…
111 / 11Ignition Failure (Heater Won't Light)
Error code 111 on a Takagi tankless water heater means ignition failure: the heater tried to light three times and never got a flame.
121Flame Loss (Flame Goes Out While Running)
Error code 121 on a Takagi tankless water heater means flame loss: the burner lit, but the flame went out while the heater was still supposed to be running.
291Blocked Condensate Drain
Error code 291 on a Takagi condensing tankless water heater means the condensate drain system is blocked.
391Air-Fuel Ratio Rod Failure
Error code 391 on a Takagi tankless water heater means air-fuel ratio rod failure: the air-fuel ratio (AFR) rod in the burner isn't detecting flame.

991 / 99Abnormal Combustion (Heater Shut Down)
Error code 991 on a Takagi tankless water heater means abnormal (imperfect) combustion, and the heater has shut itself down.
