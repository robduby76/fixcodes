Code: F70🌀 Whirlpool Dryer

Whirlpool Dryer F70 Error Code: Control Communication Failure (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 6 manufacturer & service sources

⚡ Quick answer

F70 on a Whirlpool dryer means the display and button board (the user interface) isn't getting messages from the dryer's main control board. Whirlpool's first fix is a full power reset: turn the breaker off for 5 minutes, turn it back on, start a timed dry cycle and watch for a minute. If F70 comes back, the wiring between the two boards or one of the boards themselves needs to be checked.

What the code means

Whirlpool's service sheets for its commercial-grade and coin-operated dryers (for example tech sheet W11316893 Rev A and the CED9150 electronic control setup instructions) define F 70 as "Communication failure from dryer CCU to UIC": the user interface control (UIC) is not receiving communications from the central control unit (CCU), the main board that runs the motor and heat. While the error is present, cycles are disabled. Its mirror code, F 71, means the opposite direction, where the CCU isn't hearing from the user interface. Whirlpool's Product Help lists F70 for both its residential and commercial-grade dryers with the same reset steps, and Sears PartsDirect's Whirlpool Duet dryer code list describes F:70 or F:71 as no communication between the main electronic control board and the user interface board assemblies. On newer Whirlpool dryers that use the F#E# format, the communication codes are F6E1 and F6E2 instead, so if your display shows those, the same idea applies but the steps come from that model's tech sheet.

Likely causes

  • A power glitch or surge that left the boards out of sync, which a 5-minute breaker reset usually clears
  • A loose, damaged or corroded wire harness connector between the main control (CCU) and the user interface board
  • A damaged harness between the two boards, for example a pinched wire behind the console
  • A failed user interface board
  • A failed main control board (CCU)

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Turn off the dryer's circuit breaker (or breakers) for 5 minutes, then turn them back on. That is Whirlpool's first step for F70.
  2. Start a timed dry cycle and watch the dryer for one minute to see whether F70 comes back, as Whirlpool's Product Help says.
  3. If the dryer was recently moved, pushed back hard against the wall, or had other work done on it, make sure the power cord and outlet are solid. A loose connection at the outlet can cause power drops.
  4. If F70 returns and you're comfortable with it, unplug the dryer first, then check that the connectors between the main control board and the user interface board are fully seated, with no burnt, bent or corroded pins. Sears PartsDirect's Duet guide gives this as the check before calling a technician.
  5. Don't run the dryer with panels off, and don't swap boards on a guess. These two boards are expensive, and the code alone doesn't tell you which one failed.

🛠 When to call a pro

  • F70 keeps coming back after the breaker reset and the connectors look fine. Whirlpool says to contact them or schedule service at that point.
  • Testing the harness for continuity and the boards' power supplies to work out whether the user interface board or the main control board has failed.
  • The display goes dark, flickers or ignores button presses along with the code, which points toward the user interface board or its power.
  • Coin-operated or commercial-grade machines, where the setup and diagnostic modes in Whirlpool's service sheets are meant for the operator or a technician.
  • The dryer is still under warranty. Schedule Whirlpool service instead of opening it up.
