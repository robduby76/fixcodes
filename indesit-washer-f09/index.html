Code: F09🧺 Indesit Washer

Indesit Washing Machine F09 Error Code: Software Fault (Flashing Lights, Can't Select a Programme)

Reviewed 2026-10-26 · Based on 4 manufacturer & service sources

⚡ Quick answer

F09 on an Indesit washing machine is a software fault. Indesit says the machine won't operate, several lights or the display flash, and you can't select a programme. Behind it, the control board can't read the setup data (stored on its EEPROM memory chip) that tells it which machine it's in, so it refuses to run. A 2-minute power reset is worth one try, but if F09 comes back it needs an engineer to reprogram or replace the board's memory.

What the code means

Indesit Service UK lists F09 as "Software fault": the washing machine isn't operating, multiple lights and/or the display are flashing, and you can't select a programme. Indesit's advice is to call 0800 030 8901 to book an engineer. Indesit's WIL10 technical documentation (the French service file for this control platform) defines F09 as a machine configuration error (EEPROM error). Its remedy depends on the board: if the production board has the EEPROM soldered on, replace the board and EEPROM together; if it's a spare board with a separate EEPROM, check the EEPROM is properly seated in its socket on the board. The Indesit Arcadia service manual describes F09 as a setting file error detected by the main PCB or display PCB, with the steps of disconnecting the machine for 2 minutes and checking for correct operation, then reprogramming the main PCB, renewing the main PCB, or renewing the display PCB. An Indesit Company service bulletin adds that F09 can appear after a control card or EEPROM is replaced with a part that isn't a matching, compatible one. F09 is different from F12, an electronic control fault where the machine won't turn on, and from F08, the heater fault. Hotpoint machines in the UK share these electronics and list F09 the same way.

Likely causes

  • The main control board can't read or doesn't accept its machine configuration file stored on the EEPROM memory chip
  • A replacement board or EEPROM that wasn't programmed for your exact model, or isn't compatible with the board it was fitted to
  • On spare boards with a socketed EEPROM, the chip not seated properly in its socket (WIL10 service file)
  • A glitch after a power cut or surge that a full power reset can sometimes clear
  • Less often, a fault on the display (user interface) board, which the Arcadia service manual lists as a part to renew

Safe DIY checks

⚠ Before you start

Unplug the machine before any check. Don't open the panels or handle the control boards yourself; they carry mains voltage and can hold a charge. Never open the door with hot water in the drum.

  1. Switch the machine off and unplug it at the wall for at least 2 minutes, then plug it back in and try selecting a programme. That's the first step in Indesit's Arcadia service manual for F09.
  2. If the door is locked with water in the drum, don't force it. Leave the machine unplugged and drain it through the pump filter at the bottom front, with towels and a shallow tray ready.
  3. If F09 appeared right after a board was replaced, contact whoever fitted it, because the new board or memory chip may not match your model.
  4. If F09 comes back after the reset, book an Indesit engineer on 0800 030 8901. Reprogramming the board needs Indesit's service tools and isn't something you can do at home.

🛠 When to call a pro

  • F09 comes back after a 2-minute power reset: Indesit's advice is to book an engineer.
  • The engineer reprograms the board's configuration for your model, reseats or replaces a socketed EEPROM, or replaces the main board (with its EEPROM if soldered), and if that doesn't clear it, the display board.
  • You're offered a used or generic control board: make sure it's programmed for your exact model number, because a mismatched board or EEPROM is a known cause of F09.
  • The machine is still under warranty: use Indesit service first.
