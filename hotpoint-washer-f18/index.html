Code: F18🧺 Hotpoint Washer

Hotpoint Washing Machine F18 Error Code: Internal Data Error (Display or Buttons Not Working)

Reviewed 2026-10-26 · Based on 3 manufacturer & service sources

⚡ Quick answer

F18 on a Hotpoint washing machine or washer dryer is an internal data error: the electronics on the main control board have hit a fault, so some or all of the display and buttons stop working. Hotpoint's advice is to unplug the machine for at least 2 minutes, plug it back in, wait 30 seconds and try again. If F18 keeps coming back, it's a board fault rather than anything you can clean or adjust, so book an engineer.

What the code means

Hotpoint UK's washing machine error code guide lists F18 as "Internal data error", with the symptom that some or all of the display or functions do not work, and its washer dryer guide gives the same definition. On models without a digital display, Hotpoint's flashing-LED chart lists F18 as a static (steadily lit, not flashing) light pattern. Hotpoint's advice in both guides is to disconnect the appliance from the mains for a minimum of 2 minutes, reconnect, wait 30 seconds and try starting the machine again, and if the fault remains, to call Hotpoint on 0344 822 4224 to book an engineer. Hotpoint and Indesit are sister brands that share the same fault-code system, and Indesit's technical documentation for the WIL10 washer dryer (the French service file, mod. WIL10FR) gives the engineer's definition: F18 is a communication error between the microprocessor and the DSP (Digital Signal Processor), a second processor on the same electronics, and the only service step listed is to replace the board. There are no connector or wiring checks for it, which points to a fault inside the board itself. For contrast, Hotpoint lists F09 as a software fault (multiple flashing lights, can't select a programme), F12 as an electronic control fault (the machine won't turn on) and, on washer dryers only, F19 as a fan motor or heating fault.

Likely causes

  • A one-off electronics glitch, for example after a power cut, a surge or switching off at the wall mid-cycle, which Hotpoint's 2-minute power reset can clear
  • A communication failure between the main microprocessor and the DSP (Digital Signal Processor) on the control board (Indesit WIL10 service file for the shared Hotpoint/Indesit platform)
  • A failed main control board: the service file's only listed fix for F18 is replacing the board

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Unplug the machine at the wall, or switch it off at the isolator, and leave it for at least 2 minutes, as Hotpoint advises.
  2. Plug it back in, wait 30 seconds, then try starting a programme again.
  3. If the reset works, keep an eye on it. Run the machine from a wall socket rather than an extension lead, and avoid switching it off at the wall mid-cycle.
  4. If washing and water are trapped inside and the door won't open, drain the water through the pump filter at the bottom front (towels and a shallow tray ready) before the engineer visit.
  5. If F18 comes back, stop there. There's nothing to test outside the board, so book an engineer.

🛠 When to call a pro

  • F18 returns after the 2-minute power reset: Hotpoint recommends booking an engineer on 0344 822 4224.
  • The display or buttons stay partly or completely dead: the fix in the shared Hotpoint/Indesit service file is a replacement main board.
  • You're thinking of fitting a board yourself: it has to match your exact model and may need programming, so an engineer is usually the safer route.
  • The machine is under warranty: contact Hotpoint service rather than opening it up.
