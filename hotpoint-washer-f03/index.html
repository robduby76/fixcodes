Code: F03🧺 Hotpoint Washer

Hotpoint Washing Machine F03 Error Code: Temperature Sensing Fault (Wash NTC Sensor)

Reviewed 2026-10-26 · Based on 4 manufacturer & service sources

⚡ Quick answer

F03 on a Hotpoint washing machine is a temperature sensing fault: the machine can't get a sensible reading from the wash temperature sensor (an NTC thermistor), so it won't heat the water. The usual culprits are the sensor itself or its wiring and connector, and less often a stuck heater relay on the main board. Hotpoint's own advice is to book an engineer, but if you're comfortable with a multimeter the sensor check is simple: it should read about 20 kOhm at room temperature.

What the code means

Hotpoint UK's washing machine error code guide lists F03 as "Temperature sensing fault", with the symptom that the machine is not heating on wash or dry settings, and advises calling 0344 822 4224 to book an engineer. UK Whitegoods' engineer fault list for Hotpoint First Edition (HVL series) washing machines and washer dryers gives the technical meaning: the thermistor is open or short circuited, so check the wiring to the temperature sensor and the thermistor itself. Indesit's technical documentation for the WIL10 (the French service file for the electronics Hotpoint and Indesit share) adds that F03 is also raised if the wash heater relay is stuck closed, and that it is flagged when the machine is full of water; its steps are to check connector J8 on the board, measure the NTC between pins 11 and 12 of the J8 harness connector (about 20 kOhm at 20 C), check the wiring, replace the NTC, and finally replace the board. On models without a display the code shows as flashing lights: Whitegoods Help notes a three-flash pattern on single-LED models. For contrast, Hotpoint lists F08 as a heater fault and F13 as the drying temperature sensor fault on washer dryers.

Likely causes

  • A failed wash temperature sensor (NTC thermistor) that reads open or short circuit
  • A loose, corroded or damaged connection at the sensor or at connector J8 on the main board, or a break in the wiring between them
  • The wash heater relay on the main board stuck closed, which the WIL10 service file also reports as F03
  • A failed main control board, the last step once the sensor and wiring test fine

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Switch the machine off and unplug it. If water is still in the drum, drain it through the pump filter at the bottom front, with towels and a shallow tray ready.
  2. Try one power reset: leave it unplugged for a couple of minutes, plug back in and run a short warm wash. If F03 comes back, the fault is real.
  3. If you're comfortable working on appliances: with the machine unplugged, remove the back panel and find the temperature sensor, which on most models is fitted into the heater element at the bottom of the tub. Check its connector is pushed fully home and the wires aren't chafed or burnt.
  4. Measure the sensor with a multimeter. The WIL10 service file gives about 20 kOhm at 20 C (room temperature), and the reading should fall as the sensor warms. Zero or open circuit means the sensor needs replacing.
  5. If the sensor reads correctly, check the wiring back to the main board for continuity and a clean, tight connection.
  6. If the sensor and wiring all check out, the board is the likely fault, so book an engineer.

🛠 When to call a pro

  • You'd rather not open the machine: Hotpoint's own advice for F03 is to book an engineer on 0344 822 4224.
  • The sensor and wiring test fine but F03 persists: the next step is the main board, which must match your exact model.
  • There's burning, scorched wiring or a tripped breaker around the heater: stop using the machine and have it checked.
  • The machine is under warranty: contact Hotpoint service rather than opening it up.
