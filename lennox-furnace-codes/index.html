Lennox Furnace Error Codes: What Each Code Means

Every Lennox furnace code explained on FixCodes, 10 in all. Together they cite 19 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
C2Second-Stage Cooling, Not an Error
C2 on a Lennox furnace or air handler display means the system is running second-stage (high) cooling.
E112Ground Not Detected
Error 112 on a Lennox furnace means the control can't find an earth ground on the furnace's power supply, so it shuts the system down.
E154Refrigerant Leak Sensor #1 Lost Communication

E201Lost Communication With the Blower Motor
Error 201 on a Lennox furnace or air handler means the control board lost communication with the variable-speed indoor blower motor.
E203Unit Size Code Not Programmed
Error 203 on a Lennox variable-speed furnace means the integrated control board doesn't have a valid unit size (capacity) code programmed, so it doesn't know which…
E207Hot Surface Ignitor Sensed Open
Error 207 on a Lennox furnace means the control sensed that the hot-surface ignitor circuit is open, so it will not try to light the burners.
E223Low Pressure Switch Failed Open
E223 on a Lennox furnace means the low-fire (first-stage) combustion air pressure switch did not close when the furnace tried to start a heating cycle, so the control…
E250Limit Switch Circuit Open
Error 250 on a Lennox SureLight furnace means the control sees the primary limit switch circuit open.
E270Soft Lockout, No Flame Current Sensed
Error 270 on a Lennox SureLight furnace is a soft lockout.
E312Restricted Airflow, Blower in Cutback Mode
Error 312 on a Lennox furnace is a warning, not a shutdown.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
