Code: F18🧺 Indesit Washer

Indesit Washing Machine F18 Error Code: Internal Data Error (Main Board Communication Fault)

Reviewed 2026-10-26 · Based on 2 manufacturer & service sources

⚡ Quick answer

F18 on an Indesit washing machine is an internal data error: two processors on the main control board have stopped talking to each other, so some or all of the display and functions stop working. Indesit's own advice is to unplug the machine for at least 2 minutes, plug it back in, wait 30 seconds and try again. If F18 comes back, it's a board fault, and Indesit's service documentation says the fix is replacing the main board, so book an engineer.

What the code means

Indesit Service UK's washing machine error code guide lists F18 as "Internal data error", with the symptom that some or all of the display or functions do not work. Its advice is to disconnect the appliance from the mains for a minimum of 2 minutes, reconnect, wait 30 seconds and try starting the machine again, and if the fault remains, to call Indesit to book an engineer. Indesit's technical documentation for the WIL10 washer dryer (the French service file, mod. WIL10FR) gives the engineer's definition: F18 is a communication error between the microprocessor and the DSP (Digital Signal Processor), a second processor on the same electronics. The only service step it lists is to replace the board. Unlike most other codes in that file, there are no connector or wiring checks for F18, which tells you the fault sits inside the board itself. A power reset is still worth trying, because a one-off glitch (a power cut or surge mid-cycle) can trip it, but a code that keeps returning means the board needs replacing. For contrast, the same Indesit guide lists F09 as a software fault (multiple flashing lights, can't select a programme) and F12 as an electronic control fault (the machine won't turn on), and the WIL10 file describes F12 as a lost connection between the display board and the power board, which does have wiring checks.

Likely causes

  • Communication failure between the main microprocessor and the DSP (Digital Signal Processor) on the control board (Indesit WIL10 service file)
  • A failed main control board: the WIL10 file's only listed fix for F18 is replacing the board
  • A one-off glitch after a power cut, surge or the machine being switched off mid-cycle, which the 2-minute power reset Indesit recommends can clear

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Unplug the machine at the wall (or switch off at the isolator) for at least 2 minutes, as Indesit advises.
  2. Plug it back in, wait 30 seconds, then try starting a programme again.
  3. If the reset works, keep an eye on it. Plug the machine straight into a wall socket rather than an extension lead, and avoid switching it off at the wall mid-cycle.
  4. If water or washing is trapped inside and the door won't open, drain it through the pump filter at the bottom front (towels and a shallow tray ready) before the engineer visit.
  5. If F18 comes back, stop there. There's nothing to test or adjust outside the board, so book an engineer.

🛠 When to call a pro

  • F18 returns after the 2-minute power reset: Indesit recommends booking an engineer.
  • Some or all of the display and buttons stay dead: the fix in Indesit's service file is a replacement main board.
  • You're replacing the board yourself: it must match your exact model number and may need programming for that model, so an engineer is usually the safer route.
  • The machine is under warranty: contact Indesit service rather than opening it up.
