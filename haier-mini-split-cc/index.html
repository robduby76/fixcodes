Code: CC🔧 Haier Mini Split

Haier Mini Split CC Code: Start-Up Installation Test Ready (Meaning, How to Run or Skip It)

Reviewed 2026-10-25 · Based on 3 manufacturer & service sources

⚡ Quick answer

CC on a Haier mini split is not a fault. It means the system is ready to run Haier's built-in ENERGY STAR start-up installation test, and it usually appears for a few seconds when a new system is first powered up. You can let the test run (it shows n1, n2 or n3 while it works and PS when it passes) or skip it by setting the indoor unit to Dry and 68°F while CC is showing; the display then shows BP and the unit works normally.

What the code means

Haier's installation instructions and its Haier/GE multi-zone service manual describe CC as the signal that the unit is ready to enter its pre-programmed installation (start-up system) test, added for ENERGY STAR 6.1 certified product lines released from February 2022. On first power-up the indoor display (and the outdoor display on models that have one) shows CC; the service manual says for 5 seconds. Haier's install manuals add that if CC never appears, the indoor and outdoor combination isn't an ENERGY STAR test-capable match and the unit is simply ready for normal use. While the test runs, the display steps through Fn and n1 (a 3-minute fan test), then n2 (heating) and/or n3 (cooling) depending on outdoor temperature, and shows PS when every check passes. If a check fails, the display shows a regular error code instead and the test stops. BP means the test was bypassed.

Likely causes

  • The system was just powered up for the first time after installation, so it is offering the start-up installation test (normal).
  • Someone started the test on purpose: Haier's manuals say setting the remote to Cool, High fan, 60°F (16°C) and pressing Sleep 4 times brings CC back (on single-zone models, after 5 beeps and a power cycle).
  • Power was cycled before an earlier test finished, so the unit is offering the test again (Haier's manuals note a power cycle is needed before you can bypass a test that has already started).

Safe DIY checks

⚠ Before you start

CC itself needs no repair. If the test turns up a real error code, any work inside the indoor or outdoor unit, on refrigerant or on live wiring should be done by a qualified HVAC technician.

  1. To skip the test: right after power-up, while CC is showing, set the indoor unit to Dry mode and the temperature to 68°F (20°C). The display should show BP for 5 seconds, then go to standby, and the unit can be used normally.
  2. To run the test instead (Haier calls it optional): while CC is showing, set the indoor unit to Heat or Cool and 77°F (25°C). The test starts within 5 seconds and runs about 18 to 23 minutes, showing Fn/n1, then n2 and/or n3. Leave it alone until it shows PS.
  3. If the display already shows n2 or n3, you can't bypass it. Let it finish, or turn the power off and back on and try the Dry/68°F bypass again while CC shows.
  4. Haier suggests skipping the test when it is below -4°F (-20°C) or above 115°F (46°C) outside, because running it then may show a false error code. Run it later when the weather allows.
  5. If the test ends with an error code instead of PS, look up that code (for example E7 or F3) and fix it first, then restart the test. Call your installer or a licensed HVAC technician if you're not sure.

🛠 When to call a pro

  • CC is the entry state for the ENERGY STAR 6.1 installation-capability test. Use it after install to confirm charge and airflow; Haier's service manual gives a 20-minute run table of expected suction, discharge, indoor coil and indoor outlet temperatures by mode and ambient for each multi-zone outdoor model.
  • Test sequence per Haier: Fn/n1 fan mode for 3 minutes; then at 14 to 75°F outdoor, heating and cooling 10 minutes each (n2, n3); at -4 to 14°F, heating only for 15 minutes (n2); at 75 to 115°F, cooling only for 15 minutes (n3); PS on pass.
  • Any failure shows a normal fault code and stops the test. Correct the fault per the service manual, then restart the test from the CC step.
  • Haier's service manual says the start-up test may be bypassed after an outdoor control board has been replaced for service.
  • No CC on power-up means the paired indoor and outdoor units aren't an ENERGY STAR test-capable combination; that is not a fault.
