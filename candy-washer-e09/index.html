Candy Washing Machine E09 Error Code: Motor Control (Triac) Fault on the Main Board

Reviewed 2026-10-26 · Based on 3 manufacturer & service sources

⚡ Quick answer

E09 (shown as E:09 on some displays) on a Candy washing machine means the main board can't drive the drum motor properly. Candy's own service note blames a damaged motor triac on the main power board, or the wiring to the motor. Unplug the machine for a few minutes and try once more, then check the motor plug and wiring for loose or burnt connections. If E09 comes straight back, the board (and sometimes the motor) needs a repair engineer.

What the code means

Candy Hoover Service's technical note 00188/LB, which covers Candy Smart Touch and Hoover One Touch washing machines with the Invensys power board, lists E:09 as "Defective 'Cuore' Power Card (damaged Motor's TRIAC) and/or Wiring". The triac is the electronic switch on the main board (Candy calls it the "Cuore" power card) that feeds power to the drum motor. When the board sees that circuit misbehaving, it stops the programme rather than run the motor uncontrolled, so you'll usually find the drum won't turn, or turns briefly and stops, often with water still inside. For comparison, E:08 is a fault on the motor's speed sensor (tacho) and E:17 is a wrong signal from that sensor, while E:09 points at the board side of the motor circuit. On Candy models with only LEDs, the same note says four LEDs flash together once a second for the number of the error (nine times for E09), then pause, and repeat until the machine is switched off. Independent repair guides such as Whitegoods Help and ASAP Repairs describe E09 the same way, as a triac fault on the control board, and add that a shorted motor or damaged harness can be what took the triac out, so it's worth checking those before fitting a new board.

Likely causes

  • Damaged motor triac on the main ("Cuore") power board, which is Candy's stated cause
  • Loose, burnt or damaged wiring between the main board and the drum motor
  • A motor with a winding shorted to the frame, which can damage the triac and make a new board fail too
  • Board damage after a power surge

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Switch the machine off and unplug it for a few minutes. These Candy machines stay powered in standby even with the knob on OFF, so a full unplug is the real reset. Try one short programme; if E09 appears straight away again, don't keep resetting it.
  2. If there's water in the drum, put towels and a shallow tray down, open the pump filter at the bottom front and drain it before moving the machine.
  3. With the machine unplugged, turn the drum by hand. It should turn freely with no grinding.
  4. If you're comfortable working on an unplugged machine, remove the back panel and check the motor plug is fully seated, with no melted, blackened or corroded pins, and look along the harness to the main board for damage.
  5. With the motor plug off, a multimeter set to continuity should show nothing between any motor terminal and the metal motor frame. Any continuity means the motor is shorted and needs replacing along with the board.

🛠 When to call a pro

  • E09 returns after a reset and the wiring and motor plug look fine, which points to the main board.
  • You can see burn marks on the board or the motor connector, or the machine trips the house electrics.
  • The machine is under warranty: contact Candy's customer service rather than opening it.
