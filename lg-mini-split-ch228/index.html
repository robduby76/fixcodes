Code: CH228🔧 LG Mini Split

LG Mini Split CH228 Error Code: Refrigerant Leak Detector Malfunction (Meaning, Causes, Fixes)

Reviewed 2026-10-24 · Based on 3 manufacturer & service sources

⚡ Quick answer

CH228 on an LG mini split or ductless system means the R32 refrigerant leak detector itself has failed. It is a sensor fault, not a confirmed leak (that is CH230), but LG still says to ventilate the room and contact authorized service when CH228, CH229 or CH230 appears. LG's fix path is to check the detector's connecting cable, then replace the R32 sensor sub PCB or the leak sensor, and only authorized personnel should replace leak detection parts.

What the code means

LG's R32 air conditioner installation manual (MFL05739501) lists CH228 as "Refrigerant leak detector malfunction error," with the error point "Refrigerant leak detector has failed." Newer LG systems that use R32 refrigerant have a leak detector that measures refrigerant in the room air and triggers the leak detection system at 5,000 ppm or higher. CH228 means the controller has lost confidence in that detector, so it can't do its safety job. LG lists two related codes in the same table: CH229 means the detector has reached the end of its lifetime, and CH230 means the detector actually sensed a refrigerant leak. LG also lists 236 as a warning that the detector has less than six months of life left.

Likely causes

  • A broken or shorted sensor inside the refrigerant leak detector, which LG lists first among the main reasons.
  • Abnormal voltage from the detector's DC converter.
  • Abnormal operation of the detector's microprocessor.
  • A connecting cable between the indoor unit and the leak detector that isn't properly connected. LG's flowchart checks this first.
  • On LG Multi V systems with a separate leak detector kit, a damaged connecting cable or a detector setting that doesn't match what's installed. LG's PLDRNV1S manual also says to check the main PCBA if CH228 continues after the sensor assembly is replaced.

Safe DIY checks

⚠ Before you start

R32 is a mildly flammable refrigerant. LG says to ventilate the room and contact authorized personnel when 228, 229 or 230 appears, and that only authorized personnel may replace leak detection parts, using detectors the manufacturer specifies. Don't run a flame or spark source near a suspected leak. Refrigerant handling and repairs must be done by a certified technician (in the US, EPA Section 608 certification is required).

  1. Treat the code seriously even though it's a sensor fault. LG's warning for codes 228, 229 and 230 is to ventilate the room and contact authorized service right away.
  2. Avoid using strong chemicals such as ethanol, hair spray, pesticide or smoke near the indoor unit. LG says the R32 sensor can react to other gases and give a false reading.
  3. Turn the system off at the breaker for a few minutes and back on to see whether the code clears. LG's flowchart steps all start and end with turning the power supply off and on.
  4. If CH228 comes back, don't open the indoor unit to reseat the sensor cable or swap parts yourself. LG says leak detection system replacement must be done by authorized personnel only, using detectors specified by the manufacturer.
  5. If your system is under warranty, LG's US manual says to call the installing contractor, since warranty service is provided through them.

🛠 When to call a pro

  • Checking that the refrigerant leak detector's connecting cable is properly connected. If it isn't, LG's steps are power off, reconnect the connector, power on.
  • Checking whether the red LED on the R32 sensor sub PCB is blinking. Per LG's flowchart, if it isn't blinking, power off, replace the R32 sensor sub PCB and power on.
  • If the red LED is blinking, replacing the R32 refrigerant leakage sensor and resetting the power supply.
  • On Multi V systems with the PLDRNV1S detector kit, confirming the detector is installed and set correctly in the outdoor unit function settings, checking the connecting cable for damage and replacing it if needed, then replacing the sensor assembly and checking the main PCBA if CH228 persists.
  • Remembering that LG says the R32 detector must be replaced after detecting any gas or at the end of its 3,650-day (10-year) lifetime.
