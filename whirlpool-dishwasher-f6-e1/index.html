Whirlpool Dishwasher F6 E1 (F6E1) Error Code: Control Panel Can't Talk to the Main Control

Reviewed 2026-10-23 · Based on 2 manufacturer & service sources

⚡ Quick answer

F6 E1 on a Whirlpool dishwasher is a communication error between the control panel you press (the user interface) and the main control board. Whirlpool's help page calls it a user interface or main control error and says to cut power for 30 seconds, then call for service if the code stays. In Whirlpool's technician manual, the cause is the user interface having power but not hearing from the main control, usually from a loose connection, a broken wire in the harness between them, or a failed communication circuit on the main control.

What the code means

Whirlpool Product Help lists F6E1 as "User Interface Error, Main Control", and the only owner step it gives is cycling power before calling for service. Whirlpool's technical manual W11480208 for Whirlpool, JennAir, Brastemp and KitchenAid 24 inch filtration dishwashers explains the code in more detail: Function 6 is Communication, and Error 1 means "UI does not get communication from main control", where the user interface has power but cannot communicate with the main control board. The manual lists three causes: a loose connection between the user interface and the main control, a broken terminal or wire in the harness between them, or a failed communication circuit on the main control. It also lists F6E1 when one or more keys won't respond or the keys, lights or display behave oddly, pointing to loose connections or bent connector pins between the keypad and the control. On models with a numeric display the code shows as F6 then E1; on models with only status lights, the manual says the Clean or Complete light blinks the Function number (6 times), pauses 2 seconds, then blinks the Error number (once).

Likely causes

  • A loose connection between the user interface (control panel) and the main control board, which Whirlpool's technical manual lists first
  • A broken terminal or wire in the harness that runs between the user interface and the main control
  • Bent, damaged or contaminated connector pins between the keypad and the control
  • A failed communication circuit on the main control board

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Reset the control the way Whirlpool describes: unplug the dishwasher for 30 seconds, or turn off its breaker for 30 seconds if it's hard-wired, then restore power.
  2. Run a cycle and see whether F6E1 comes back. Whirlpool's help page says to call for service if the code remains.
  3. If the keys or lights were acting strangely before the code appeared, note that for the technician. Whirlpool's manual ties F6E1 to keys that won't respond and unusual key, light or display behavior.
  4. If you're comfortable working on appliances and have unplugged the dishwasher or shut off its breaker first, the manual's first check is the harness connection between the main control (connector P1) and the user interface in the door: reseat any loose connector and look for broken wires or bent pins. Leave live-voltage checks to a technician.

🛠 When to call a pro

  • F6E1 stays after a power reset. Whirlpool's help page says to call for service.
  • The harness connections look good but the code keeps returning. Whirlpool's technical manual says the next step is replacing the main control board, which has to match your full model number.
  • You find damaged or contaminated connector pins or a broken wire in the door harness. The manual says to repair or replace the harness or parts with damaged pins.
