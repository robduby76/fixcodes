GE Oven F7 Error Code: Stuck or Shorted Function Key (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 6 manufacturer & service sources

⚡ Quick answer

F7 on a GE range or wall oven points to the touch keypad (GE calls it the keypanel): the control is seeing a function key that is stuck, pressed, or shorted. GE says it often means the keypanel needs to be replaced. Try a power reset at the breaker first; if F7 comes back, the usual fix is a new keypanel, and less often the electronic oven control.

What the code means

GE's own fault-code chart for ranges and wall ovens says F7 "usually means that there is a problem with the keypanel. Many times, it means the keypanel needs to be replaced." GE's range training material describes F7 as a stuck or shorted function key on the keypad. The electronic range control constantly checks the key circuits, which should stay open when no key is pressed; if one reads as closed (stuck or shorted), it flags F7 and shuts off oven functions as a precaution. On newer GE wall ovens with glass-touch controls, the code shows as F7 plus a letter: F7A is a stuck key other than START or CLEAR, F7B a stuck START key, F7C and F7d a stuck upper or lower CLEAR key, F7E a glass-touch communication failure and F7F a glass-touch data check (CRC) failure. GE's service guide for those ovens says that in most cases the failure is in the glass-touch panel and it will most likely have to be replaced.

Likely causes

  • A worn, damaged or moisture-affected key on the membrane keypad (the kind with raised bubbles) that reads as permanently pressed
  • A stuck START or CLEAR/OFF key (some models name which key in an F7 letter code)
  • A failed glass-touch control panel, or a communication fault between it and the control (F7E, F7F on newer wall ovens)
  • A damaged, pinched or corroded keypad ribbon cable or connector
  • Heat damage after a self-clean cycle, which commonly brings out keypad faults on older units
  • Less often, a fault in the electronic oven control's key-sensing circuit

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Touch CLEAR/OFF. GE's owner's manuals say that when an F-code flashes, you should touch CLEAR/OFF, let the oven cool for an hour, and try again; if the code repeats, disconnect power and call for service.
  2. Do a power reset: switch off the oven's circuit breaker (or unplug a freestanding range) for a few minutes, then restore power. GE notes this sometimes clears the code.
  3. Look at the keypad for a key that is cracked, swollen, pushed in or stuck, and wipe the panel dry. Avoid spraying cleaner directly onto the controls.
  4. If F7 keeps coming back, GE recommends leaving the breaker off until the oven is serviced. It's fine to turn the breaker back on just long enough to use the cooktop burners, then off again.
  5. Write down your model number (on a label around the oven door frame or storage drawer) before ordering a keypanel or booking service; keypanels are model-specific.

🛠 When to call a pro

  • The classic GE isolation test: with power off, disconnect the keypad ribbon cable from the electronic control, restore power and wait about 30 seconds. If F7 still appears, the control is at fault; if it doesn't, the keypanel is the problem.
  • Checking each membrane key and the ribbon cable for shorts and continuity with a multimeter, and inspecting connectors for bent pins, corrosion or moisture.
  • Reading stored fault codes from the control's diagnostic mode, which varies by model.
  • Replacing the keypanel or glass-touch panel (the usual repair), and the electronic oven control only if the isolation test points to it.
