Code: F3E2🌀 Whirlpool Dryer

Whirlpool Dryer F3E2 (F3 E2): Moisture Sensor Issue, Meaning and Fixes

Reviewed 2026-10-22 · Based on 4 manufacturer & service sources

⚡ Quick answer

F3E2 on a Whirlpool dryer means a moisture sensor issue: five loads in a row were dried without the dryer registering any data from its moisture sensor strips. Press Power to clear it, make sure the dryer is level, and dry full-sized loads on an automatic cycle. If it keeps coming back, the sensor strips, their harness or the main control need checking.

What the code means

Whirlpool's Product Help says the F3E2 error code occurs when five consecutive loads are dried without registering moisture sensor data, and that pressing Power clears the code so you can restart the dryer. Whirlpool's commercial-grade residential dryers use the same code with the same wording. The moisture sensor is a pair of metal strips inside the drum, usually on or near the lint screen housing. Wet clothes brushing across both strips close a small circuit, which is how automatic cycles know when the load is dry. If clothes never touch the strips, or the strip circuit is open or shorted, the control gets no useful reading. Whirlpool and Maytag technical manual W11416805 groups the strips, their wire harness and the main control (ACU) as the moisture system and gives a service test for it, done when automatic cycles stop too soon or run much longer than expected. The same code means the same thing on Maytag dryers built on this platform.

Likely causes

  • Very small loads or single items that never touch the sensor strips (Whirlpool's first suggestion)
  • Loads dried on Timed Dry rather than an automatic cycle, so the sensor is never used
  • A dryer that isn't level, so clothes don't tumble across the strips
  • Lint, fabric softener or dryer-sheet film on the strips; W11416805 says to clean the strips when the circuit reads a small resistance
  • A loose or damaged moisture sensor harness between the strips and the control (connector J13 on the models in W11416805)
  • Less often, a faulty main control (ACU), which the manual replaces only after the sensor and thermistor checks

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Press Power to clear F3E2, as Whirlpool directs, then restart the dryer.
  2. Dry a normal, full-sized load on an automatic (sensor) cycle instead of Timed Dry so clothes actually reach the sensor strips.
  3. Check that the dryer is level with a level or a phone level app. Whirlpool notes the top may be curved, so measure from the cabinet edge, then adjust the feet.
  4. With the dryer unplugged, find the two metal strips inside the drum and wipe off lint and film. Family Handyman suggests rubbing alcohol until the metal is shiny, which matters most if you use dryer sheets.
  5. If the code returns, follow Whirlpool's power cycle: turn the breaker off for one minute, turn it back on, start a timed dry cycle and watch the dryer for one minute to make sure the code doesn't come back.
  6. If F3E2 still returns, schedule service through Whirlpool or a local technician.

🛠 When to call a pro

  • F3E2 keeps returning after you've cleared it, leveled the dryer, cleaned the strips and run full loads on automatic cycles.
  • Automatic cycles end far too early or keep running until the dryer shuts off on its own; W11416805 notes the dryer stops automatically after 2.5 hours.
  • Running the sensor test in Service Diagnostics. In W11416805 the technician advances to Sensing, opens the door and touches both strips with a wet cloth or finger; if the drum light turns off, the sensor passes.
  • Checking harness continuity from J13 on the control to the 3-wire sensor connector below the door opening, and measuring the strip circuit. That means removing the console and front panel, and per the manual a small resistance after cleaning or any reading to ground means replacing the sensor harness.
  • Replacing the main control, which the manual reserves for when the sensor and outlet thermistor test good.
  • The dryer is under warranty.
