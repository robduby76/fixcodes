Hotpoint Washing Machine F17 Error Code: Door Lock Not Powered or Door Not Closed

Reviewed 2026-10-26 · Based on 3 manufacturer & service sources

⚡ Quick answer

F17 on a Hotpoint (or Hotpoint-Ariston) washing machine is a door lock fault: the electronics either can't see the door as shut or the door lock isn't getting power. Start by shutting the door firmly and checking nothing is caught in the latch or seal. If F17 keeps coming back, the usual suspects are the door hook, the door lock (interlock) itself, its wiring or the main board, so book an engineer.

What the code means

Hotpoint's current UK error code guide doesn't list F17 (on the models it covers, the consumer door lock code is F06), but F17 does appear on Hotpoint and Hotpoint-Ariston machines built on the shared Hotpoint/Indesit electronics. Indesit's technical documentation for the WIL10 washer dryer (the French service file, mod. WIL10FR), which uses the same fault-code system, defines F17 as "door lock not powered or open" and gives two versions of the check, one for machines with the Easy Door lock and one for a traditional door lock. In both, the engineer checks for 230 V mains at the lock connector (J4) on the board, checks that mains comes back out of the door lock, and on Easy Door models checks the door micro-switch reads closed with the door shut and open with it open. The listed fixes, in order, are the wiring between J4 and the lock, the door hook, the door lock, and finally the board. BuySpares, the UK appliance spares retailer, agrees that F17 on Hotpoint and Indesit washers points to the door lock area, either the lock wiring or the board. For contrast, F06 is the door lock fault on Hotpoint's current list, F16 is a drum lock fault on top loaders, and F18 is an internal data error on the main board.

Likely causes

  • The door isn't fully shut, or clothing, a sock or the door seal is caught in the latch so the door switch never reads closed
  • A worn, bent or broken door hook (the catch on the door) that doesn't engage the lock properly (WIL10 service file lists replacing the door hook)
  • A failed door lock (interlock) that isn't passing power through, or whose closed-door micro-switch has failed
  • Damaged or loose wiring between the door lock and the board's J4 connector
  • A fault on the main control board that isn't powering the lock (the last step in the service file)

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Open the door and shut it again firmly until it clicks. Check that no clothing or the rubber door seal is trapped in the gap or the latch.
  2. Look at the hook on the door: if it's loose, bent or cracked, it may not be engaging the lock.
  3. Switch the machine off and unplug it for a couple of minutes, plug it back in and try a programme again. This is general advice for clearing a one-off glitch, not a Hotpoint step specific to F17.
  4. If water is trapped inside and the door won't open, drain it through the pump filter at the bottom front (towels and a shallow tray ready) before anyone works on the lock.
  5. Check whether your model is part of Hotpoint's washing machine door lock safety recall (Hotpoint's error code page links to it) before paying for a repair.
  6. If F17 keeps coming back with the door properly shut, stop there: the lock checks involve live 230 V tests, so book an engineer.

🛠 When to call a pro

  • F17 returns with the door shut and nothing trapped: the service file's checks are live mains-voltage tests at the board and lock, which is an engineer job.
  • The door hook or lock needs replacing and you're not comfortable taking the front of the machine apart.
  • The lock and wiring test fine: the service file's last step is a replacement main board, and Hotpoint/Indesit boards usually need programming to the model.
  • The machine is under warranty or might be covered by the door lock recall: contact Hotpoint service on 0344 822 4224 rather than opening it up.
