Code: F3E2🌀 Maytag Dryer

Maytag Dryer F3E2: Moisture Sensor Issue (Meaning, Causes, Fixes)

Reviewed 2026-10-22 · Based on 5 manufacturer & service sources

⚡ Quick answer

F3E2 on a Maytag dryer is a moisture sensor issue: five loads in a row dried without the dryer getting a reading from its moisture sensor strips. Press Power to clear it, check that the dryer is level, and dry normal-sized loads on an automatic cycle before calling for service.

What the code means

Maytag's Product Help says F3E2 appears when five consecutive loads are dried without registering moisture sensor data, and that pressing Power clears the code so you can restart the dryer. The moisture sensor is a pair of metal strips inside the drum (on many models on the lint screen housing) that wet clothes touch as they tumble. Maytag's technical manuals describe the service-side meaning as an open or shorted moisture sensor strip circuit, made up of the strips, their wire harness and the main control. Some manuals note that this version of F3E2 shows only in Service Diagnostic mode. Whirlpool uses the same code with the same meaning on its dryers.

Likely causes

  • Very small loads or single items that never touch the sensor strips
  • Loads dried on Timed Dry, which doesn't use the moisture sensor
  • Dryer not level, so clothes don't brush against the strips
  • Residue or lint on the sensor strips (Maytag's technical manual says to clean the strips when the circuit reads a low resistance)
  • Loose or damaged moisture sensor wire harness between the strips and the control (connector J13 on the models covered by technical manual W11576955)
  • Less often, a faulty main control (ACU)

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Press Power to clear F3E2, as Maytag directs.
  2. Dry a normal-sized load on an automatic (sensor) cycle rather than Timed Dry, so the clothes reach the sensor strips.
  3. Check that the dryer is level, measuring from the cabinet edge since the top may be curved, and adjust the feet.
  4. With the dryer unplugged, find the two metal strips in the drum and wipe off lint and film. Family Handyman suggests rubbing alcohol until the metal is shiny, especially if you use dryer sheets.
  5. If the code returns, turn the dryer off at the breaker for one minute, turn it back on, start a timed dry cycle and watch it for a minute, per Maytag's power-cycle steps.
  6. If F3E2 keeps coming back, call Maytag at 1-800-344-1274 or a technician.

🛠 When to call a pro

  • F3E2 returns after you've cleared it, leveled the dryer, cleaned the strips and dried full loads on an automatic cycle.
  • Automatic cycles stop much too soon or run until the dryer shuts itself off (Maytag's manual says it stops automatically after 2.5 hours).
  • Testing the sensor harness for continuity or measuring the strip circuit, which means removing the console and working on the control.
  • Replacing the moisture sensor, its harness, or the main control.
  • The dryer is under warranty.
