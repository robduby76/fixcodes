Samsung Microwave Error Codes: What Each Code Means

Every Samsung microwave code explained on FixCodes, 5 in all. Together they cite 16 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
C-10Cooking (Gas) Sensor Fault
C-10 on a Samsung microwave means the control has a problem reading the cooking sensor, the gas/humidity sensor that the Sensor Cook and auto-cook buttons rely on.
C-d1Door or Key Error
C-d1 on a Samsung microwave is one of Samsung's door or key errors (the C-d0, C-d1 and C-d2 group).
C-F2Touch Key Communication Problem
C-F2 on a Samsung microwave (shown as -tE- or -TE- on some models) means the control lost normal communication with the touch keys.
E-11Open Gas (Cooking) Sensor Error
E-11 on a Samsung microwave means the control has lost the signal from the gas sensor, the humidity/cooking sensor that Popcorn, Sensor Reheat and the other auto-cook…
SEA Touch Key Is Stuck or Shorted
SE on a Samsung microwave (it can also read 5E, -SE- or C-d0 on some models) means the control thinks a touch key has been held down for more than 10 seconds.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
