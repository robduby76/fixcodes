Code: F09🧺 Hotpoint Washer

Hotpoint Washer F09 Error Code: Software Fault (Flashing Lights, Can't Select a Programme)

Reviewed 2026-10-26 · Based on 5 manufacturer & service sources

⚡ Quick answer

F09 on a Hotpoint washing machine (the UK and European Hotpoint made by Whirlpool EMEA, formerly Indesit Company) is a software fault. Hotpoint says the machine won't operate, several lights or the display flash, and you can't select a programme. Unplug it for a few minutes and try again, but if F09 comes back it needs an engineer, because the fix is usually reprogramming or replacing the main control board's memory.

What the code means

Hotpoint UK's washing machine error code guide lists F09 as a "Software fault": the washing machine is not operating, multiple lights and/or the display are flashing, and you can't select a programme. Hotpoint's advice is to call its service centre to book an engineer. Indesit, the sister brand built on the same electronics, lists F09 the same way. Indesit Company's own service documentation explains what sits behind it. The Arcadia service manual describes F09 as a setting file error detected by the main PCB or the display PCB, and its remedy is to disconnect the machine for 2 minutes and check for correct operation, then reprogram the main PCB, renew the main PCB, or renew the display PCB. An Indesit Company service bulletin for electronic washing machines (LB2000 and EVO II) calls F09 a machine setup error (EEPROM error) and notes it can appear after a control card or EEPROM memory chip has been replaced with one that isn't a matching, compatible part. In plain terms, the control board can't read the setup data that tells it which machine it's in, so it refuses to run. That's different from F01 and F12, which are circuit board and board communication faults, and from F18, an internal data error that Hotpoint also suggests a 2-minute power reset for. This page covers UK and European Hotpoint models; US Hotpoint washers are made by GE and use different codes.

Likely causes

  • The main control board can't read or doesn't accept its setup (configuration) file, stored in its EEPROM memory chip
  • A replacement main board or EEPROM that wasn't programmed for your exact model, or isn't compatible with the board it was fitted to (Indesit Company service bulletin STN-WM-0405.1)
  • A glitch after a power cut or surge that a full power reset can sometimes clear
  • A fault on the display (user interface) board, which the service manual lists as a possible part to renew
  • Less often, poor connector contacts between the main and display boards

Safe DIY checks

⚠ Before you start

Unplug the machine before any check. Don't open the back or front panels or handle the control boards yourself; they carry mains voltage and can hold a charge. Never open the door with hot water in the drum.

  1. Switch the machine off and unplug it at the wall for at least 2 minutes, then plug it back in, wait 30 seconds and try selecting a programme again. That's the reset Hotpoint gives for its board and data faults (F01 and F18) and the first step in Indesit Company's service manual for F09.
  2. If the door is locked with water in the drum, don't force it. Leave the machine unplugged and see the F05 guidance on draining through the pump filter before anything else.
  3. If F09 appeared right after a board was replaced, contact whoever fitted it, because the new board or memory chip may not match your model.
  4. If F09 comes back after the reset, book a Hotpoint engineer (Hotpoint UK 0344 822 4224). Reprogramming the board needs Hotpoint's service tools and isn't something you can do at home.

🛠 When to call a pro

  • F09 comes back after a 2-minute power reset: Hotpoint says to book an engineer.
  • The engineer checks connector contacts between the boards, then reprograms the main board's setup file for your model, or replaces the main board (or a socketed EEPROM) with a correctly programmed part, and if that doesn't clear it, replaces the display board.
  • You're offered a used or generic control board: make sure it's programmed for your exact model number, because a mismatched board or EEPROM is a known cause of F09.
  • The machine is still under warranty or extended cover: use Hotpoint service first.
