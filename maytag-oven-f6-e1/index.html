Code: F6 E1♨️ Maytag Oven

Maytag Oven F6 E1 Error Code: Over Temperature or Control Communication Fault (Meaning, Causes, Fixes)

Reviewed 2026-10-25 · Based on 6 manufacturer & service sources

⚡ Quick answer

F6 E1 (F6E1) on a Maytag range or wall oven is a control-system fault. On most Maytag electronic ranges from about 2019 to 2021, the tech sheets define it as an oven over-temperature during cooking (the oven read hotter than about 600°F). On some newer Maytag ranges it instead means the main control and the display have lost communication. Either way, Maytag's first step is a one-minute breaker reset. If F6 E1 comes back, stop using the oven and have the sensor, wiring and control checked.

What the code means

Maytag's Product Help pages list F6 E1 on ranges as a possible problem with the Appliance Manager (the main oven control) or its wiring, and on wall ovens as the Appliance Manager Control, the Converter Control or the wiring, with a one-minute breaker reset as the owner fix. Maytag's technician tech sheets are more specific, and they differ by control. On ranges covered by tech sheets W11393920 and W11503318, F6 E1 is "Over temperature cook" (F6 E2 is over temperature during Self-Clean, F6 E3 is the warming drawer). The Whirlpool/Maytag range service manual W11174814 explains that on LCX-control ranges the code sets when the control reads an oven temperature near 600°F (316°C), and on MRC-control ranges the listed fix is replacing the control. On some newer models, such as the MFES8030RZ0 electric range, the tech sheet (W11639167, as listed by MyPros+) defines F6E1 as a communication failure between the main control (ACU1) and the display (HMI1). So the same code can mean the oven really got too hot, the control got a false high reading from the sensor or its wiring, or the two control boards stopped talking. Check your model number's tech sheet, usually tucked behind the lower kick panel or inside the control panel, to see which one applies.

Likely causes

  • A temporary control glitch, for example after a power surge or outage, that clears with a power reset
  • A loose or backed-out terminal at the oven sensor connector on the control board, which can make the control read a false high temperature
  • A faulty oven temperature sensor (it should read about 1,000 to 1,200 ohms at room temperature on these ranges)
  • Damaged wiring between the oven sensor and the control board
  • A failed main control board, for example a bake or broil relay stuck on so the oven keeps heating past the set temperature
  • On newer ranges and some wall ovens, a loose or damaged harness between the main control and the display, or a failed display or converter board

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. If the oven is hot or you smell burning, turn it off, keep the door closed and let it cool. Don't cook with it while the code is showing.
  2. Reset the power the way Maytag recommends: turn off the range's circuit breaker(s) for one minute, turn them back on, and watch the display for one minute to make sure F6 E1 doesn't come back. Then verify the oven works.
  3. Run a normal Bake at a moderate temperature with an oven thermometer inside. If the oven heats far past the set temperature, or keeps heating after it should cycle off, turn it off at the breaker and call for service.
  4. Note whether the code showed up during baking, during Self-Clean, or with the oven off. That helps a technician tell an over-temperature fault from a communication fault.
  5. If you're comfortable with basic electrical checks: with the breaker off and the oven cool, remove the rear access cover and make sure the oven sensor connector is fully seated. Maytag's service manual lists a backed-out terminal there as a first check.
  6. With power off, test the sensor with a multimeter. Maytag's tech sheets list 1,000 to 1,200 ohms at room temperature as normal. A reading far outside that means the sensor should be replaced.

🛠 When to call a pro

  • F6 E1 comes back after the one-minute breaker reset.
  • The oven gets much hotter than the set temperature or heats when it's supposed to be off. That points to a stuck relay on the control board and is a fire risk, so leave the breaker off.
  • The sensor and its wiring test good. Maytag's tech sheets then call for replacing the control.
  • The display goes blank, freezes or won't respond along with the code, which fits a control-to-display communication fault on newer models.
  • The range is under warranty. Call Maytag at 1-800-344-1274 or schedule service rather than opening it up.
