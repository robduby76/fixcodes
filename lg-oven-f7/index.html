LG Oven F7 Error Code: Upper Convection Fan Error (Meaning, Causes, Fixes)

Reviewed 2026-10-23 · Based on 4 manufacturer & service sources

⚡ Quick answer

F7 on most LG ranges and ovens means an upper convection fan error: the control isn't seeing the convection fan run. Press CLEAR/OFF and try again, then reset the breaker for 30 seconds. If F7 keeps coming back, the fan motor, its wiring or the main control board needs a technician. A few older LG electric ranges use F7 differently, as an oven not-heating code, so check your model.

What the code means

LG USA's range error code list says F7 indicates an Upper Convection Fan Error, and its only owner steps are pressing CLEAR/OFF to retry the function, then turning the breaker off for 30 seconds; if the code continues, the range needs service. LG's authorized service center Bayside Appliance lists F7 the same way, and lists F17 separately as a convection fan error on other models. The independent reference site lgerrorcodes.com describes the condition behind F7 as the convection fan's operation not being detected for over 1 minute, and points first to the wiring harness at the convection fan and the main control board. Model matters here: LG Canada's help library describes F-7 on some electric ranges as a not-heating code (the oven doesn't get above 150°F for 5 minutes or more while preheating with the door closed), and lgerrorcodes.com names older electric ranges LRE3012, LRE30451, LRE30453 and LRE30757 as using F7 that way. On those models, follow the not-heating steps instead.

Likely causes

  • The upper convection fan motor has failed or is seized, so the control never sees it running
  • Something is blocking the convection fan blade behind the rear oven wall cover
  • A loose, damaged or heat-burnt wire or connector between the convection fan and the main control board
  • A fault on the main control board's fan circuit
  • A one-time glitch after a power interruption, which a reset clears
  • On some older LG electric ranges (such as LRE3012, LRE30451, LRE30453, LRE30757): the oven isn't heating, a different fault that shares the F7 number

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Press CLEAR/OFF and try the cooking function again, as LG instructs.
  2. If F7 comes back, turn the range's circuit breaker off, wait at least 30 seconds (LG Canada suggests 3 to 5 minutes), then turn it back on.
  3. With the oven cool and the power off, look through the slots in the rear oven wall to make sure no foil, rack or cookware is touching or jamming the fan.
  4. Note whether the fan runs at all when you start a convection mode, and whether the oven still heats in plain Bake. That helps the technician.
  5. Check your model number (on the label on the warming drawer or storage drawer frame). If it's one of the older LRE3012, LRE30451, LRE30453 or LRE30757 ranges, treat F7 as an oven not-heating code.
  6. If the code keeps returning, LG's advice is to schedule service. Don't keep running convection modes while it's showing.

🛠 When to call a pro

  • Confirming the model's code meaning in the range's service manual or tech sheet before ordering parts.
  • With the power off, removing the rear oven wall cover and checking that the convection fan blade spins freely and is secure on the motor shaft.
  • Checking the convection fan motor and its harness for continuity and burnt or loose terminals, from the motor back to the main control board.
  • Running the fan in the service test mode to see whether the motor gets voltage and runs.
  • Replacing the convection fan motor, the harness or, only after those test good, the main control board, then confirming the code is cleared.
