Code: F5🔧 LG Microwave

LG Microwave F5 Error Code: Damper Switch Error (What to Do)

Reviewed 2026-10-26 · Based on 5 manufacturer & service sources

⚡ Quick answer

F5 (shown as F-5) on an LG microwave is a damper switch error: the control board asked the vent damper to move and its switch never confirmed the new position. It belongs to over-the-range models with a vent damper. Unplug the microwave for a minute and plug it back in; if F5 comes back, LG says service is needed, and the fix is usually the damper switch, the damper motor or the wiring to them.

What the code means

LG's microwave error code guide in its help library, the same chooser that lists F1 (main board), F2 (thermistor), F3 (control panel), F4 (humidity sensor) and F11 (inverter communication), lists F5 as a damper switch error that needs service. The damper is the flap in the vent path of an over-the-range microwave, the kind that sits above a cooktop and doubles as a range hood. A small motor moves it and a switch reports its position back to the main board. LG's service-tech reference for this code puts it plainly: the main board doesn't see the damper motor move when it calls for it, so the problem is either the damper motor or the switch, and the first check is the motor and switch connections. LG's first step for any F code is the same: the symptom may be a temporary error, so unplug the microwave, plug it back in and see whether the code returns, and book an inspection if it does. One note on conflicting tables: Appliance Aid's NeoChef chart lists F-5 as a humidity sensor error, but LG's own NeoChef service manual and help library put the humidity sensor at F4, so on a current LG microwave read F5 as the damper. If your microwave is a countertop model with no vent, check the code again and see our LG F4 page.

Likely causes

  • A damper switch that no longer confirms the damper's position (LG's named fault)
  • A damper motor that doesn't move the flap when the main board calls for it
  • A loose, corroded or damaged connector or wire at the damper motor or switch, which LG's service guidance says to check first
  • A damper flap that is stiff or blocked, for example by grease build-up or something lodged in the vent path
  • Less often, the main control board not driving the damper motor

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Unplug the microwave or switch off its breaker for a minute, then restore power. LG says F codes can be temporary errors that clear this way.
  2. If F5 came up right after a storm, power cut or new installation, try the reset once more before booking service.
  3. Check that nothing is blocking the vent openings on top of or around the microwave, and that the duct or recirculating grille isn't packed with grease or debris you can reach without tools.
  4. Clean the grease filters under the microwave as your owner's manual describes, since heavy grease in the vent area can make moving parts stiff.
  5. Write down your full model number and the exact code before you call, so the technician brings the right damper parts.
  6. Don't open the cabinet to reach the damper switch or motor. A microwave holds a high-voltage capacitor that can stay charged after it is unplugged.

🛠 When to call a pro

  • F5 returns after a power reset: LG says the code needs service, and a technician checks the damper motor and switch connections first, then the parts themselves.
  • The vent fan runs but air comes out the wrong way, or you hear the damper motor buzzing without moving: book service, since the damper motor or its linkage is the likely part.
  • A new damper switch or motor doesn't clear F5: the technician checks the wiring back to the main board and then the board.
  • The microwave is under LG's warranty: use LG service rather than opening it.
