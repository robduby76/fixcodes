Code: EC🔧 Senville Mini Split

Senville Error Code EC (EL 0C): Refrigerant Leak / System Low on Refrigerant (Meaning, Causes, Fixes)

Reviewed 2026-10-25 · Based on 6 manufacturer & service sources

⚡ Quick answer

EC on a Senville mini split (shown as EL 0C on newer models) is the refrigerant leakage detection code: the unit thinks the system is low on refrigerant and shuts down to protect the compressor. Senville says to switch the power off, wait 15 minutes and restart. If the code comes back, a technician needs to check the indoor coil sensor, look for a leak, check pressures and, last, replace the indoor board. It isn't the same as EH C1 or EC C1, which come from a refrigerant gas sensor on newer R-454B units.

What the code means

Senville's support article groups EC and EL 0C together and says they mean there's a problem with the refrigeration system. Senville's Leto user manual describes Refrigerant Leakage Detection as the indoor unit automatically displaying "EC" when the unit detects refrigerant leakage, and the Senville multi-zone installation manual lists EL 0C as "Refrigerant leakage detection". The Aura service manual calls EL 0C "System lacks refrigerant" (troubleshooting sheet TS06-INV) and explains that the unit judges the refrigeration system abnormal from the number of compressor stops and the changes in operating readings caused by excessive discharge temperature. In other words, the control isn't measuring refrigerant directly; it infers a shortage from how the system behaves. Note: EH C1 (refrigerant sensor detects leakage) and EC C1 (another indoor unit's sensor detected a leak, multi-zone) are separate codes from the gas sensor fitted to newer units, with their own Senville articles.

Likely causes

  • A refrigerant leak, for example at the flare connections on the line set, so the system is undercharged.
  • A system that was undercharged from the start, such as a long line set that needed extra refrigerant that was never added.
  • A loose evaporator coil temperature sensor (T2) on the indoor coil, which gives the board false readings (Senville's first check if air is still blowing warm or cool).
  • A room temperature sensor (T1) sitting too close to the evaporator coil.
  • A faulty indoor control board (Senville's last step once sensors, leaks and pressures check out).

Safe DIY checks

⚠ Before you start

Refrigerant work requires EPA Section 608 certification and proper recovery, vacuum and charging equipment. Newer Senville units use R-454B, a mildly flammable refrigerant, so leak checks must use detectors suitable for it and no open flames. Senville says these procedures must be performed by a certified HVAC contractor.

  1. Turn off power to the unit, wait 15 minutes and turn it back on (Senville's initial reset).
  2. Hold your hand in front of the indoor air outlet while it runs. Note whether cool or warm air is coming out; it tells the technician whether to start with the sensors or with a leak search.
  3. Clean or replace dirty indoor filters and clear anything blocking the indoor or outdoor unit, so poor airflow isn't adding to the problem.
  4. If the code returns, call a licensed HVAC technician. Senville says these procedures must be performed by a certified HVAC contractor, since they involve the refrigerant circuit.

🛠 When to call a pro

  • If cool or warm air is blowing from the indoor unit, check whether the T2 evaporator coil sensor is loose and secure it. If T2 is fine, check whether the T1 room sensor is too close to the evaporator and reposition it. If both are correct, replace the indoor PCB (Aura service manual TS06-INV flowchart).
  • If no conditioned air is coming out, check the system for refrigerant leaks. If a leak is found, repair it and recharge the refrigerant.
  • If no leak is found, attach gauges to the low-side service port on the outdoor unit and compare the pressure with the manufacturer's specification for the current ambient temperature. If it's low, add refrigerant (Senville says about 10% of the nameplate charge).
  • If pressures are within range and the code persists, replace the indoor PCB.
