Code: F6 E8🔧 Whirlpool Microwave

Whirlpool Microwave F6 E8 Error Code: Lost Communication with the Microwave Control

Reviewed 2026-10-25 · Based on 4 manufacturer & service sources

⚡ Quick answer

F6 E8 shows up on Whirlpool-family built-in microwaves and microwave/wall oven combination units, and it means the main user interface lost communication with the microwave's own control board (the Microwave Appliance Manager, or ACU). Whirlpool's first step is a power reset: turn the breaker off for one full minute, turn it back on, and watch for a minute. If F6 E8 comes back, the fix is a check of the harness between the two boards, then a new microwave control board, and only if that doesn't clear it, a new user interface board. That repair is a technician job.

What the code means

Whirlpool's Product Help article for F6 E8 on built-in microwaves says there may be a problem with the Microwave Appliance Manager Control or the associated wiring, and lists a power reset as the owner step: circuit breaker off for one minute, back on, then monitor the oven for one minute and verify it works. Whirlpool added F6 E8 to its combination ovens in 2011 because the older F6 E0 code (lost communication) was too vague. Technical Service Pointer W10538518 (September 2012, JennAir built-in microwaves and combination ovens) defines F6 E8 as lost communication with the Microwave AM, alongside F6 E6 for the upper oven and F6 E9 for the lower oven. Whirlpool's Smart Wall Oven service manual W11174422 gives the current procedure: cycle power, confirm the code in the diagnostics menu, make sure the oven is plugged in and the microwave light comes on when the door opens, turn Sabbath mode off, then with power off check the harness between the UI board (J1-3 yellow, J1-4 orange) and the Microwave ACU (P26-3 orange, P26-4 yellow). If the harness is good, replace the Microwave ACU; if the code returns, replace the UI. This is a different fault from plain F6 on over-the-range microwaves, which points to the relay control board.

Likely causes

  • A loose, unplugged, or damaged wire in the communication harness between the user interface board and the microwave control board, the first thing Whirlpool's service manual has a technician check
  • Sabbath mode left on, which Whirlpool's service procedure says to turn off before diagnosing
  • A temporary communication glitch after a power blip, which a one-minute breaker reset clears
  • A failed Microwave Appliance Manager (microwave ACU) control board, Whirlpool's replacement once the harness checks out
  • A failed user interface board, Whirlpool's last step if a new microwave control board doesn't clear the code

Safe DIY checks

⚠ Before you start

Built-in microwave and combination ovens run on a 240-volt or dedicated circuit and the microwave holds dangerous high voltage in its capacitor even after power is off. Leave board and harness work behind the panels to a trained technician.

  1. Turn off the circuit breaker(s) for the oven for one full minute, turn them back on, and watch the display for a minute. This is Whirlpool's own first step.
  2. Open the microwave door and check that the light comes on. If nothing in the microwave section has power, check the breaker and the household supply before anything else.
  3. Make sure Sabbath mode is off. On Whirlpool's smart wall ovens that's under Tools, then More Modes, then Sabbath.
  4. If F6 E8 returns, note the full model and serial number from the label and book service. Ask the technician to check the UI-to-microwave harness before replacing a board.

🛠 When to call a pro

  • F6 E8 comes back after a one-minute breaker reset: book service. Whirlpool's procedure goes harness check, then microwave control board, then user interface board, all behind panels on a built-in unit.
  • The microwave section has no power at all (no light when the door opens) but the oven works: a technician should check the supply to the microwave control board.
  • You see F6 E6 or F6 E9 too: those point to the upper and lower oven controls, so mention every code to the technician.
