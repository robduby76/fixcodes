Code: EAS (EA5)🔥 Goodman Gas Furnace

Goodman Furnace EA5 (EAS) Code: R-32 Refrigerant Sensor Fault (Meaning, Fixes)

Reviewed 2026-10-23 · Based on 4 manufacturer & service sources

⚡ Quick answer

If your Goodman furnace display reads EA5, it's almost certainly showing EAS: on a seven-segment display the letter S looks just like a 5, and Goodman's code tables list EAS but no EA5. EAS means the R-32 refrigerant leak sensor on the indoor coil has reported a fault of its own. The furnace goes into mitigation mode, so it stops heating and only the fan runs. Goodman's fix is to check the sensor and replace it if the fault stays.

What the code means

Goodman's R-32-ready gas furnaces (for example the GR9S96, GD9S96 and GR9S92 families) have a control board that watches a refrigerant leak sensor mounted on the indoor evaporator coil, so it can shut off the gas and run the blower if R-32 leaks. The wiring-diagram status table lists four A2L (mildly flammable refrigerant) alarms: EAF for lost communication with the sensor, EAL for a detected refrigerant leak, EAS for an A2L internal alarm, and EAr for a fault in the board's A2L relay. Goodman's troubleshooting chart describes EAS as "R-32 sensor has detected a fault and the furnace is in mitigation mode," with the symptom that the furnace stops heating and only the fan operates. So EAS isn't a leak reading and isn't a lost connection: the board is still talking to the sensor, and the sensor itself is reporting that something is wrong with it. Goodman doesn't publish an EA5 code; the display uses a lowercase-style S that reads as 5, which is why so many people search for EA5.

Likely causes

  • The R-32 sensor on the indoor evaporator coil has an internal fault and is reporting it to the furnace control, which is what Goodman's chart lists for EAS
  • A failed or damaged R-32 sensor that needs to be replaced, the corrective action Goodman gives when the fault doesn't clear
  • A sensor wire that's pinched, chafed or routed near hot surfaces or sharp edges, which Goodman's routing notes warn against (worth checking, though a fully lost signal usually shows EAF instead)
  • Mistaking a different A2L code for EAS: EAF (lost sensor communication), EAL (refrigerant leak detected) and EAr (board relay fault) all show the same no-heat, fan-only symptom

Safe DIY checks

⚠ Before you start

Turn off power at the furnace/HVAC service switch and the breaker before opening panels. Shut the gas valve before any work near the burners, and never disconnect or alter the gas line. If you smell gas, leave the house and call your gas utility.

  1. Read the display carefully and write down exactly what it shows. EA5 on a Goodman furnace is the EAS code; if it reads EAL instead, the sensor thinks it smells refrigerant, so treat it as a possible leak and call a technician.
  2. Leave the blower running. In mitigation mode the furnace runs the fan on purpose to clear any refrigerant from the coil area, and it won't heat until the fault clears.
  3. Turn the furnace off at its service switch or breaker for about a minute, then back on. At startup the board looks for the sensor again; a green LED next to the sensor connection on the control board stays on during startup, then blinks if the sensor is talking to the board or goes off if there's no signal.
  4. With the power off, look at the sensor wire where it runs from the indoor coil into the furnace blower compartment and plugs into the control board. Make sure it's plugged in firmly and isn't crushed, cut or touching anything hot.
  5. To see past codes, press the left or right button until the display shows L6F (printed "L 6 F" in the manual), then press the center button to view stored faults. Goodman says pressing and holding the center button for 5 to 30 seconds erases them; the display flashes three dashes when it's done.

🛠 When to call a pro

  • EAS comes back after a power cycle. Goodman's corrective action is to investigate the R-32 sensor and replace it, which means working on the indoor coil.
  • Replacing the R-32 refrigerant sensor with the exact part for your coil and furnace. The sensor is matched to the A2L system, so it isn't a generic part.
  • Any doubt about whether the system actually uses R-32. Goodman says the R-32 function must stay on for furnaces paired with an R-32 outdoor unit and should only be turned off in the A2E menu for R-410A systems or furnace-only installs, so a tech should confirm which you have before changing it.
  • Checking for a real refrigerant leak if the code ever changes to EAL, or if the cooling isn't working well.
  • You smell gas or a carbon monoxide alarm sounds. Leave the house and call your gas utility from outside.
