Code: 6E / bE🧺 LG Dishwasher

LG Dishwasher 6E Error Code: It's Really bE, Too Many Suds (Meaning, Causes, Fixes)

Reviewed 2026-10-22 · Based on 4 manufacturer & service sources

⚡ Quick answer

LG doesn't list a 6E code. On the dishwasher's digital display a lowercase b looks almost exactly like a 6, so a 6E is almost always bE, LG's bubble error. It means the dishwasher detected too many suds, usually from hand dish soap, liquid detergent or too much detergent. Switch to powder or solid dishwasher detergent, clear the foam with LG's milk cycle, and request service if bE shows with no suds at all.

What the code means

LG's US support pages define bE as a bubble error: if hand dish soap or a liquid dishwashing detergent makes excessive bubbles, suds can leak out of the dishwasher, so the control shows bE to prevent that leak. LG's error-code guide gives two causes, oversudsing from dish soap and oversudsing from adding too much detergent. LG's own code lists have no 6E entry. On a seven-segment display a lowercase b uses the same segments as a 6 except the top bar, which is why owners read bE as 6E, and repair guides such as Check Appliance and MachineLounge treat 6E as the same code as bE. Look closely at the first character: if it curves like a lowercase b (or a 6), use this page. If it is made of straight lines like an L, the code is LE, which LG says is a wash (cleaning) motor problem that needs a technician.

Likely causes

  • Hand dish soap or regular kitchen detergent used in the dishwasher. LG says never to use it, because it makes far more suds than dishwasher detergent
  • Liquid dishwashing detergent, or too much of it. LG recommends powder or solid detergent made for dishwashers and only a small amount if you use liquid
  • Too much detergent, or a high-sudsing detergent such as an eco-friendly type 1 detergent. LG says these can cause bE now and then depending on how dirty the dishes are
  • Dish soap residue left on dishes that were prewashed by hand before loading
  • A unit that isn't level, which third-party repair guides list alongside detergent as a bE (6E) cause; LG's bE pages don't mention leveling
  • If there are no suds at all, a sensor or control problem that LG says needs service

Safe DIY checks

⚠ Before you start

Unplug the appliance (or switch off its breaker) and shut off the water supply valves before removing panels or disconnecting hoses. Keep towels handy for residual water.

  1. Open the door and look for foam in the tub. If suds are spilling onto the floor, turn off the dishwasher and wipe up the water first.
  2. Check what detergent went in. Stop using hand dish soap or liquid dish soap, and switch to a powder or solid detergent made for dishwashers, as LG directs. Use one pod or tablet, or less powder.
  3. Clear the foam with LG's milk cycle: set the rinse aid level to L0, put no detergent in the dispenser, place a bowl with 200 to 300 ml (about 7 to 10 oz) of milk in the middle of the upper rack, and run the Normal cycle.
  4. If foam is still there afterward, repeat the milk cycle. LG notes that detergents and rinse aids vary by brand, so it can take more than one run.
  5. Set the rinse aid level back to where you had it once the suds are gone.
  6. To confirm the detergent was the cause, run the empty dishwasher without any detergent, as LG suggests. If foam and bE come back with no detergent at all, the earlier detergent was the problem and suds are still in the system, so repeat the milk cycle.
  7. Check that the dishwasher sits level side to side and front to back, then run a normal load with the correct detergent.

🛠 When to call a pro

  • bE (6E) shows even though there are no suds in the tub. LG says to request service.
  • The code keeps coming back after you've switched to powder or solid dishwasher detergent and cleared the foam.
  • The first character is actually an L (LE). LG says the LE wash motor error requires inspection by a service technician.
  • Water reached the floor or the code changes to AE, E1 or FE, which LG ties to a leak or too much water in the base. See the LG AE page for drying the base pan.
