Code: F08🧺 Hotpoint Washer

Hotpoint Washer F08 Error Code: Heater Fault (Programme Pauses Mid-Wash)

Reviewed 2026-10-26 · Based on 4 manufacturer & service sources

⚡ Quick answer

F08 on a Hotpoint washing machine or washer dryer (the UK and European Hotpoint made by Whirlpool EMEA) means a heater fault. Hotpoint says the programme pauses part way through the wash and recommends booking an engineer. Indesit service documentation for the same platform explains that the board raises F08 when the wash heater relay appears stuck on while the drum is empty, or when the pressure switch reports empty and full at the same time. A power reset is worth one try, but a repeat F08 needs an engineer. This code applies to UK and European Hotpoint machines, not the GE-made Hotpoint washers sold in the US.

What the code means

Hotpoint UK's washing machine and washer dryer error code guides both list F08 as a "Heater fault", with the issue "During a wash cycle the programme pauses part way through", and advise calling Hotpoint to book an engineer. Indesit, Hotpoint's sister brand, lists F08 the same way. Indesit's WIL10 service documentation (a French technician document for the same control platform) is more specific: F08 means the wash heater relay is stuck (detected when the machine is empty), or the pressure switch is stuck on full, so the board sees empty and full at the same time. In other words, the board is getting a signal that the heater could be powered with no water to cover it, so it stops the programme to protect the machine. F08 is not the same as F07, which Hotpoint lists as a circuit board or heating circuit fault where the machine doesn't heat and the pump runs continuously. Some older third-party code lists give F08 a different meaning, so go by Hotpoint's own guide and your instruction booklet.

Likely causes

  • A wash heater relay on the control board that is stuck closed, so the board sees the heater circuit live while the drum is empty (Indesit service documentation)
  • A pressure switch (water level sensor) stuck on full, so it reports empty and full at the same time (Indesit service documentation)
  • A blocked or split pressure switch hose or air chamber, which can make the level reading wrong (general appliance repair practice)
  • Poor contacts or damaged wiring at the control board connector that carries the pressure switch and heater connections
  • A faulty heating element or loose heater terminals
  • Less often, a failed main control board

Safe DIY checks

⚠ Before you start

Unplug the machine before removing any panel. The heater and control board carry mains voltage, and testing the heater relay, pressure switch and wiring is a job for a qualified engineer. Don't keep running a machine that shows F08, since the fault can mean the heater circuit isn't being switched safely. Never open the door with hot water inside.

  1. Note the code and when it appeared. Hotpoint describes F08 as the programme pausing part way through a wash.
  2. Switch the machine off and unplug it for a couple of minutes, plug it back in and try a short programme. If F08 doesn't come back, it may have been a one-off.
  3. Check that the water supply tap is fully on and the inlet hose isn't kinked, so the machine fills normally before it tries to heat.
  4. If water is left in the drum, clear the pump filter as you would for F05 before running another programme, and never open the door with hot water inside.
  5. If F08 comes back, stop using the machine and book an engineer (Hotpoint UK 0344 822 4224). Hotpoint doesn't list any user fix for this code.
  6. Have your model and serial number ready (inside the door or on the rear label).

🛠 When to call a pro

  • F08 returns after a power reset: Hotpoint says to book an engineer.
  • The engineer checks the contacts on the board connector, tests the pressure switch for continuity at each water level (empty, normal and overfill), checks its wiring and hose, and checks the heater connections, per the Indesit service procedure.
  • If the pressure switch is stuck it gets replaced; if the switch and wiring are fine, the control board (with the heater relay) is replaced.
  • You notice a burning smell, scorch marks or tripping electrics: unplug the machine and don't use it until it's been checked.
  • The machine is still under warranty or extended cover: use Hotpoint service first.
