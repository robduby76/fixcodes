Code: F6 E2 (F6E2)🌀 Amana Dryer

Amana Dryer F6 E2 Error Code: Control Can't Talk to the Display (Meaning, Causes, Fixes)

Reviewed 2026-10-25 · Based on 4 manufacturer & service sources

⚡ Quick answer

F6 E2 on an Amana dryer is a communication error: the main control (cycle control unit) isn't hearing back from the user interface, the board behind the buttons and display. Amana's first fix is a full power reset: turn off the breaker for 5 minutes, turn it back on, start a timed dry cycle and watch for 5 minutes. If the code comes back, the Whirlpool-family tech sheet for this dryer platform says to check the wiring between the two boards and their power supply, then replace the user interface, and only then the main control.

What the code means

Amana dryers with F# E# codes share their electronics with Whirlpool and Maytag dryers. On these dryers the main control, called the Cycle Control Unit (CCU) in the tech sheet, and the User Interface (UI) send messages to each other constantly. The tech sheet for this platform (for example the Whirlpool WED94HEX sheet on ManualsLib) lists F6E1 as "Communication Error UI to CCU" and F6E2 as "Communication Error CCU to UI", and explains both the same way: communication between the CCU and UI has not been detected. In other words, F6 E2 isn't a heating, venting or sensor problem. It means the two circuit boards have lost contact, which usually comes from a loose or damaged harness connector, a power-supply problem on the board, a brief electrical glitch, or a failed board. Amana's own Product Help page for F6 E2 starts with a 5-minute power reset because a glitch can trigger it once and never again.

Likely causes

  • A brief power disturbance (surge, brownout or outage) that confused the boards, which is why Amana's first step is a 5-minute breaker reset
  • A loose, unplugged or corroded connector on the harness between the main control and the user interface
  • A pinched, chafed or broken wire in that harness, often after the console was opened or the dryer was moved
  • Missing or low AC or DC supply to the boards (the tech sheet's power check)
  • A failed user interface board, which the tech sheet says to replace first
  • A failed main control (CCU), replaced only after the harness, power and user interface are ruled out

Safe DIY checks

⚠ Before you start

Unplug the appliance or switch off its breaker before opening panels.

  1. Do Amana's reset exactly: turn off the dryer's circuit breaker(s) for 5 minutes, turn them back on, start a Timed Dry cycle, and watch the dryer for 5 minutes to see whether F6 E2 comes back. Unplugging the dryer for 5 minutes does the same thing.
  2. If the code appeared after a storm or outage, note that. A one-time F6 E2 that clears after the reset and doesn't return usually needs no repair.
  3. Check that the dryer has a solid supply: the plug is fully seated, the cord isn't damaged, and (for an electric dryer) both breakers in the double breaker are on.
  4. If it keeps coming back and you're comfortable with basic appliance repair, unplug the dryer first, then open the console and check the harness plugs on the user interface and main control. Reseat each one firmly and look for burnt, corroded or bent pins and pinched wires. Don't probe live circuits.
  5. Look up the tech sheet for your exact model (Amana sends people to its ServiceMatters site with the full model number). It shows the board connectors and the power check (TEST #1 on the WED94HEX sheet) for your dryer.
  6. If the harness is good and F6 E2 returns, the next part is the user interface board, then the main control. Order by full model number, since boards differ between models.

🛠 When to call a pro

  • F6 E2 keeps returning after the 5-minute reset and reseating the connectors.
  • You see burnt connectors, scorched board parts or melted wires.
  • You aren't comfortable working inside a 240-volt electric dryer or near a gas dryer's burner.
  • The diagnosis needs live voltage checks on the boards, which should be done by a technician.
  • The dryer is under warranty, since opening it and swapping boards yourself can complicate a claim.
