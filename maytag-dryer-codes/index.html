Maytag Dryer Error Codes: What Each Code Means

Every Maytag dryer code explained on FixCodes, 8 in all. Together they cite 27 sources (manufacturer manuals, service literature and support pages), and each guide covers what the code means, the likely causes, safe DIY checks and when to call a pro. Find the code on your display (or count the blinks) below.

CodeWhat it means
AFRestricted Airflow, Check the Vent
AF on a Maytag dryer means restricted airflow: the lint screen or the vent is clogged, or the vent is crushed, kinked or has too many turns.
F01Main Control Failure
F01 (shown as F-01, or F1 alternating with E1 on newer models) on a Maytag dryer means the main electronic control has detected a problem with itself.
F2E1Keypad Error
F2E1 on a Maytag dryer is a keypad error.
F2E2Keypad or Control Error
F2E2 on a Maytag dryer is a keypad or control error: the dryer's main control can't properly communicate with the user interface (the console keypad and display board).
F3E2Moisture Sensor Issue
F3E2 on a Maytag dryer is a moisture sensor issue: five loads in a row dried without the dryer getting a reading from its moisture sensor strips.
F4 E4Low or No L2 Line Voltage
F4 E4 on a Maytag dryer means the control is seeing low or no voltage on L2, the second 120-volt leg of the 240-volt supply.
F7E1Motor System Error
F7E1 on a Maytag dryer means a motor system problem: something is wrong with the drive motor, the control, or the wiring between them.
PFPower Failure Interrupted the Cycle
PF on a Maytag dryer means Power Failure: the drying cycle was interrupted because the power dropped out.

The same code can mean different things on different model lines. Always confirm against the manual or wiring-diagram label for your exact model number.
